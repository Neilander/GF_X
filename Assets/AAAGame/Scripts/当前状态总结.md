### 2. 卡牌丢弃功能 ✅ (已修复)

#### 问题
卡牌拖动到垃圾桶时生成士兵对象，而不是丢弃卡牌

#### 根本原因
1. 坐标转换错误（Overlay Canvas 模式下坐标异常）
2. 检测优先级错误

#### 修复方案
1. 使用 `RectTransformUtility.RectangleContainsScreenPoint`
2. 添加 `GetUICamera()` 方法，根据 Canvas 模式返回正确的相机
3. 调整检测优先级：垃圾桶 > 手牌区域 > 场景放置

#### 修改文件
- `CardUIForm.cs` - 完全重写了区域检测逻辑

#### 测试方法
拖动卡牌到垃圾桶，应该看到：
```
[CardUI] ✅ Is in trash bin: True
[CardUI] ✅✅✅ Card in trash bin, DISCARDING
[CardUI] ✅ Card discarded and removed successfully
```

## 技术要点

### 小地图系统架构
```
单位 Update → MinimapReportComponent.Tick() 
           → MinimapManager.UpdateUnit()
           → MinimapManager.LateUpdate() 广播事件
           → MinimapUI.HandleUnitsUpdated()
           → 更新 UI 显示
```

### 卡牌丢弃检测优先级
```
1. 检查垃圾桶区域 → 丢弃卡牌
2. 检查手牌区域 → 取消放置
3. 尝试场景放置 → 生成对象
```
