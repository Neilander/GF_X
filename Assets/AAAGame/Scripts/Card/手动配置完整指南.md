# 卡牌系统手动配置完整指南

## 概述

本指南将帮助你从零开始手动配置卡牌系统，无需使用任何自动化工具。

## 前置条件

- ✅ 所有代码已编译通过（无错误）
- ✅ Unity 编辑器已打开
- ✅ 项目已加载

## 配置步骤

### 步骤 1: 配置 ChangeSceneProcedure（设置启动流程）

#### 1.1 打开场景选择工具

在 Unity 编辑器中：

1. 找到菜单栏：`AAAGame → Scene Selector`
2. 或者找到：`Tools → Scene Selector`
3. 如果没有这个菜单，继续下一步手动配置

#### 1.2 手动设置启动流程（如果没有 Scene Selector）

在 Unity 编辑器中：

1. 打开 `Launch` 场景
2. 在 Hierarchy 中找到 `GameEntry` GameObject
3. 在 Inspector 中找到相关的启动配置组件
4. 或者通过代码设置（见下方）

#### 1.3 通过代码设置（推荐）

创建一个临时脚本来设置启动流程：

**文件位置**: `Assets/AAAGame/Scripts/Card/Test/SetCardGameProcedure.cs`

```csharp
using UnityEngine;
using UnityEditor;

public class SetCardGameProcedure
{
    [MenuItem("AAAGame/Card System/Set Card Game Procedure")]
    public static void SetProcedure()
    {
        // 设置启动流程为 CardGameProcedure
        ChangeSceneProcedure.SelectedProcedureForGame = "CardGameProcedure";
        ChangeSceneProcedure.SelectedSceneForGame = "Game";
        
        Debug.Log("✓ 已设置启动流程为 CardGameProcedure");
        Debug.Log("✓ 已设置场景为 Game");
        Debug.Log("现在可以运行 Launch 场景测试卡牌系统");
    }
}
```

保存后，在 Unity 菜单中会出现：`AAAGame → Card System → Set Card Game Procedure`

点击它即可设置启动流程。

### 步骤 2: 配置 UITable（注册 CardUIForm）

#### 2.1 打开 UITable.xlsx

文件位置：`GF_X/AAAGameData/DataTables/Core/UITable.xlsx`

用 Excel 或 WPS 打开。

#### 2.2 查看现有格式

UITable 应该类似这样：

| Id | Name | AssetPath | UIGroup | AllowMultiInstance | PauseCoveredUIForm |
|----|------|-----------|---------|-------------------|-------------------|
| 1 | MenuUIForm | Assets/AAAGame/Prefabs/UI/MenuUIForm.prefab | Default | FALSE | FALSE |
| 2 | GameUIForm | Assets/AAAGame/Prefabs/UI/GameUIForm.prefab | Default | FALSE | FALSE |
| ... | ... | ... | ... | ... | ... |

#### 2.3 添加 CardUIForm 行

在最后一行添加：

| Id | Name | AssetPath | UIGroup | AllowMultiInstance | PauseCoveredUIForm |
|----|------|-----------|---------|-------------------|-------------------|
| 16 | CardUIForm | Assets/AAAGame/Prefabs/UI/CardUIForm.prefab | Default | FALSE | FALSE |

**注意**：
- `Id` 使用下一个可用的 ID（如果最后一行是 15，就用 16）
- `Name` 必须是 `CardUIForm`
- `AssetPath` 是预制体的完整路径
- `UIGroup` 通常是 `Default`
- `AllowMultiInstance` 和 `PauseCoveredUIForm` 都是 `FALSE`

#### 2.4 保存文件

保存并关闭 Excel。

### 步骤 3: 生成 DataTable

#### 3.1 清理 Excel 锁定文件（如果需要）

如果之前打开过 Excel，可能有锁定文件。

**方法 1**: 使用清理脚本
```powershell
cd GF_X
.\CleanExcelLocks.ps1
```

**方法 2**: 手动删除
删除所有 `~$` 开头的文件：
- `GF_X/AAAGameData/DataTables/Build/~$DeviceTable.xlsx`
- `GF_X/AAAGameData/DataTables/Tech/~$TechNodeTable.xlsx`
- 等等...

#### 3.2 生成 DataTable

在 Unity 编辑器中：

1. 菜单栏：`AAAGame → Generate DataTables`
2. 等待生成完成（10-30 秒）
3. 检查 Console 是否有错误

#### 3.3 验证生成成功

检查文件：`Assets/AAAGame/Scripts/UI/Core/UIViews.cs`

应该包含：
```csharp
public enum UIViews : int
{
    MenuUIForm = 1,
    GameUIForm = 2,
    // ...
    CardUIForm = 16,  // ← 新增的
}
```

### 步骤 4: 创建 HandCardItem 预制体

#### 4.1 创建基础 GameObject

1. 在 Hierarchy 中右键 → `UI → Image`
2. 重命名为 `HandCardItem`

#### 4.2 配置 RectTransform

在 Inspector 中：
- Width: 150
- Height: 200
- Anchor: Center

#### 4.3 添加 HandCardItem 脚本

1. 在 Inspector 中点击 `Add Component`
2. 搜索 `HandCardItem`
3. 添加脚本

#### 4.4 添加 CanvasGroup 组件

1. 点击 `Add Component`
2. 搜索 `CanvasGroup`
3. 添加组件

#### 4.5 创建子对象

在 `HandCardItem` 下创建以下子对象：

**1. CardImage (Image)**
- 右键 HandCardItem → `UI → Image`
- 重命名为 `CardImage`
- 设置为填充父对象：
  - Anchor: Stretch (左上角的方框图标，选择右下角的拉伸选项)
  - Left: 10, Right: 10, Top: 10, Bottom: 10

**2. PopulationText (TextMeshProUGUI)**
- 右键 HandCardItem → `UI → Text - TextMeshPro`
- 重命名为 `PopulationText`
- 位置：左上角
- 文本内容：`5`
- 字体大小：24
- 颜色：白色

**3. SoldierCountText (TextMeshProUGUI)**
- 右键 HandCardItem → `UI → Text - TextMeshPro`
- 重命名为 `SoldierCountText`
- 位置：右下角
- 文本内容：`3`
- 字体大小：20
- 颜色：白色

#### 4.6 配置 HandCardItem 脚本

在 Inspector 中，将组件拖拽到对应字段：
- `Card Image` → 拖拽 `CardImage` 对象
- `Population Text` → 拖拽 `PopulationText` 对象
- `Soldier Count Text` → 拖拽 `SoldierCountText` 对象
- `Canvas Group` → 拖拽 `CanvasGroup` 组件

设置动画参数：
- `Drag Scale`: 1.2
- `Hover Scale`: 1.1
- `Animation Duration`: 0.2

#### 4.7 保存为预制体

1. 在 Project 窗口中，导航到 `Assets/AAAGame/Prefabs/UI/`
2. 如果没有这个文件夹，创建它
3. 将 Hierarchy 中的 `HandCardItem` 拖拽到这个文件夹
4. 删除 Hierarchy 中的 `HandCardItem`

### 步骤 5: 创建 CardUIForm 预制体

#### 5.1 创建基础 Canvas

1. Hierarchy 右键 → `UI → Canvas`
2. 重命名为 `CardUIForm`

#### 5.2 配置 Canvas

在 Inspector 中：
- Render Mode: Screen Space - Overlay
- Canvas Scaler:
  - UI Scale Mode: Scale With Screen Size
  - Reference Resolution: 1920 x 1080

#### 5.3 添加 CardUIForm 脚本

1. 点击 `Add Component`
2. 搜索 `CardUIForm`
3. 添加脚本

#### 5.4 创建 UI 结构

在 `CardUIForm` 下创建以下结构：

```
CardUIForm (Canvas)
├─ HandCardsContainer (Empty GameObject)
├─ PopulationView (Empty GameObject)
│  └─ PopulationText (TextMeshProUGUI)
├─ TrashBin (Image)
│  ├─ Icon (Image)
│  └─ HintText (TextMeshProUGUI)
└─ CardDeck (Empty GameObject)
```

#### 5.5 详细配置每个对象

**1. HandCardsContainer**
- 右键 CardUIForm → `Create Empty`
- 重命名为 `HandCardsContainer`
- 添加 `Horizontal Layout Group` 组件：
  - Spacing: 20
  - Child Alignment: Middle Center
  - Child Force Expand: Width ✓, Height ✗
- 位置：屏幕底部中央
- RectTransform:
  - Anchor: Bottom Center
  - Pos Y: 150
  - Width: 800
  - Height: 250

**2. PopulationView**
- 右键 CardUIForm → `Create Empty`
- 重命名为 `PopulationView`
- 添加 `PopulationView` 脚本
- 位置：屏幕右上角
- RectTransform:
  - Anchor: Top Right
  - Pos X: -50
  - Pos Y: -50

**2.1 PopulationText**
- 右键 PopulationView → `UI → Text - TextMeshPro`
- 重命名为 `PopulationText`
- 文本内容：`0/10`
- 字体大小：36
- 颜色：白色
- 对齐：Center

**3. TrashBin**
- 右键 CardUIForm → `UI → Image`
- 重命名为 `TrashBin`
- 位置：屏幕右下角
- RectTransform:
  - Anchor: Bottom Right
  - Pos X: -100
  - Pos Y: 100
  - Width: 100
  - Height: 100
- 颜色：半透明红色 (R:255, G:0, B:0, A:100)

**3.1 Icon (可选)**
- 右键 TrashBin → `UI → Image`
- 重命名为 `Icon`
- 设置垃圾桶图标（如果有）

**3.2 HintText**
- 右键 TrashBin → `UI → Text - TextMeshPro`
- 重命名为 `HintText`
- 文本内容：`拖到这里删除`
- 字体大小：16
- 颜色：白色
- 对齐：Center
- 默认隐藏：取消勾选 GameObject 的激活状态

**4. CardDeck**
- 右键 CardUIForm → `Create Empty`
- 重命名为 `CardDeck`
- 位置：屏幕左上角（抽卡动画起点）
- RectTransform:
  - Anchor: Top Left
  - Pos X: 100
  - Pos Y: -100

#### 5.6 配置 CardUIForm 脚本

在 Inspector 中，将组件拖拽到对应字段：

**UI 容器**:
- `Hand Card Container` → 拖拽 `HandCardsContainer`
- `Hand Card Area` → 可选，留空
- `Trash Bin` → 拖拽 `TrashBin`
- `Trash Bin Hint Text` → 拖拽 `TrashBin/HintText`

**预制体**:
- `Hand Card Item Prefab` → 拖拽 `HandCardItem.prefab`（从 Project 窗口）

**人口显示**:
- `Population View` → 拖拽 `PopulationView` 组件

**区域材质效果**:
- `Area Material Overlay` → 暂时留空（后面配置）

**抽卡动画**:
- `Card Deck Transform` → 拖拽 `CardDeck`
- `Card Move To Hand Duration` → 0.5

**快捷键**:
- `Toggle UI Key` → Tab

#### 5.7 保存为预制体

1. 在 Project 窗口中，导航到 `Assets/AAAGame/Prefabs/UI/`
2. 将 Hierarchy 中的 `CardUIForm` 拖拽到这个文件夹
3. 删除 Hierarchy 中的 `CardUIForm`

### 步骤 6: 配置场景（Game 场景）

#### 6.1 打开 Game 场景

在 Project 窗口中：
- 导航到 `Assets/AAAGame/Scenes/`
- 双击打开 `Game.unity`

#### 6.2 创建地面（如果没有）

1. Hierarchy 右键 → `3D Object → Plane`
2. 重命名为 `Ground`
3. 位置：(0, 0, 0)
4. 缩放：(10, 1, 10)
5. 确保有 `Mesh Collider` 组件

#### 6.3 创建 ValidArea（可放置区域）

1. Hierarchy 右键 → `Create Empty`
2. 重命名为 `ValidArea`
3. 位置：(0, 0, 0)

**添加子对象**:
- 右键 ValidArea → `3D Object → Plane`
- 重命名为 `ValidAreaPlane`
- 位置：(0, 0.01, 0)（稍微高于地面）
- 缩放：(5, 1, 5)
- 确保有 `Mesh Collider` 组件

**设置材质（可选）**:
- 创建一个绿色半透明材质
- 应用到 `ValidAreaPlane`

#### 6.4 创建 InvalidArea（禁止区域）

1. Hierarchy 右键 → `Create Empty`
2. 重命名为 `InvalidArea`
3. 位置：(0, 0, 0)

**添加子对象**:
- 右键 InvalidArea → `3D Object → Cube`
- 重命名为 `InvalidAreaCube`
- 位置：(5, 0.5, 5)
- 缩放：(2, 1, 2)
- 确保有 `Box Collider` 组件

**设置材质（可选）**:
- 创建一个红色半透明材质
- 应用到 `InvalidAreaCube`

#### 6.5 创建 CardAreaMaterialOverlay（可选）

如果需要区域材质效果：

1. Hierarchy 右键 → `Create Empty`
2. 重命名为 `CardAreaMaterialOverlay`
3. 添加 `CardAreaMaterialOverlay` 脚本

**配置脚本**:
- `Valid Overlay Material` → 绿色材质
- `Invalid Overlay Material` → 红色材质
- `Valid Area Object` → 拖拽 `ValidArea`
- `Invalid Area Object` → 拖拽 `InvalidArea`

然后在 `CardUIForm.prefab` 中：
- 打开预制体编辑模式
- 将场景中的 `CardAreaMaterialOverlay` 拖拽到 `Area Material Overlay` 字段
- 保存预制体

#### 6.6 保存场景

`Ctrl + S` 或 `File → Save`

## 常见问题

### Q1: CardUIForm 没有打开

**检查**:
1. UITable.xlsx 是否正确配置
2. DataTable 是否已生成
3. UIViews.cs 是否包含 CardUIForm
4. 预制体路径是否正确

**解决**:
```
菜单 → AAAGame → Generate DataTables
```

### Q2: 卡牌无法拖拽

**检查**:
1. HandCardItem 是否有 CanvasGroup 组件
2. Canvas 是否有 GraphicRaycaster 组件
3. EventSystem 是否存在于场景中

**解决**:
- 添加缺失的组件
- 确保 Canvas 的 Render Mode 正确

### Q3: 区域效果不显示

**检查**:
1. CardAreaMaterialOverlay 是否已配置
2. ValidArea 和 InvalidArea 是否有 Collider
3. 材质是否已设置

**解决**:
- 按照步骤 6.5 配置
- 确保 Collider 已启用

### Q4: 人口不显示

**检查**:
1. PopulationView 组件是否已添加
2. PopulationText 是否已配置
3. CardSystemController 是否正确初始化

**解决**:
- 检查 CardGameProcedure 的初始化代码
- 确保 SetMaxPopulation 被调用

### Q5: Console 显示 "CardSystemController is null"

**检查**:
1. CardGameProcedure 是否正确传递参数
2. CardUIForm 是否正确接收参数

**解决**:
- 确保使用 `uiParams.Set("CardSystemController", controller)`
- 确保使用 `uiParams.Get("CardSystemController")`
