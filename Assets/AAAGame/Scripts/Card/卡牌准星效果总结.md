# 卡牌准星效果总结

## 1. 本次效果目标

本次改造的目标是让当前 `Card` 卡牌系统在拖拽放置时，拥有更接近《杀戮尖塔》《影之诗》这类卡牌游戏的交互表现：

- 鼠标悬浮到卡牌时，卡牌放大
- 拖拽卡牌时，卡牌先跟随鼠标移动
- 当拖拽到可放置区域时，进入“准星目标模式”
- 进入目标模式后，卡牌回到手牌原索引位置
- 鼠标目标点显示准星
- 手牌中的卡牌与准星之间显示一条弯曲连线
- 地图上显示士兵生成范围圈
- 当拖回不可放置区域时，准星和曲线消失，恢复为卡牌本体跟随鼠标

## 2. 当前实现后的交互逻辑

### 2.1 悬浮阶段

- `HandCardItem` 继续保留原有悬浮放大逻辑
- 当卡牌可打出时，鼠标移入卡牌会缩放到 `hoverScale`

### 2.2 普通拖拽阶段

- 开始拖拽后，卡牌先提升到 Canvas 顶层
- 卡牌本体跟随鼠标移动
- 同时开始进入放置检测流程

### 2.3 准星目标阶段

当拖拽位置满足放置条件时：

- 卡牌本体不再跟随鼠标
- 卡牌回到手牌区域原始索引位
- 鼠标对应的场景投影位置显示准星
- 卡牌和准星之间绘制一条 UI 曲线
- 地图上显示一个与 `SpawnRadius` 对应的生成范围圈

### 2.4 无效区域阶段

当拖拽位置不合法，或者拖回手牌区、垃圾桶区域时：

- 准星隐藏
- 曲线隐藏
- 地图范围圈隐藏
- 卡牌重新恢复为本体跟随鼠标

## 3. 本次改动的核心文件

### 3.1 UI 层

#### `Assets/AAAGame/Scripts/Card/UI/CardUIForm.cs`

负责整体拖拽表现控制，主要新增了：

- 准星图片、尺寸、曲线颜色、粗细、弯曲高度、分段数等参数
- 运行时创建准星 UI
- 运行时创建目标连线 UI
- 根据拖拽状态切换“普通拖拽”和“准星目标模式”
- 根据屏幕坐标与场景坐标同步更新准星位置

#### `Assets/AAAGame/Scripts/Card/UI/HandCardItem.cs`

负责单张手牌交互，主要新增了：

- `m_IsTargetingMode`
- `EnterTargetingMode()`
- `ExitTargetingMode(Vector2 screenPosition)`
- `GetScreenAnchorPosition(Camera uiCamera)`

作用：

- 控制卡牌是否继续跟随鼠标
- 控制卡牌回到手牌原位置
- 提供曲线起点位置

#### `Assets/AAAGame/Scripts/Card/UI/CardTargetingCurveGraphic.cs`

这是新增脚本。

作用：

- 使用 `uGUI` 的 `MaskableGraphic` 在界面上绘制二次贝塞尔曲线
- 用于实现卡牌到准星之间的目标连线

### 3.2 场景反馈层

#### `Assets/AAAGame/Scripts/Card/UI/CardAreaMaterialOverlay.cs`

在原有区域材质叠加的基础上，新增了：

- 地图放置范围圈预览
- 合法区域和非法区域不同颜色

新增内容包括：

- `ShowPlacementPreview(Vector3 worldPosition, float radius, bool isValid)`
- `LineRenderer` 方式生成范围圈

### 3.3 放置控制层

#### `Assets/AAAGame/Scripts/Card/Controller/CardPlacementController.cs`

新增：

- `GetDetectionRadius()`
- `TryGetPlacementPreview(Vector2 screenPosition, out Vector3 groundPosition, out bool isValid)`

作用：

- 提供当前放置检测半径
- 在拖拽过程中实时返回目标点和是否合法

#### `Assets/AAAGame/Scripts/Card/Controller/CardSystemController.cs`

新增：

- `TryGetPlacementPreview(...)`
- `GetCurrentPlacementRadius()`

并修改：

- `StartPlacement(CardModel cardModel)` 中把放置检测半径设置为当前卡牌的 `SpawnRadius`

这样可以保证：

- 地图上的范围圈
- 放置合法性检测半径
- 最终士兵生成半径

三者尽量保持一致

## 4. 当前准星效果的参数说明

以下参数位于 `CardUIForm` 面板中：

### 准星图片

- 字段名：`targetingReticleSprite`
- 作用：拖拽进入目标模式后显示的准星图片
- 如果未配置，会使用运行时自动生成的默认准星图

### 准星尺寸

- 字段名：`targetingReticleSize`
- 作用：控制准星在 UI 上的显示大小

### 连线颜色

- 字段名：`targetingCurveColor`
- 作用：控制卡牌到准星之间曲线的颜色

### 连线粗细

- 字段名：`targetingCurveThickness`
- 作用：控制曲线宽度

### 连线弯曲高度

- 字段名：`targetingCurveHeight`
- 作用：控制曲线拱起程度

### 连线分段数

- 字段名：`targetingCurveSegments`
- 作用：控制曲线平滑程度
- 数值越高越圆滑，但开销也略高

## 5. 地图范围圈说明

地图上的范围圈由 `CardAreaMaterialOverlay` 负责绘制。

它的作用有两个：

1. 告诉玩家当前目标点是否可放置
2. 告诉玩家这张卡对应的士兵生成影响范围

当前范围圈半径直接取自：

- `CardData.spawnRadius`
- 或 `ICardDataProvider.SpawnRadius`

因此后续策划调卡时，只需要调卡牌自己的 `SpawnRadius`，放置预览和实际生成范围会一起变化。

## 6. 当前方案的优点

### 6.1 符合当前 GF_X 卡牌结构

这次没有另起一套卡牌系统，而是沿用：

- `HandCardItem`
- `CardUIForm`
- `CardSystemController`
- `CardPlacementController`

因此不会破坏你当前 GF_X 下已经接好的事件、对象池和手牌逻辑。

### 6.2 不强依赖额外 prefab 改造

准星和曲线是运行时创建的：

- 就算 prefab 里暂时没有手动配置这些对象
- 代码运行时也可以自动生成

这样能减少场景和预制体上的额外手工配置成本。

### 6.3 可直接替换准星美术

只要把你的准星图拖到 `CardUIForm` 面板上的“准星图片”字段，就能直接替换默认准星，不需要再改代码。

## 7. 后续建议

如果后续要继续优化，可以考虑：

### 7.1 准星增加合法/非法两套贴图

目前主要通过范围圈颜色和状态切换表现合法/非法。  
后续可以补：

- 合法准星图
- 非法准星图

这样视觉反馈会更明确。

### 7.2 曲线增加渐变或发光

当前曲线已经可用，但还属于基础版。  
后续可以加：

- 颜色渐变
- 外发光
- 尾部呼吸效果

### 7.3 准星增加轻微缩放动画

当进入可放置区时，可以让准星轻微弹出，手感会更像成熟卡牌游戏。

### 7.4 不同卡牌配置不同准星表现

后续如果有需要，可以在 `CardData` 里继续扩展：

- 不同卡使用不同准星图
- 不同卡使用不同曲线颜色
- 不同卡使用不同范围圈颜色

## 8. 本次总结

本次准星效果改造完成后，当前卡牌系统已经从单纯的“卡牌跟随鼠标拖拽”升级为：

- 手牌悬浮放大
- 拖拽进入目标模式
- 卡牌回归手牌位
- 鼠标目标点显示准星
- 卡牌与准星之间显示曲线
- 地图上显示生成范围圈

整体交互表现已经更接近传统成熟卡牌游戏的打牌手感，也更适合后续继续往正式表现层上细化。
