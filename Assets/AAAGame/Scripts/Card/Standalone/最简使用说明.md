# 最简卡牌系统 - 1分钟快速开始

## 🚀 超快速启动（1分钟）

### 步骤 1: 创建场景
1. 新建场景：`File → New Scene`
2. 保存为：`CardTest.unity`

### 步骤 2: 添加地面
1. `GameObject → 3D Object → Plane`
2. 命名为：`Ground`
3. Position: (0, 0, 0)
4. Scale: (5, 1, 5)

### 步骤 3: 添加系统
1. `GameObject → Create Empty`
2. 命名为：`CardSystem`
3. 添加脚本：`MinimalCardSystem`

### 步骤 4: 运行
1. 点击 **Play**
2. 按 **F1** 抽卡
3. 按 **1-8** 打出卡牌
4. **左键点击** 场景放置士兵

**完成！** 🎉

---

## 🎮 操作说明

### 键盘
- **1-8**: 打出对应位置的卡牌
- **F1**: 抽一张卡
- **F2**: 增加人口上限 +5

### 鼠标
- **左键**: 确认放置士兵
- **右键**: 取消放置

## 🔧 可选配置

### 添加有效/无效区域

#### 有效区域（绿色）
```
GameObject → 3D Object → Plane
名称：ValidArea
Position: (0, 0, 0)
Scale: (2, 1, 2)
Material: 绿色材质
```

#### 无效区域（红色）
```
GameObject → 3D Object → Plane
名称：InvalidArea
Position: (5, 0, 0)
Scale: (2, 1, 2)
Material: 红色材质
```

然后在 `MinimalCardSystem` 的 Inspector 中：
- Valid Area: 拖入 ValidArea
- Invalid Area: 拖入 InvalidArea

## 🎯 游戏流程

1. 按 **F1** 抽卡（最多 8 张手牌）
2. 按 **1-8** 选择要打出的卡牌
3. 鼠标移动预览放置位置
   - 绿色 = 可以放置
   - 红色 = 不能放置
4. **左键** 确认放置，生成士兵
5. 人口消耗，卡牌从手牌移除
6. 重复步骤 1-5

## 🐛 故障排除

### Q: 看不到 UI？
A: 确保场景中有 Camera（Main Camera）

### Q: 无法放置士兵？
A: 确保场景中有地面（Plane 或其他带 Collider 的对象）

### Q: 点击没反应？
A: 检查 Console 是否有错误信息

## 🎨 自定义

### 修改初始配置
在 Inspector 中修改：
- Max Population: 最大人口（默认 10）
- Max Hand Cards: 最大手牌数（默认 8）
- Initial Card Count: 初始手牌数（默认 4）

### 修改默认卡牌
编辑 `MinimalCardSystem.cs` 的 `CreateDefaultCardPool()` 方法：

```csharp
private void CreateDefaultCardPool()
{
    cardPool.Add(new SimpleCard("你的卡牌", 人口消耗, 掉落权重));
    // 添加更多卡牌...
}
```
