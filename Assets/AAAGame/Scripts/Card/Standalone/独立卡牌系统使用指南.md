# 独立卡牌系统使用指南

## 概述
这是一个完全独立的卡牌系统，**不依赖 GameFramework**，可以在任何 Unity 场景中直接使用。

---

## 🚀 快速开始（5分钟）

### 1. 创建测试场景
1. 创建新场景：`File → New Scene`
2. 保存为：`Assets/AAAGame/Scene/CardTest.unity`

### 2. 添加基础对象

#### A. 创建 Canvas（UI容器）
1. `GameObject → UI → Canvas`
2. 设置 Canvas Scaler：
   - UI Scale Mode: Scale With Screen Size
   - Reference Resolution: 1920x1080

#### B. 创建手牌容器
1. 在 Canvas 下创建空对象：`GameObject → Create Empty`
2. 命名为：`HandCardContainer`
3. 添加组件：`Horizontal Layout Group`
   - Spacing: 10
   - Child Alignment: Middle Center
4. 设置 RectTransform：
   - Anchor: Bottom Center
   - Pos Y: 100
   - Width: 1000, Height: 200

#### C. 创建人口显示文本
1. `GameObject → UI → Text`
2. 命名为：`PopulationText`
3. 设置位置：左上角
4. 文本内容：`人口: 0/10`
5. 字体大小：24

#### D. 创建手牌数量文本
1. `GameObject → UI → Text`
2. 命名为：`HandCountText`
3. 设置位置：左上角（人口文本下方）
4. 文本内容：`手牌: 0/8`
5. 字体大小：24

### 3. 创建手牌预制体（简化版）

1. `GameObject → UI → Button`
2. 命名为：`HandCardItem`
3. 调整大小：Width: 150, Height: 200
4. 修改 Button 下的 Text：
   - 文本内容：`卡牌名称`
   - 字体大小：18
5. 保存为预制体：拖到 `Assets/AAAGame/Prefabs/` 文件夹
6. 删除场景中的 HandCardItem

### 4. 创建区域对象

#### A. 有效区域（绿色）
```
GameObject → 3D Object → Plane
名称：ValidArea
Position: (0, 0, 0)
Scale: (2, 1, 2)
Material: 绿色半透明材质
```

#### B. 无效区域（红色）
```
GameObject → 3D Object → Plane
名称：InvalidArea
Position: (5, 0, 0)
Scale: (2, 1, 2)
Material: 红色半透明材质
```

### 5. 添加卡牌系统脚本

1. 创建空对象：`GameObject → Create Empty`
2. 命名为：`CardSystem`
3. 添加脚本：`StandaloneCardSystem`
4. 在 Inspector 中配置：

```
UI 配置:
- UI Canvas: 拖入场景中的 Canvas
- Hand Card Container: 拖入 HandCardContainer
- Hand Card Item Prefab: 拖入 HandCardItem 预制体
- Population Text: 拖入 PopulationText
- Hand Count Text: 拖入 HandCountText

游戏配置:
- Max Population: 10
- Max Hand Cards: 8
- Initial Card Count: 4

区域配置:
- Valid Area: 拖入 ValidArea
- Invalid Area: 拖入 InvalidArea

卡牌数据:
- Card Data List: 点击 + 添加卡牌数据
```

### 6. 创建卡牌数据（可选）

如果你有 CardData ScriptableObject：
1. 在 Inspector 的 Card Data List 中点击 +
2. 拖入你的 CardData 资源

如果没有，系统会使用默认配置。

### 7. 运行测试

1. 点击 Play
2. 使用快捷键：
   - **F1**: 抽一张卡
   - **F2**: 增加人口上限
   - **左键点击卡牌**: 开始放置
   - **左键点击场景**: 确认放置
   - **右键**: 取消放置

## 🎮 操作说明

### 鼠标操作
- **左键点击卡牌**: 选择卡牌开始放置
- **左键点击场景**: 在当前位置放置士兵
- **右键**: 取消当前放置

### 键盘快捷键
- **F1**: 抽一张卡
- **F2**: 增加人口上限 +5

### 放置规则
- 绿色预览 = 有效位置（可以放置）
- 红色预览 = 无效位置（不能放置）
- 人口不足时无法打出卡牌

## 🐛 常见问题

### Q: 点击卡牌没有反应？
A: 检查以下内容：
1. HandCardItem 预制体是否有 Button 组件
2. Canvas 是否有 GraphicRaycaster 组件
3. 场景中是否有 EventSystem

### Q: 无法放置士兵？
A: 检查以下内容：
1. 场景中是否有 Camera（Main Camera）
2. ValidArea 是否有 Collider 组件
3. 人口是否已满

### Q: 抽不到卡？
A: 检查以下内容：
1. Card Data List 是否为空
2. 手牌是否已满（最多8张）
