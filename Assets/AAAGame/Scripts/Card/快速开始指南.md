# 卡牌系统快速开始指南

## 🚀 5 分钟快速启动

### 第 1 步：重新生成 UIViews 枚举（必需）
```
Unity 菜单 → AAAGame → Generate DataTables
```
等待生成完成，确保 `UIViews.CardUIForm` 枚举值存在。

### 第 2 步：检查配置（推荐）
```
Unity 菜单 → AAAGame → Card → Check Card System Setup
```
查看控制台输出，确认所有配置项都是 ✅。

### 第 3 步：快速启动
```
Unity 菜单 → AAAGame → Card → Quick Start Card Game
```
这将自动：
- 设置启动场景为 Launch
- 设置目标场景为 Game
- 设置流程为 CardGameProcedure
- 打开 Launch 场景

### 第 4 步：运行游戏
点击 Unity 的 Play 按钮，观察流程：
```
Launch 场景启动
    ↓
LaunchProcedure (初始化)
    ↓
PreloadProcedure (预加载)
    ↓
ChangeSceneProcedure (加载 Game 场景)
    ↓
CardGameProcedure (显示卡牌 UI)
    ↓
CardUIForm 打开，手牌显示
```

## 📋 配置清单

### 必需配置

#### 1. CardUIForm 预制体
路径：`Assets/AAAGame/Prefabs/UI/CardUIForm.prefab`

必需字段：
- ✅ `handCardContainer` - 手牌容器
- ✅ `trashBinArea` - 垃圾桶区域
- ✅ `handCardItemPrefab` - HandCardItem 预制体
- ✅ `populationView` - 人口显示组件

#### 2. HandCardItem 预制体
路径：`Assets/AAAGame/Scripts/Card/HandCardItem.prefab`

必需字段：
- ✅ `cardImage` - 卡面图片
- ✅ `populationText` - 人口消耗文本
- ✅ `soldierCountText` - 士兵数量文本
- ✅ `canvasGroup` - CanvasGroup 组件

#### 3. 场景对象
在 Game 场景中：
- ✅ `ValidArea` GameObject
- ✅ `InvalidArea` GameObject
- ✅ EventSystem（UI 交互必需）

#### 4. 卡牌数据
路径：`Resources/CardData/`
- ✅ 至少一个 CardData ScriptableObject

### 可选配置

#### 对象池参数
在 `CardUIForm.cs` 的 `CreateHandCardItem()` 方法中：
```csharp
SpawnItem<HandCardItemObject>(
    handCardItemPrefab,
    handCardContainer,
    autoReleaseInterval: 5f,  // 自动释放间隔
    capacity: 50,             // 对象池容量
    expireTime: 50            // 过期时间
)
```

#### 卡牌系统参数
在 `CardGameProcedure.cs` 的 `InitializeCardSystem()` 方法中：
```csharp
m_CardSystemController.SetMaxPopulation(10); // 最大人口
```

## 🔧 常见问题解决

### 问题 1: 编译错误 "UIViews.CardUIForm 不存在"
**解决方案：**
```
Unity 菜单 → AAAGame → Generate DataTables
```

### 问题 2: 卡牌 UI 不显示
**检查项：**
1. 是否执行了 Quick Start Card Game？
2. 是否从 Launch 场景启动？
3. 控制台是否有错误信息？

**解决方案：**
```
Unity 菜单 → AAAGame → Card → Check Card System Setup
```
根据检查结果修复配置。

### 问题 3: 手牌创建失败
**检查项：**
1. CardUIForm 预制体的 `handCardItemPrefab` 是否赋值？
2. HandCardItem 预制体是否存在？
3. HandCardItem 预制体是否挂载了 HandCardItem 脚本？

**解决方案：**
在 CardUIForm 预制体中正确配置 `handCardItemPrefab` 字段。

### 问题 4: 卡牌拖拽无响应
**检查项：**
1. 场景中是否有 EventSystem？
2. HandCardItem 是否实现了拖拽接口？
3. Canvas 的 Render Mode 是否正确？

**解决方案：**
确保场景中有 EventSystem，Canvas 使用 Screen Space - Overlay 或 Screen Space - Camera。

### 问题 5: 人口显示不更新
**检查项：**
1. PopulationView 组件是否正确配置？
2. 是否订阅了人口变化事件？

**解决方案：**
检查 CardUIForm 的 `populationView` 字段是否赋值。

## 📊 性能优化建议

### 对象池优化
```csharp
// 根据实际手牌数量调整容量
capacity: 10,  // 如果最多 4 张手牌，10 足够

// 根据游戏节奏调整过期时间
expireTime: 30,  // 快节奏游戏可以缩短

// 根据抽卡频率调整自动释放间隔
autoReleaseInterval: 3f,  // 频繁抽卡可以缩短
```

### 卡牌数据优化
```csharp
// 使用 DataTable 替代 ScriptableObject
// 在 CardGameProcedure.LoadCardPool() 中：
var cardTable = GF.DataTable.GetDataTable<CardTable>();
foreach (var row in cardTable.GetAllDataRows())
{
    cardPool.Add(new CardDataTableAdapter(row));
}
```
