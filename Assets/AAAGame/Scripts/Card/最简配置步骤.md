# 卡牌系统 - 最简配置步骤

## 5 步快速配置

### 步骤 1: 设置启动流程（1 分钟）

在 Unity 菜单栏：
```
AAAGame → Card System → Set Card Game Procedure
```

如果没有这个菜单，刷新 Unity 或重新编译。

---

### 步骤 2: 配置 UITable（2 分钟）

1. 打开文件：`GF_X/AAAGameData/DataTables/Core/UITable.xlsx`

2. 在最后一行添加：

| Id | Name | AssetPath | UIGroup | AllowMultiInstance | PauseCoveredUIForm |
|----|------|-----------|---------|-------------------|-------------------|
| 16 | CardUIForm | Assets/AAAGame/Prefabs/UI/CardUIForm.prefab | Default | FALSE | FALSE |

3. 保存文件

---

### 步骤 3: 生成 DataTable（30 秒）

在 Unity 菜单栏：
```
AAAGame → Generate DataTables
```

等待完成，检查 Console 无错误。

---

### 步骤 4: 创建预制体（10 分钟）

#### 4.1 创建 HandCardItem.prefab

**最简版本**：

1. Hierarchy 右键 → `UI → Image`，命名为 `HandCardItem`
2. 添加组件：
   - `HandCardItem` 脚本
   - `CanvasGroup` 组件
3. 创建子对象：
   - `CardImage` (Image) - 卡面
   - `PopulationText` (TextMeshProUGUI) - 人口
   - `SoldierCountText` (TextMeshProUGUI) - 士兵数
4. 配置脚本字段（拖拽组件）
5. 保存到 `Assets/AAAGame/Prefabs/UI/HandCardItem.prefab`

#### 4.2 创建 CardUIForm.prefab

**最简版本**：

1. Hierarchy 右键 → `UI → Canvas`，命名为 `CardUIForm`
2. 添加 `CardUIForm` 脚本
3. 创建子对象：
   - `HandCardsContainer` (Empty) - 手牌容器
   - `PopulationView` (Empty + PopulationView 脚本)
     - `PopulationText` (TextMeshProUGUI)
   - `TrashBin` (Image) - 垃圾桶
     - `HintText` (TextMeshProUGUI)
   - `CardDeck` (Empty) - 卡组位置
4. 配置脚本字段：
   - `Hand Card Container` → HandCardsContainer
   - `Hand Card Item Prefab` → HandCardItem.prefab
   - `Population View` → PopulationView 组件
   - `Trash Bin` → TrashBin
   - `Trash Bin Hint Text` → HintText
   - `Card Deck Transform` → CardDeck
5. 保存到 `Assets/AAAGame/Prefabs/UI/CardUIForm.prefab`

---

### 步骤 5: 配置场景（5 分钟）

打开 `Game` 场景，创建：

1. **ValidArea**（可放置区域）
   - Empty GameObject，命名 `ValidArea`
   - 子对象：Plane，添加 Collider

2. **InvalidArea**（禁止区域）
   - Empty GameObject，命名 `InvalidArea`
   - 子对象：Cube，添加 Collider

保存场景。

---

## 测试运行

1. 打开 `Launch` 场景
2. 点击 Play
3. 等待进入 Game 场景
4. CardUIForm 应该自动打开

## 如果出现问题

### 问题 1: CardUIForm 没有打开

**检查**：
- UITable.xlsx 是否正确配置
- DataTable 是否已生成
- 预制体路径是否正确

**解决**：
```
AAAGame → Generate DataTables
```

### 问题 2: 找不到菜单

**解决**：
1. 确保 `SetCardGameProcedure.cs` 文件存在
2. 刷新 Unity：`Ctrl + R`
3. 重新编译：`Ctrl + Shift + B`

### 问题 3: 编译错误

**解决**：
查看 `错误修复报告.md` 或 `UIParams传参修复.md`
