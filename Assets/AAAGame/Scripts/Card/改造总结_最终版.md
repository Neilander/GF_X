## ⚠️ 需要在 Unity 中完成的配置

### 必须完成（5 分钟）

1. **UITable.xlsx** - 添加 CardUIForm 条目
   ```
   打开：GF_X/AAAGameData/DataTables/Core/UITable.xlsx
   添加行：Id=16, Name=CardUIForm, AssetPath=Assets/AAAGame/Prefabs/UI/CardUIForm.prefab
   ```

2. **生成 DataTable**
   ```
   Unity 菜单：AAAGame → Generate DataTables
   ```

3. **创建预制体**
   - `Assets/AAAGame/Prefabs/UI/CardUIForm.prefab`
   - `Assets/AAAGame/Prefabs/UI/HandCardItem.prefab`

4. **配置场景**
   - 创建 `ValidArea` GameObject（带 Collider）
   - 创建 `InvalidArea` GameObject（带 Collider）

详细步骤请查看：`快速配置指南.md`
