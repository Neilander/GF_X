## 事件流程图

### 抽卡流程

```
用户操作 / 系统触发
       ↓
CardSystemController.DrawCard()
       ↓
HandCardController.DrawCard()
       ↓
PlayerHandModel.AddCard()
       ↓
触发事件: CardDrawnEventArgs
       ↓
CardUIForm.OnCardDrawn()
       ↓
CreateHandCardItem()
       ↓
SpawnItem<HandCardItemObject>() (对象池)
       ↓
HandCardItem.Initialize()
       ↓
播放抽卡动画
       ↓
卡牌显示在手牌区
```

### 打出卡牌流程

```
用户拖拽卡牌
       ↓
HandCardItem.OnBeginDrag()
       ↓
CardUIForm.OnCardBeginDrag()
       ↓
CardSystemController.StartPlacement()
       ↓
用户拖拽中...
       ↓
HandCardItem.OnDrag()
       ↓
CardUIForm.OnCardDragging()
       ↓
UpdateAreaMaterialEffect() (显示绿色/红色)
       ↓
用户松开鼠标
       ↓
HandCardItem.OnEndDrag()
       ↓
CardUIForm.OnCardEndDrag()
       ↓
CardSystemController.ConfirmPlacement()
       ├─ 检查区域 (AreaDetectionController)
       ├─ 消耗人口 (PopulationModel)
       ├─ 生成士兵
       └─ 移除手牌 (HandCardController)
       ↓
触发事件: CardPlayedEventArgs
       ↓
CardUIForm.OnCardPlayed()
       ↓
RemoveHandCardItem()
       ↓
UnspawnItem<HandCardItemObject>() (回收到对象池)
```

### 删除卡牌流程

```
用户拖拽卡牌到垃圾桶
       ↓
HandCardItem.OnEndDrag()
       ↓
CardUIForm.OnCardEndDrag()
       ↓
IsInTrashBin() == true
       ↓
CardSystemController.DiscardCard()
       ↓
HandCardController.RemoveCard()
       ↓
触发事件: CardDiscardedEventArgs
       ↓
CardUIForm.OnCardDiscarded()
       ↓
RemoveHandCardItem()
       ↓
UnspawnItem<HandCardItemObject>() (回收到对象池)
```

## 人口系统

```
┌─────────────────────────────────────────┐
│         PopulationModel                  │
│                                          │
│  CurrentPopulation: 5                    │
│  MaxPopulation: 10                       │
│                                          │
│  ConsumePopulation(cost)                 │
│  HasEnoughPopulation(cost)               │
└─────────────────────────────────────────┘
         ↓ 变化时触发事件
┌─────────────────────────────────────────┐
│    PopulationChangedEventArgs            │
└─────────────────────────────────────────┘
         ↓ 订阅
┌─────────────────────────────────────────┐
│         PopulationView                   │
│                                          │
│  显示: "5/10"                            │
│  颜色: 白色 (正常) / 红色 (不足)         │
└─────────────────────────────────────────┘
         ↓ 同时通知
┌─────────────────────────────────────────┐
│         CardUIForm                       │
│                                          │
│  UpdatePlayability() (所有手牌)         │
│  ├─ 人口足够: alpha = 1.0               │
│  └─ 人口不足: alpha = 0.5 (置灰)        │
└─────────────────────────────────────────┘
```

---

**说明**: 
- 实线箭头 (→) 表示直接调用
- 虚线箭头 (⇢) 表示事件触发
- 双向箭头 (↔) 表示双向通信
