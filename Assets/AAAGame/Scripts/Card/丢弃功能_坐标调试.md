## 🔍 坐标系统说明

### 1. Screen Position（屏幕坐标）
- 单位：像素
- 原点：屏幕左下角 (0, 0)
- 范围：(0, 0) 到 (屏幕宽度, 屏幕高度)
- 例如：1920x1080 屏幕，右上角是 (1920, 1080)

### 2. Anchored Position（锚点坐标）
- 单位：像素（相对于锚点）
- 原点：取决于锚点设置
- 范围：可以是负数
- 例如：锚点在右下角，对象在左上方，坐标可能是负数

## 🐛 可能的问题

### 问题 1：UI Camera 为 NULL

**症状**：日志显示 `UI Camera: NULL`

**原因**：`GFBuiltin.UICamera` 没有正确设置

**解决方案**：
1. 检查场景中是否有 UI Camera
2. 检查 GFBuiltin 是否正确初始化
3. 可能需要手动设置 UI Camera

### 问题 2：Canvas 设置错误

**症状**：World Corners 的屏幕坐标不对

**原因**：Canvas 的 Render Mode 设置不正确

**解决方案**：
1. 打开 CardUIForm 预制体
2. 选中根对象的 Canvas 组件
3. 确认设置：
   - Render Mode: Screen Space - Overlay 或 Screen Space - Camera
   - 如果是 Camera 模式，确认 Render Camera 已设置

### 问题 3：垃圾桶不在正确的 Canvas 下

**症状**：垃圾桶的屏幕坐标和实际位置不匹配

**原因**：垃圾桶可能在错误的 Canvas 下

**解决方案**：
1. 确认 TrashBin 是 CardUIForm 的子对象
2. 确认 TrashBin 在同一个 Canvas 下

## 🎯 临时解决方案

如果坐标检测一直有问题，可以使用简化的检测方法：

### 方法 1：使用世界坐标检测

```csharp
private bool IsInTrashBin(Vector2 screenPosition)
{
    if (m_TrashBinRect == null) return false;
    
    // 将屏幕坐标转换为世界坐标
    Vector3 worldPos;
    RectTransformUtility.ScreenPointToWorldPointInRectangle(
        m_TrashBinRect, screenPosition, GFBuiltin.UICamera, out worldPos);
    
    // 检查是否在矩形内
    Vector3 localPos = m_TrashBinRect.InverseTransformPoint(worldPos);
    Rect rect = m_TrashBinRect.rect;
    
    bool isInside = rect.Contains(localPos);
    Log.Info($"[CardUI] Local Position: {localPos}, Rect: {rect}, Inside: {isInside}");
    
    return isInside;
}
```

### 方法 2：使用距离检测

```csharp
private bool IsInTrashBin(Vector2 screenPosition)
{
    if (m_TrashBinRect == null) return false;
    
    // 获取垃圾桶的屏幕中心位置
    Vector2 trashBinScreenPos = RectTransformUtility.WorldToScreenPoint(
        GFBuiltin.UICamera, m_TrashBinRect.position);
    
    // 计算距离
    float distance = Vector2.Distance(screenPosition, trashBinScreenPos);
    float threshold = 100f; // 检测半径
    
    bool isNear = distance < threshold;
    Log.Info($"[CardUI] Distance to trash bin: {distance}, Threshold: {threshold}, Near: {isNear}");
    
    return isNear;
}
```
