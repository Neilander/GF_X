## 🔧 技术要点

### 1. GF_X 对象池使用

```csharp
// 创建
var itemObject = SpawnItem<UIItemObject>(prefab, container);

// 访问
GameObject go = itemObject.gameObject;
HandCardItem item = go.GetComponent<HandCardItem>();

// 回收
UnspawnItem<UIItemObject>(prefab, itemObject);

// 清空
UnspawnAllItem<UIItemObject>(prefab);
```

### 2. UIParams 参数传递

```csharp
// 发送方
UIParams uiParams = UIParams.Create();
uiParams.Set("Key", value);
GF.UI.OpenUIForm(UIViews.MyForm, uiParams);

// 接收方
UIParams uiParams = userData as UIParams;
var value = uiParams.Get("Key") as MyType;
```

### 3. GF_X 事件系统

```csharp
// 订阅
GFBuiltin.Event.Subscribe(EventId, OnEvent);

// 触发
GFBuiltin.Event.Fire(this, eventArgs);

// 取消订阅
GFBuiltin.Event.Unsubscribe(EventId, OnEvent);
```
