## 📋 需要手动完成的步骤

### 步骤 1: 重新生成 UIViews 枚举
```
Unity 菜单 → AAAGame → Generate DataTables
```
这将根据 UITable.txt 生成包含 `UIViews.CardUIForm` 的枚举。

### 步骤 2: 配置预制体

#### CardUIForm.prefab
位置：`Assets/AAAGame/Prefabs/UI/CardUIForm.prefab`

必需字段：
- `handCardContainer`: Transform - 手牌容器
- `trashBinArea`: Transform - 垃圾桶区域
- `handCardItemPrefab`: GameObject - HandCardItem 预制体引用
- `populationView`: PopulationView - 人口显示组件

#### HandCardItem.prefab
位置：`Assets/AAAGame/Scripts/Card/HandCardItem.prefab`

必需字段：
- `cardImage`: Image - 卡面图片
- `populationText`: TextMeshProUGUI - 人口消耗
- `soldierCountText`: TextMeshProUGUI - 士兵数量
- `canvasGroup`: CanvasGroup - 透明度控制

### 步骤 3: 配置场景

在 Game 场景中创建：
1. `ValidArea` GameObject - 可放置区域
2. `InvalidArea` GameObject - 禁止放置区域

### 步骤 4: 配置卡牌数据

将 CardData ScriptableObject 放置在：
```
Resources/CardData/
```

或修改 `CardGameProcedure.LoadCardPool()` 方法以适配你的数据加载方式。

### 步骤 5: 启动测试

方式 1 - 使用快速启动工具：
```
Unity 菜单 → AAAGame → Card → Quick Start Card Game
```

方式 2 - 手动设置：
1. 打开 Launch 场景
2. 运行游戏
3. 观察流程：Launch → Game → CardUIForm 显示

### 步骤 6: 配置检查

使用检查工具：
```
Unity 菜单 → AAAGame → Card → Check Card System Setup
```

## 🔧 对象池配置

在 `CardUIForm.CreateHandCardItem()` 中，对象池参数：

```csharp
SpawnItem<HandCardItemObject>(
    handCardItemPrefab,      // 预制体
    handCardContainer,       // 父节点
    autoReleaseInterval: 5f, // 自动释放间隔（秒）
    capacity: 50,            // 对象池容量
    expireTime: 50           // 过期时间（秒）
)
```

可根据需要调整这些参数。

## 📊 架构优势

### 使用 GF_X 对象池
1. **性能优化** - 避免频繁 Instantiate/Destroy
2. **内存管理** - 自动回收和复用
3. **配置灵活** - 可调整容量、过期时间
4. **框架统一** - 符合 GF_X 规范

### 使用 Procedure

2. **生命周期** - OnEnter/OnUpdate/OnLeave 明确
3. **状态切换** - 方便在不同模式间切换
4. **资源管理** - 流程结束时自动清理

### 使用 UIFormBase
1. **UI 动画** - 内置打开/关闭动画
2. **事件系统** - 统一的 UI 事件处理
3. **多语言** - 自动多语言支持
4. **子 UI** - 支持子界面管理

## 🐛 常见问题

### Q1: UIViews.CardUIForm 不存在
**A:** 执行 `AAAGame → Generate DataTables` 重新生成枚举

### Q2: 手牌创建失败
**A:** 检查 `handCardItemPrefab` 是否正确赋值

### Q3: 卡牌拖拽无效
**A:** 检查场景中是否有 EventSystem

### Q4: 人口显示不更新
**A:** 检查 PopulationView 组件是否正确配置

### Q5: 卡牌放置无效
**A:** 检查 ValidArea 和 InvalidArea 是否存在
