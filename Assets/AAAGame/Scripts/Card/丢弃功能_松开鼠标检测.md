# 丢弃功能 - 松开鼠标时检测

## ✅ 已恢复原逻辑

已经恢复为**松开鼠标时检测**丢弃功能。

---

## 🎯 工作流程

### 1. 开始拖拽（OnBeginDrag）
- 显示垃圾桶
- 开始放置流程

### 2. 拖拽过程中（OnCardDragging）
- 更新垃圾桶提示（高亮显示）
- 更新区域材质效果
- **不进行丢弃检测**

### 3. 松开鼠标（OnCardEndDrag）
- **检测鼠标位置**
- 如果在垃圾桶区域 → 丢弃卡牌
- 如果在手牌区域 → 返回原位
- 否则 → 尝试放置到场景

---

## 🔄 代码逻辑

### OnCardDragging（拖拽中）

```csharp
public void OnCardDragging(HandCardItem cardItem, Vector2 screenPosition)
{
    // 更新垃圾桶提示
    UpdateTrashBinHint(screenPosition);
    
    // 更新区域材质效果
    UpdateAreaMaterialEffect(screenPosition);
    
    // 不进行丢弃检测
}
```

### OnCardEndDrag（松开鼠标）

```csharp
public bool OnCardEndDrag(HandCardItem cardItem, Vector2 screenPosition)
{
    // 隐藏垃圾桶和效果
    
    // 1. 优先检查是否在垃圾桶区域
    if (IsInTrashBin(screenPosition))
    {
        m_CardSystemController.DiscardCard(cardItem.GetCardModel());
        return true; // 丢弃成功
    }
    
    // 2. 检查是否拖回手牌区域
    if (IsOverHandCardArea(screenPosition))
    {
        return false; // 返回原位
    }
    
    // 3. 尝试放置到场景
    return m_CardSystemController.ConfirmPlacement(cardItem.GetCardModel());
}
```

## 🐛 如果仍然不工作

### 问题：IsInTrashBin 返回 False

**查看日志**：
```
[CardUI] IsInTrashBin:
  Mouse: (1656.6, 432.0)
  TrashBin Screen Bounds: X(1438.0 - 1862.0), Y(353.5 - 488.0)
  Method2 (Manual Calculation): False  ← 这里是 False
```

**原因**：鼠标位置不在垃圾桶范围内

**解决方案**：

#### 方案 1：调整垃圾桶位置

1. 打开 `CardUIForm.prefab`
2. 选中 `TrashBin` 对象
3. 调整位置到你拖拽卡牌的位置
4. 例如：如果鼠标在 (1656, 432)，垃圾桶应该在这个位置附近

#### 方案 2：增大垃圾桶尺寸

1. 选中 `TrashBin` 对象
2. 增大 Width 和 Height
3. 例如：Width: 200, Height: 200

#### 方案 3：检查 Canvas 设置

确认 Canvas 设置：
- Render Mode: Screen Space - Overlay（推荐）
- 或 Screen Space - Camera（需要设置 Render Camera）

## 📊 坐标对比

从日志中可以看到：

```
Mouse: (1656.6, 432.0)
TrashBin Screen Bounds: X(1438.0 - 1862.0), Y(353.5 - 488.0)
```

**判断**：
- X 坐标：1656.6 在 1438.0 - 1862.0 之间 ✅
- Y 坐标：432.0 在 353.5 - 488.0 之间 ✅
- 结果：应该返回 True

如果返回 False，说明坐标计算有问题。

## 🔧 临时解决方案

如果坐标检测一直有问题，可以临时使用距离检测：

```csharp
private bool IsInTrashBin(Vector2 screenPosition)
{
    if (m_TrashBinRect == null) return false;
    
    // 获取垃圾桶中心的屏幕坐标
    Camera uiCamera = GFBuiltin.UICamera;
    Vector2 trashBinCenter;
    
    if (uiCamera != null)
    {
        trashBinCenter = uiCamera.WorldToScreenPoint(m_TrashBinRect.position);
    }
    else
    {
        trashBinCenter = m_TrashBinRect.position;
    }
    
    // 计算距离
    float distance = Vector2.Distance(screenPosition, trashBinCenter);
    float threshold = 150f; // 检测半径
    
    bool isNear = distance < threshold;
    Log.Info($"[CardUI] Distance to trash bin: {distance:F1}, Threshold: {threshold}, Near: {isNear}");
    
    return isNear;
}
```
