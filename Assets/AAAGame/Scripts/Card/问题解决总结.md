### 2. ⚠️ DataTable 生成错误（待用户操作）

**问题**: 
```
GameFrameworkException: Name row '1' >= raw row count '1' is not allow.
```

**原因**: 
- Excel 临时锁定文件残留
- 某些 DataTable 文件格式可能不正确

**已采取的措施**:
1. ✅ 删除了临时锁定文件：
   - `~$DeviceTable.xlsx`
   - `~$TechNodeTable.xlsx`
2. ✅ 创建了清理脚本：`CleanExcelLocks.ps1`
3. ✅ 创建了详细的修复指南：`DataTable错误修复指南.md`

**用户需要做的**:

#### 方法 1: 使用清理脚本（推荐）

在项目根目录打开 PowerShell：

```powershell
cd GF_X
.\CleanExcelLocks.ps1
```

然后在 Unity 中：
```
菜单 → AAAGame → Generate DataTables
```

#### 方法 2: 手动操作

1. **关闭所有 Excel 窗口**
2. **在 Unity 中重新生成**：
   ```
   菜单 → AAAGame → Generate DataTables
   ```

#### 如果问题仍然存在

请查看详细指南：`DataTable错误修复指南.md`
