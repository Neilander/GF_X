## 📋 可能的问题

### 问题 1：TrashBin 未配置

**日志**：
```
[CardUI] TrashBin is not configured in CardUIForm prefab.
```

**解决方案**：
1. 打开 `CardUIForm.prefab`
2. 创建 `TrashBin` 对象（UI GameObject）
3. 配置 CardUIForm 组件的 `Trash Bin` 字段
4. 保存预制体

---

### 问题 2：垃圾桶位置不对

**日志**：
```
[CardUI] Is in trash bin: false
```

**解决方案**：
1. 打开 `CardUIForm.prefab`
2. 调整 `TrashBin` 位置到屏幕可见区域（建议右下角）
3. 设置合适的大小（建议 100x100）

---

### 问题 3：手牌区域太大

**日志**：
```
[CardUI] Is over hand area: true
```

**解决方案**：
1. 打开 `CardUIForm.prefab`
2. 调整 `HandCardArea` 大小
3. 确保只占屏幕底部，不覆盖整个屏幕
4. 推荐设置：
   - Anchor: Bottom (Stretch)
   - Height: 250

---

## 🎯 快速配置

### 创建垃圾桶对象

在 `CardUIForm.prefab` 中：

```
CardUIForm
└── TrashBin (UI GameObject)
    ├── RectTransform
    │   ├── Anchor: Bottom Right
    │   ├── Position: (-100, 100, 0)
    │   ├── Width: 100
    │   └── Height: 100
    └── Image (垃圾桶图标)
```

配置 CardUIForm 组件：
- `Trash Bin` → 拖入 TrashBin 对象
