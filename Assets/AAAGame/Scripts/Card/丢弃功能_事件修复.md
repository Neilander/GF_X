# 丢弃功能 - 事件修复

## ✅ 问题已修复

**问题**：卡牌拖到丢弃区域后，没有消失，而是固定在丢弃区域且仍然可以拖动。

**原因**：`CardSystemController.DiscardCard()` 方法只触发了 C# 事件，没有触发 GameFramework 事件系统，导致 `CardUIForm` 无法收到丢弃事件，卡牌 UI 没有被移除。

---

## 🔧 修复内容

### 修改了 `CardSystemController.DiscardCard()` 方法

**之前**：
```csharp
public bool DiscardCard(CardModel cardModel)
{
    // 从手牌移除
    m_HandCardController.RemoveCard(cardModel);
    
    // 只触发 C# 事件
    OnCardDiscarded?.Invoke(cardModel);
    
    return true;
}
```

**现在**：
```csharp
public bool DiscardCard(CardModel cardModel)
{
    // 从手牌移除
    m_HandCardController.RemoveCard(cardModel);
    
    // 触发 C# 事件
    OnCardDiscarded?.Invoke(cardModel);
    
    // 触发 GameFramework 事件系统 ✨
    GameFramework.Event.GameEventArgs e = CardDiscardedEventArgs.Create(cardModel);
    UnityGameFramework.Runtime.GFBuiltin.Event.Fire(this, e);
    GameFramework.ReferencePool.Release(e);
    
    Debug.Log($"[Card] Card discarded: {cardModel.GetCardName()}");
    return true;
}
```

## 🔄 事件流程

### 1. 松开鼠标（OnCardEndDrag）
```csharp
if (IsInTrashBin(screenPosition))
{
    // 调用 DiscardCard
    m_CardSystemController.DiscardCard(cardItem.GetCardModel());
    return true;
}
```

### 2. DiscardCard 方法
```csharp
// 从手牌数据模型中移除
m_HandCardController.RemoveCard(cardModel);

// 触发 GameFramework 事件
GFBuiltin.Event.Fire(this, CardDiscardedEventArgs.Create(cardModel));
```

### 3. CardUIForm 收到事件
```csharp
private void OnCardDiscarded(object sender, GameEventArgs e)
{
    CardDiscardedEventArgs ne = (CardDiscardedEventArgs)e;
    // 移除卡牌 UI
    RemoveHandCardItem(ne.CardModel);
}
```

### 4. RemoveHandCardItem
```csharp
private void RemoveHandCardItem(CardModel cardModel)
{
    // 找到对应的 UI 对象
    UIItemObject itemToRemove = ...;
    
    // 从列表中移除
    m_HandCardItemObjects.Remove(itemToRemove);
    
    // 回收到对象池（销毁 UI）
    UnspawnItem<UIItemObject>(handCardItemPrefab, itemToRemove);
}
```

## 🐛 如果仍然不工作

### 检查 1：事件是否触发

查看 Console 是否有：
```
[Card] Card discarded: 步兵
```

如果没有，说明 `DiscardCard` 方法没有被调用。

### 检查 2：事件是否被订阅

确认 `CardUIForm.OnInit()` 中有：
```csharp
GFBuiltin.Event.Subscribe(CardDiscardedEventArgs.EventId, OnCardDiscarded);
```

### 检查 3：RemoveHandCardItem 是否执行

在 `RemoveHandCardItem` 方法中添加日志：
```csharp
private void RemoveHandCardItem(CardModel cardModel)
{
    Log.Info($"[CardUI] Removing hand card item: {cardModel.GetCardName()}");
    // ... 移除逻辑
}
```
