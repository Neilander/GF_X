# 小地图系统更新说明

## 🎯 新功能

### 1. 区分士兵和建筑显示
- **士兵**：显示为正方形小点，颜色可配置（玩家蓝色，敌方红色）
- **建筑**：显示为自定义图标预制体，可为不同建筑配置不同图标

### 2. 摄像机视野框
- 在小地图上显示一个方框，表示玩家摄像机当前能看到的区域
- 方框随摄像机移动而移动
- 方框随摄像机缩放而缩放

### 3. 比例尺显示
- 在小地图下方显示水平比例尺（地图宽度）
- 在小地图左侧显示垂直比例尺（地图高度）
- 自动根据地图范围计算

### 4. 实时更新
- 所有单位（士兵/建筑）的位置实时跟随世界坐标更新
- 单位销毁时，小地图上的图标自动消失

## 📋 使用方法

### 1. 场景设置

在 Unity 场景中创建 MinimapManager：

```
1. 创建空 GameObject，命名为 "MinimapManager"
2. 添加 MinimapManager 组件
3. 配置参数：
   - World Min X/Max X: 地图 X 轴范围（例如 -50 到 50）
   - World Min Z/Max Z: 地图 Z 轴范围（例如 -50 到 50）
   - Player Soldier Color: 玩家士兵颜色（蓝色）
   - Enemy Soldier Color: 敌方士兵颜色（红色）
   - Soldier Dot Size: 士兵点大小（5）
   - Building Icon Size: 建筑图标大小（15）
```

### 2. UI 设置

#### 2.1 创建小地图面板

```
1. 在 Canvas 下创建 Image，命名为 "MinimapPanel"
2. 设置为正方形（例如 200x200）
3. 设置背景色为深色（黑色半透明）
4. 设置 Anchor 到右下角
```

#### 2.2 创建士兵点预制体

```
1. 创建 Image，命名为 "SoldierDot"
2. 设置大小为 5x5 像素
3. 设置为正方形（不需要圆形）
4. 保存为 Prefab
```

#### 2.3 创建建筑图标预制体

为每种建筑类型创建图标预制体：

```
1. 创建 Image，命名为 "BuildingIcon_XXX"（例如 BuildingIcon_Barracks）
2. 设置大小为 15x15 像素
3. 设置图标 Sprite（例如兵营图标）
4. 保存为 Prefab
5. 重复以上步骤为其他建筑创建图标
```

#### 2.4 创建摄像机视野框

```
1. 在 MinimapPanel 下创建 Image，命名为 "CameraViewFrame"
2. 设置为透明背景，白色边框
3. 设置 Anchor 为 center
4. 初始大小可以设置为 50x50（运行时会自动调整）
```

#### 2.5 创建比例尺文本

```
1. 在 MinimapPanel 下方创建 TextMeshProUGUI，命名为 "ScaleTextHorizontal"
2. 在 MinimapPanel 左侧创建 TextMeshProUGUI，命名为 "ScaleTextVertical"
3. 设置字体大小和颜色
```

#### 2.6 配置 MinimapUI 组件

```
在 MinimapPanel 上添加 MinimapUI 组件，配置：
- Minimap Container: 拖入 MinimapPanel 的 RectTransform
- Soldier Dot Prefab: 拖入 SoldierDot Prefab
- Camera View Frame: 拖入 CameraViewFrame 的 RectTransform
- Scale Text Horizontal: 拖入水平比例尺文本
- Scale Text Vertical: 拖入垂直比例尺文本
- Minimap Size: 200（与面板大小一致）
- Main Camera: 拖入主摄像机（或留空自动查找）
- Building Icon Mappings: 添加建筑图标映射
  - Icon Name: "Barracks"（与代码中的名称对应）
  - Prefab: 拖入 BuildingIcon_Barracks Prefab
  - 重复添加其他建筑图标
```

### 3. 单位集成

#### 3.1 士兵集成

在士兵 Entity 中：

```csharp
using AAAGame.MiniMap;

public class SoldierEntity : EntityLogic
{
    private MinimapReportComponent minimapReport;
    
    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        
        // 添加小地图报告组件（士兵）
        minimapReport = gameObject.AddComponent<MinimapReportComponent>();
        minimapReport.Initialize(Side); // 使用单位的 Side 属性
    }
    
    protected override void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(elapseSeconds, realElapseSeconds);
        
        // 每帧更新位置
        minimapReport?.Tick();
    }
}
```

#### 3.2 建筑集成

在建筑 Entity 中：

```csharp
using AAAGame.MiniMap;

public class BuildingEntity : EntityLogic
{
    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        
        // 添加小地图报告组件（建筑）
        minimapReport = gameObject.AddComponent<MinimapReportComponent>();
        
        // 根据建筑类型指定图标名称
        string iconName = GetBuildingIconName(); // 例如 "Barracks", "TownHall" 等
        minimapReport.Initialize(Side, MinimapUnitType.Building, iconName);
    }
    
    protected override void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(elapseSeconds, realElapseSeconds);
        
        // 建筑通常不移动，但仍需要 Tick（用于势力变化等）
        minimapReport?.Tick();
    }
    
    private string GetBuildingIconName()
    {
        // 根据建筑类型返回对应的图标名称
        // 这个名称必须与 MinimapUI 中配置的 Building Icon Mappings 的 Icon Name 一致
        switch (buildingType)
        {
            case BuildingType.Barracks:
                return "Barracks";
            case BuildingType.TownHall:
                return "TownHall";
            case BuildingType.Farm:
                return "Farm";
            default:
                return "DefaultBuilding";
        }
    }
}
```

## 📊 数据流

```
单位 Update
    ↓
MinimapReportComponent.Tick()
    ↓
MinimapManager.UpdateUnit(位置, 势力)
    ↓
MinimapManager.LateUpdate()
    ↓
广播 MinimapUpdateEventArgs
    ↓
MinimapUI.OnMinimapUpdate()
    ↓
更新士兵点/建筑图标位置
    ↓
MinimapUI.OnUpdate()
    ↓
更新摄像机视野框
```

## 🔧 配置建议

### 地图范围配置

根据你的场景大小配置地图范围：

```
小型地图（50x50）：
- World Min X: -25, World Max X: 25
- World Min Z: -25, World Max Z: 25

中型地图（100x100）：
- World Min X: -50, World Max X: 50
- World Min Z: -50, World Max Z: 50

大型地图（200x200）：
- World Min X: -100, World Max X: 100
- World Min Z: -100, World Max Z: 100
```

### 图标大小建议

```
- 士兵点：5x5 像素（小而密集）
- 建筑图标：15x15 像素（大而显眼）
- 小地图面板：200x200 像素（正方形）
```

### 颜色建议

```
- 玩家士兵：蓝色 (0.2, 0.5, 1)
- 敌方士兵：红色 (1, 0, 0)
- 摄像机视野框：白色边框，透明填充
- 小地图背景：黑色半透明 (0, 0, 0, 0.7)
```

## ⚠️ 注意事项

1. **地图范围必须正确**：确保 WorldMinX/MaxX/MinZ/MaxZ 与场景实际大小一致
2. **建筑图标名称必须匹配**：代码中的 iconPrefabName 必须与 UI 配置的 Icon Name 一致
3. **摄像机引用**：如果主摄像机不是 Camera.main，需要手动拖入
4. **单位必须调用 Tick()**：否则位置不会更新
5. **比例尺文本**：需要使用 TextMeshProUGUI，不是普通 Text

## 🐛 常见问题

### Q: 小地图上没有显示单位？
A: 检查：
1. MinimapManager 是否在场景中
2. 单位是否调用了 Initialize()
3. 单位是否每帧调用了 Tick()
4. MinimapUI 是否已打开

### Q: 建筑图标不显示？
A: 检查：
1. iconPrefabName 是否与 UI 配置的 Icon Name 一致
2. Building Icon Mappings 是否正确配置
3. 建筑预制体是否正确拖入

### Q: 摄像机视野框不动？
A: 检查：
1. Main Camera 是否正确引用
2. Camera View Frame 是否正确拖入
3. 摄像机是否在移动

### Q: 比例尺不显示？
A: 检查：
1. Scale Text Horizontal/Vertical 是否正确拖入
2. 是否使用了 TextMeshProUGUI（不是普通 Text）
3. 文本颜色是否与背景区分

### Q: 单位位置不准确？
A: 检查：
1. 地图范围配置是否正确
2. Minimap Size 是否与面板大小一致
3. 单位的世界坐标是否在地图范围内
