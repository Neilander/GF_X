# 摄像机视野框配置指南

## 问题诊断

从日志可以看到，摄像机视野框**代码层面已经正常工作**：
```
[MinimapUI] Camera view frame updated: pos=(2.19, 12.08), size=(134.77, 95.78), active=True
```

但是**视觉上看不到**，这是 Unity UI 配置问题，不是代码问题。

## 解决方案

### 方案 1: 使用新的 MinimapCameraFrame 组件（推荐）⭐⭐⭐⭐⭐

这是最简单可靠的方法，新组件会自动配置所有必要的设置。

#### 步骤 1: 添加组件
1. 在 Unity Hierarchy 中找到 CameraViewFrame 对象
2. 在 Inspector 中点击 "Add Component"
3. 搜索并添加 `MinimapCameraFrame` 组件

#### 步骤 2: 配置 MinimapUI
1. 选择 MinimapUI 对象
2. 在 Inspector 中找到 `MinimapUI` 组件
3. 将 CameraViewFrame 对象拖到 `Camera Frame` 字段（新字段）

#### 步骤 3: 运行测试
运行游戏，你应该看到：
- 白色边框的视野框
- 半透明的填充
- 随摄像机移动和缩放

#### MinimapCameraFrame 组件参数说明
```
Frame Color: 边框颜色（默认白色）
Frame Alpha: 边框透明度（默认 1.0）
Border Width: 边框宽度（默认 2 像素）
Clamp To Bounds: 是否限制在小地图边界内（默认 true）
Minimap Bounds: 小地图边界（自动检测父对象）
```

### 方案 2: 手动修复现有配置（如果不想用新组件）

如果你想继续使用旧的 RectTransform 方式，需要手动检查以下配置：

#### 检查 1: Image 组件配置
选择 CameraViewFrame 对象，在 Inspector 中检查 Image 组件：

**必须配置**:
```
Image Component:
✅ Enabled: 勾选
✅ Color: 白色，Alpha = 255（不是 0！）
✅ Material: None (Default)
❌ Raycast Target: 不勾选（可选）
```

**常见错误**:
- ❌ Alpha = 0（完全透明，看不见）
- ❌ Color 是黑色或与背景相同
- ❌ Image 组件被禁用

#### 检查 2: RectTransform 配置
```
RectTransform:
✅ Anchors: Min(0.5, 0.5), Max(0.5, 0.5) - 中心锚点
✅ Pivot: (0.5, 0.5) - 中心轴点
✅ Scale: (1, 1, 1) - 不缩放
✅ Rotation: (0, 0, 0) - 不旋转
```

#### 检查 3: 层级顺序
在 Hierarchy 中：
```
MinimapContainer
  ├─ MinimapBackground (背景)
  ├─ SoldierDot1 (士兵点)
  ├─ SoldierDot2
  └─ CameraViewFrame (应该在最后！) ⭐
```

**如果 CameraViewFrame 不在最后**:
- 右键 CameraViewFrame
- 选择 "Move to Bottom" 或手动拖到最后

#### 检查 4: Canvas 设置
选择最顶层的 Canvas，检查：
```
Canvas:
✅ Render Mode: Screen Space - Overlay 或 Camera
✅ Sort Order: 足够高（如果有多个 Canvas）
```

#### 检查 5: 添加 Outline 组件（推荐）
为了更明显，可以添加白色边框：

1. 选择 CameraViewFrame
2. Add Component → UI → Effects → Outline
3. 配置：
   ```
   Outline:
   - Effect Color: 白色 (255, 255, 255, 255)
   - Effect Distance: (2, 2) 或 (3, 3)
   - Use Graphic Alpha: 不勾选
   ```

### 方案 3: 创建测试用的简单视野框

如果以上都不行，创建一个新的简单视野框来测试：

#### 步骤 1: 创建新对象
1. 在 minimapContainer 下右键 → UI → Image
2. 重命名为 "TestCameraFrame"

#### 步骤 2: 配置
```
RectTransform:
- Anchors: center (0.5, 0.5)
- Pivot: center (0.5, 0.5)
- Position: (0, 0, 0)
- Size: (100, 100) - 固定大小测试

Image:
- Color: 红色 (255, 0, 0, 255) - 用红色更明显
- Sprite: None
```

#### 步骤 3: 测试
运行游戏，如果能看到红色方框，说明 UI 系统正常，问题在原来的 CameraViewFrame 配置。

## 推荐配置流程

### 使用新组件（最简单）

1. **删除旧的 CameraViewFrame**（如果有问题）
2. **创建新的 Image 对象**:
   ```
   Hierarchy: minimapContainer → 右键 → UI → Image
   重命名: CameraViewFrame
   ```

3. **添加 MinimapCameraFrame 组件**:
   ```
   Inspector → Add Component → MinimapCameraFrame
   ```

4. **配置 MinimapUI**:
   ```
   将 CameraViewFrame 拖到 MinimapUI 的 Camera Frame 字段
   ```

5. **运行测试**

## 常见问题

### Q: 日志显示 active=True，但看不到视野框
**A**: Image 组件的 Alpha 可能是 0，或者颜色与背景相同。检查 Image 组件的 Color 设置。

### Q: 视野框一闪而过
**A**: 可能被其他 UI 遮挡。检查 Hierarchy 层级顺序，确保 CameraViewFrame 在最后。

### Q: 视野框位置不对
**A**: 检查 RectTransform 的 Anchors 和 Pivot 是否都设置为 center (0.5, 0.5)。

### Q: 视野框太大或太小
**A**: 检查 MinimapManager 的 WorldMinX/MaxX/MinZ/MaxZ 配置是否正确。

### Q: 使用新组件后还是看不到
**A**: 
1. 检查 CameraViewFrame 对象是否激活（勾选）
2. 检查父对象 minimapContainer 是否激活
3. 在 Scene 视图中选择 CameraViewFrame，看是否能看到（可能在 Game 视图外）

## 调试技巧

### 技巧 1: 使用 Scene 视图
1. 运行游戏
2. 在 Hierarchy 中选择 CameraViewFrame
3. 在 Scene 视图中查看（不是 Game 视图）
4. 如果能在 Scene 视图看到，但 Game 视图看不到，说明是渲染顺序问题

### 技巧 2: 临时改成红色
1. 暂停游戏
2. 选择 CameraViewFrame
3. 将 Image Color 改成红色 (255, 0, 0, 255)
4. 继续游戏
5. 如果能看到红色，说明配置正确，只是白色不明显

### 技巧 3: 检查 Canvas Scaler
如果小地图在不同分辨率下显示异常：
1. 选择 Canvas
2. 检查 Canvas Scaler 组件
3. 确保 UI Scale Mode 设置正确

## 总结

**最简单的解决方案**: 使用新的 `MinimapCameraFrame` 组件，它会自动处理所有配置问题。

**如果坚持用旧方式**: 重点检查 Image 组件的 Color Alpha 值，这是最常见的问题。
