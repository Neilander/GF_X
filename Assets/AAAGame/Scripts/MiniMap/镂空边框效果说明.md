# 摄像机视野框镂空边框效果

## 更新内容

修改了 `MinimapCameraFrame.cs`，现在支持**镂空边框效果**（只有边框，中间完全透明）。

## 新的参数

### Border Color（边框颜色）
- 类型：Color
- 默认：白色
- 说明：**只影响边框颜色**，不影响中间填充

### Border Alpha（边框透明度）
- 类型：float (0-1)
- 默认：1.0（完全不透明）
- 说明：边框的透明度

### Border Width（边框宽度）
- 类型：float
- 默认：2
- 说明：边框的像素宽度

### Hollow Center（中间镂空）⭐
- 类型：bool
- 默认：true（勾选）
- 说明：
  - ✅ **勾选**：中间完全透明（镂空效果）- **推荐**
  - ❌ 不勾选：中间半透明填充

## 使用方法

### 方法 1: 在 Inspector 中配置（推荐）

1. 选择 CameraViewFrame 对象
2. 找到 `MinimapCameraFrame` 组件
3. 配置参数：
   ```
   Border Color: 白色 (255, 255, 255)
   Border Alpha: 1.0
   Border Width: 2
   Hollow Center: ✅ 勾选（镂空效果）
   ```

### 方法 2: 通过代码控制

```csharp
MinimapCameraFrame frame = GetComponent<MinimapCameraFrame>();

// 设置边框颜色（不影响中间）
frame.SetBorderColor(Color.white);

// 设置边框透明度
frame.SetBorderAlpha(1.0f);

// 设置边框宽度
frame.SetBorderWidth(3f);

// 设置是否镂空
frame.SetHollow(true); // true = 镂空，false = 半透明填充
```

## 技术细节

### Image 组件
- **镂空模式**: `image.color = Color.clear` (完全透明)
- **填充模式**: `image.color = Color(r, g, b, 0.2)` (半透明)

### Outline 组件
- 独立控制边框颜色和透明度
- `useGraphicAlpha = false` - 不受 Image Alpha 影响
- 边框颜色由 `borderColor` 和 `borderAlpha` 控制

### 关键代码
```csharp
if (hollowCenter)
{
    // 镂空：中间完全透明
    image.color = Color.clear;
}
else
{
    // 半透明填充
    Color color = borderColor;
    color.a = 0.2f;
    image.color = color;
}

// 边框独立控制
outline.effectColor = new Color(borderColor.r, borderColor.g, borderColor.b, borderAlpha);
outline.useGraphicAlpha = false; // 关键！不使用 Image 的 Alpha
```

## 优势

### 镂空模式的优势
1. ✅ **清晰可见** - 只有边框，不遮挡地图内容
2. ✅ **性能更好** - 不需要渲染半透明填充
3. ✅ **更专业** - 类似帝国时代 4 的效果
4. ✅ **独立控制** - 边框颜色和中间填充完全独立

### 与旧版本的区别
- ❌ 旧版本：`frameColor` 同时影响边框和填充
- ✅ 新版本：`borderColor` 只影响边框，中间可以完全透明

## 调试技巧

### 如果看不到边框
1. 检查 `Border Alpha` 是否为 0
2. 检查 `Border Width` 是否太小
3. 检查 `Border Color` 是否与背景相同
4. 尝试改成红色测试：`Border Color = (255, 0, 0)`

### 如果边框太粗
1. 减小 `Border Width`（推荐 2-3）

### 如果边框太细
1. 增加 `Border Width`（推荐 3-4）

### 如果中间有填充（不想要）
1. 确保 `Hollow Center` 已勾选
2. 或者调用 `frame.SetHollow(true)`
