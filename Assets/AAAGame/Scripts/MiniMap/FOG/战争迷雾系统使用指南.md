## 系统概述

### 功能特性
✅ **基于网格的战争迷雾系统**
- 三种迷雾状态：Hidden（未探索）、Explored（已探索）、Visible（可见）
- 支持多玩家和联盟（使用位掩码）
- 地形高度遮挡视野
- 平滑颜色过渡
- 高性能（支持50+单位 @ 60FPS）

✅ **符合 GF_X 框架规范**
- 继承 `GameFrameworkComponent`
- 使用 GF_X 日志系统
- 事件驱动架构

✅ **灵活的渲染方式**
- 基于 Texture2D 的实时渲染
- 可配置的模糊效果
- 支持自定义颜色

## 快速开始

### 步骤 1：添加 FogOfWarManager 到场景

1. 找到场景中的 **Game Framework** 对象（或创建一个空对象）
2. 添加 `FogOfWarManager` 组件
3. 配置网格参数：

```
Grid Width: 100
Grid Height: 100
World Min X: -50
World Max X: 50
World Min Z: -50
World Max Z: 50
Update Interval: 0.1
```

### 步骤 2：创建迷雾渲染 UI

1. 在 Canvas 下创建一个 **RawImage**（命名为 FogOfWarOverlay）
2. 设置为全屏：
   - Anchor: Stretch (左上角到右下角)
   - Left/Right/Top/Bottom: 0
3. 添加 `FogOfWarRenderer` 组件
4. 将 `FogOfWarManager` 拖到 Fog Manager 字段

### 步骤 3：为单位添加视野

在士兵/建筑预制体上添加 `FogOfWarVisionComponent`：

```csharp
// 配置参数
Player Mask: 1          // 玩家0
Vision Range: 10        // 视野范围10米
Auto Register: ✓        // 自动注册
Use Terrain Height: ✓   // 使用地形高度
```

### 步骤 4：控制单位可见性（可选）

如果要让敌方单位在迷雾中隐藏，添加 `FogOfWarUnitVisibility`：

```csharp
Owner Player Mask: 2        // 敌方玩家
Check Player Mask: 1        // 检查玩家0的视野
Hide When Not Visible: ✓    // 不可见时隐藏
Hide Method: Layer          // 使用 Layer 方式（推荐）
```

## 核心组件

### 1. FogOfWarManager
**全局管理器，继承 GameFrameworkComponent**

主要功能：
- 管理所有单位视野
- 计算迷雾状态
- 提供查询接口

```csharp
// 获取管理器
var fogManager = GameEntry.GetComponent<FogOfWarManager>();

// 注册视野
int visionId = fogManager.RegisterVision(
    playerMask: 1,           // 玩家掩码
    visionRange: 10f,        // 视野范围
    worldPosition: position, // 世界坐标
    terrainHeight: 0         // 地形高度
);

// 更新视野
fogManager.UpdateVision(visionId, newPosition, newHeight);

// 注销视野
fogManager.UnregisterVision(visionId);

// 查询位置是否可见
bool isVisible = fogManager.IsPositionVisible(position, playerMask: 1);

// 查询位置是否被探索过
bool wasExplored = fogManager.WasPositionExplored(position, playerMask: 1);

// 获取迷雾状态
FogState state = fogManager.GetFogState(position, playerMask: 1);
```

### 2. FogOfWarVisionComponent
**单位视野组件，挂在提供视野的单位上**

```csharp
// 手动注册/注销
visionComponent.RegisterVision();
visionComponent.UnregisterVision();

// 设置玩家掩码
visionComponent.SetPlayerMask(1);

// 设置视野范围
visionComponent.SetVisionRange(15f);

// 手动更新（如果禁用了自动更新）
visionComponent.Tick();
```

### 3. FogOfWarRenderer
**迷雾渲染器，负责将迷雾绘制到屏幕**

```csharp
// 强制刷新
renderer.ForceRefresh();

// 切换显示的玩家
renderer.SetPlayerMask(2); // 显示玩家1的视野
```

### 4. FogOfWarUnitVisibility
**单位可见性控制，根据迷雾自动显示/隐藏单位**

```csharp
// 强制检查可见性
visibility.ForceCheckVisibility();

// 设置检查的玩家
visibility.SetCheckPlayerMask(1);

// 获取当前可见性
bool isVisible = visibility.IsCurrentlyVisible();
```

## 配置说明

### FogOfWarConfig 参数详解

#### 网格范围
```csharp
World Min X/Z: -50    // 世界坐标最小值
World Max X/Z: 50     // 世界坐标最大值
Grid Width: 100       // 网格宽度（格子数）
Grid Height: 100      // 网格高度（格子数）
```

**建议：**
- 网格越大，精度越高，但性能消耗越大
- 推荐：100x100 到 200x200
- 移动设备：50x50 到 100x100

#### 更新设置
```csharp
Update Interval: 0.1  // 更新间隔（秒）
                      // 0 = 每帧更新
                      // 0.1 = 每0.1秒更新一次（推荐）
```

#### 渲染设置
```csharp
Enable Blur: true         // 启用模糊效果
Blur Iterations: 2        // 模糊迭代次数（0-5）

Hidden Color: 黑色        // 未探索区域颜色
Explored Color: 灰色      // 已探索区域颜色
Visible Color: 透明       // 可见区域颜色

Enable Easing: true       // 启用颜色过渡
Easing Speed: 5           // 过渡速度
```

#### 地形遮挡
```csharp
Enable Terrain Blocking: true     // 启用地形遮挡
Height Block Threshold: 2         // 高度差阈值
```

## 使用示例

### 示例 1：士兵单位集成

```csharp
using AAAGame.MiniMap.FOG;

public class SoldierEntity : EntityLogic
{
    private FogOfWarVisionComponent visionComponent;
    
    protected override void OnShow(object userData)
    {
        base.OnShow(userData);
        
        // 添加视野组件
        visionComponent = gameObject.AddComponent<FogOfWarVisionComponent>();
        visionComponent.SetPlayerMask(GetPlayerMask());
        visionComponent.SetVisionRange(10f);
        visionComponent.RegisterVision();
    }
    
    protected override void OnHide(bool isShutdown, object userData)
    {
        base.OnHide(isShutdown, userData);
        
        // 注销视野
        if (visionComponent != null)
        {
            visionComponent.UnregisterVision();
        }
    }
    
    private int GetPlayerMask()
    {
        // 根据势力返回玩家掩码
        return Side == SideType.PlayerSide ? 1 : 2;
    }
}
```

### 示例 2：建筑视野

```csharp
public class BuildingEntity : EntityLogic
{
    [SerializeField] private float visionRange = 15f;
    
    private FogOfWarVisionComponent visionComponent;
    
    protected override void OnShow(object userData)
    {
        base.OnShow(userData);
        
        // 建筑提供更大的视野
        visionComponent = gameObject.AddComponent<FogOfWarVisionComponent>();
        visionComponent.SetPlayerMask(1); // 玩家0
        visionComponent.SetVisionRange(visionRange);
        visionComponent.RegisterVision();
    }
}
```

### 示例 3：敌方单位隐藏

```csharp
public class EnemyUnit : EntityLogic
{
    private FogOfWarUnitVisibility visibility;
    
    protected override void OnShow(object userData)
    {
        base.OnShow(userData);
        
        // 添加可见性控制
        visibility = gameObject.AddComponent<FogOfWarUnitVisibility>();
        visibility.SetCheckPlayerMask(1); // 检查玩家0的视野
    }
}
```

### 示例 4：多玩家联盟

```csharp
// 玩家0和玩家1组成联盟
int player0 = 1;      // 0001
int player1 = 2;      // 0010
int alliance = 3;     // 0011 (player0 | player1)

// 注册联盟视野
fogManager.RegisterVision(alliance, 10f, position);

// 检查联盟视野
bool visible = fogManager.IsPositionVisible(position, alliance);
```

### 示例 5：切换观察者视角（回放/观战）

```csharp
public class ReplayController : MonoBehaviour
{
    private FogOfWarRenderer fogRenderer;
    
    void Start()
    {
        fogRenderer = FindObjectOfType<FogOfWarRenderer>();
    }
    
    // 切换到玩家0视角
    public void ViewPlayer0()
    {
        fogRenderer.SetPlayerMask(1);
    }
    
    // 切换到玩家1视角
    public void ViewPlayer1()
    {
        fogRenderer.SetPlayerMask(2);
    }
    
    // 观战模式（看到所有玩家的视野）
    public void ViewAll()
    {
        fogRenderer.SetPlayerMask(3); // 0011 = 玩家0和1
    }
}
```

## 常见问题

### Q1: 迷雾不显示？
**A:** 检查以下几点：
1. FogOfWarManager 是否添加到场景
2. FogOfWarRenderer 是否正确配置
3. RawImage 是否在 Canvas 下
4. 是否有单位注册了视野

### Q2: 单位不隐藏？
**A:** 确保：
1. 添加了 `FogOfWarUnitVisibility` 组件
2. `Owner Player Mask` 和 `Check Player Mask` 设置正确
3. `Hide When Not Visible` 已勾选

### Q3: 性能问题？
**A:** 优化建议：
1. 减小网格大小（50x50）
2. 增加更新间隔（0.2秒）
3. 禁用地形遮挡和模糊效果
4. 使用 Layer 方式隐藏单位

### Q4: 地形遮挡不工作？
**A:** 检查：
1. `Enable Terrain Blocking` 已启用
2. 场景中有 Unity Terrain
3. 单位的 `Use Terrain Height` 已勾选

### Q5: 如何调试？
**A:** 使用以下方法：
```csharp
// 打印视野数量
Debug.Log($"Vision count: {fogManager.GetVisionCount()}");

// 检查位置状态
FogState state = fogManager.GetFogState(position, playerMask: 1);
Debug.Log($"Fog state at {position}: {state}");

// 在 Scene 视图中查看视野范围
// FogOfWarVisionComponent 会绘制黄色线框球体
```

## 技术参考

本系统基于以下技术文章实现：
- [Implementing Fog of War for RTS games in Unity 2/2](https://blog.gemserk.com/2018/11/20/implementing-fog-of-war-for-rts-games-in-unity-2-2/)
- [Gemserk.Rts.Fog GitHub](https://github.com/gemserk/Gemserk.Rts.Fog)

核心算法：
- **网格系统**：将世界划分为网格，每个格子存储可见性信息
- **位掩码**：使用 int 的位表示多个玩家，支持联盟
- **Bresenham 直线算法**：检测视野遮挡
- **圆形范围**：计算单位视野范围内的格子
