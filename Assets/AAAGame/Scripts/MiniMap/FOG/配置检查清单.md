## 🎯 Unity 场景配置（需要手动完成）

### 步骤 1：创建 FogOfWarManager 对象
- [ ] 在 Game 场景中创建空对象
- [ ] 命名为 `FogOfWarManager`
- [ ] 挂载 `FogOfWarManager` 组件
- [ ] 配置参数：
  - [ ] Grid Width: 100
  - [ ] Grid Height: 100
  - [ ] World Bounds Min: (-50, 0, -50)
  - [ ] World Bounds Max: (50, 0, 50)
  - [ ] Update Interval: 0.1

### 步骤 2：添加 FogOfWarSetup 组件
- [ ] 在 `GameEntry` 对象上添加 `FogOfWarSetup` 组件
- [ ] 确认组件已正确添加

### 步骤 3：创建 UI 预制体
- [ ] 创建 Canvas，命名为 `FogOfWarUI`
- [ ] 设置 Render Mode 为 Screen Space - Overlay
- [ ] 添加 RawImage 子对象，命名为 `FogRawImage`
- [ ] 设置 RawImage 的 Anchor 为 Stretch（全屏）
- [ ] 设置 RawImage 的 Color 为 White (255, 255, 255, 255)
- [ ] 在 Canvas 上添加 `FogOfWarUIForm` 组件
- [ ] 将 `FogRawImage` 拖到 `Fog Raw Image` 字段
- [ ] 保存预制体到 `Assets/AAAGame/Prefabs/UI/FogOfWarUI.prefab`

### 步骤 4：配置 Procedure
- [ ] 方式 A：在项目配置中添加 `FogOfWarGameProcedure`
  ```json
  {
    "Procedures": [
      "PreloadProcedure",
      "MenuProcedure",
      "FogOfWarGameProcedure"
    ]
  }
  ```
- [ ] 方式 B：在现有 Procedure 中调用
  ```csharp
  GameEntry.GetComponent<FogOfWarSetup>().FogOfWarSystemSetup();
  GameEntry.GetComponent<FogOfWarSetup>().OpenFogOfWarUI();
  ```

## 🔍 问题排查

### 如果 UI 不显示

**检查项**：
- [ ] 场景中是否有 `FogOfWarManager` 对象？
  ```csharp
  var fogManager = FindObjectOfType<FogOfWarManager>();
  Debug.Log($"FogOfWarManager 存在: {fogManager != null}");
  ```
- [ ] `GameEntry` 上是否有 `FogOfWarSetup` 组件？
  ```csharp
  var fogSetup = GameEntry.GetComponent<FogOfWarSetup>();
  Debug.Log($"FogOfWarSetup 存在: {fogSetup != null}");
  ```
- [ ] UI 预制体是否正确创建？
  - [ ] 检查 `Assets/AAAGame/Prefabs/UI/FogOfWarUI.prefab` 是否存在
  - [ ] 检查预制体上是否有 `FogOfWarUIForm` 组件
  - [ ] 检查 `Fog Raw Image` 字段是否已赋值
- [ ] `UIViews.cs` 中是否有 `FogOfWarUI = 18`？
  - [ ] 打开 `Assets/AAAGame/Scripts/UI/Core/UIViews.cs`
  - [ ] 搜索 `FogOfWarUI`
- [ ] 是否调用了 `OpenFogOfWarUI()`？
  - [ ] 检查 Procedure 的 OnEnter 方法

### 如果视野不更新

**检查项**：
- [ ] 单位是否挂载了 `FogOfWarVisionComponent`？
- [ ] `Player Mask` 是否正确设置（1 = 玩家0）？
- [ ] `Vision Range` 是否大于 0？
- [ ] `Update Interval` 是否设置正确（推荐 0.1）？
- [ ] 强制更新视野：
  ```csharp
  var fogManager = GameEntry.GetComponent<FogOfWarSetup>().GetFogOfWarManager();
  fogManager.ForceUpdateVision();
  ```
- [ ] 检查视野数量：
  ```csharp
  int count = fogManager.GetVisionCount();
  Debug.Log($"当前视野数量: {count}");
  ```

### 如果有编译错误

**检查项**：
- [ ] 检查 Console 中的错误信息
- [ ] 确认所有文件都已正确创建：
  - [ ] `FogOfWarSetup.cs` 在 `UTManagers` 目录
  - [ ] `FogOfWarGameProcedure.cs` 在 `Procedures` 目录

- [ ] 检查命名空间是否正确
- [ ] 尝试重新导入脚本（右键 → Reimport）
- [ ] 尝试重启 Unity

## 📝 配置参数参考

### FogOfWarManager 推荐配置

```
小场景（50x50 米）：
  Grid Width: 50
  Grid Height: 50
  World Bounds: (-25, 0, -25) 到 (25, 0, 25)
  Update Interval: 0.1

中等场景（100x100 米）：
  Grid Width: 100
  Grid Height: 100
  World Bounds: (-50, 0, -50) 到 (50, 0, 50)
  Update Interval: 0.1

大场景（200x200 米）：
  Grid Width: 200
  Grid Height: 200
  World Bounds: (-100, 0, -100) 到 (100, 0, 100)
  Update Interval: 0.2

颜色配置：
  Hidden Color: (0, 0, 0, 1) - 黑色，完全不透明
  Explored Color: (0.5, 0.5, 0.5, 0.5) - 灰色，半透明
  Visible Color: (1, 1, 1, 0) - 白色，完全透明

性能优先配置：
  Enable Easing: false
  Update Interval: 0.2
  Grid Width/Height: 较小值

质量优先配置：
  Enable Easing: true
  Easing Speed: 5.0
  Update Interval: 0.05
  Grid Width/Height: 较大值
```

### FogOfWarVisionComponent 推荐配置

```
步兵单位：
  Player Mask: 1
  Vision Range: 8.0

骑兵单位：
  Player Mask: 1
  Vision Range: 12.0

建筑物：
  Player Mask: 1
  Vision Range: 15.0

侦察单位：
  Player Mask: 1
  Vision Range: 20.0
```
