# 战争迷雾系统 - 快速参考

## 🚀 3步集成（5分钟）

### 1️⃣ 创建 FogOfWarManager 对象
```
场景根目录
└── 创建空对象 → 命名：FogOfWarManager
    └── Add Component → FogOfWarManager
        └── Add Component → FogOfWarAutoLoader
```

**注意**：`FogOfWarManager` 是独立的空对象，不挂在 Game Framework 上！

### 2️⃣ 创建预制体
```
Assets/AAAGame/Prefabs/UI/FogOfWarUIForm.prefab
├── Canvas
├── FogOfWarUIForm (Script)
└── FogOverlay (RawImage - 全屏)
```

### 3️⃣ 添加自动加载器
```
FogOfWarManager (GameObject) ← 推荐挂在这里
└── Add Component → FogOfWarAutoLoader
    ├── UI Form Id: 10001
    └── Asset Name: FogOfWarUIForm
```

**注意**：`FogOfWarAutoLoader` 推荐挂在 `FogOfWarManager` 对象上！

## 🎮 单位集成

### 士兵视野
```csharp
using AAAGame.MiniMap.FOG;

protected override void OnShow(object userData)
{
    base.OnShow(userData);
    
    var vision = gameObject.AddComponent<FogOfWarVisionComponent>();
    vision.SetPlayerMask(1);
    vision.SetVisionRange(10f);
    vision.RegisterVision();
}
```

### 敌方隐藏
```csharp
protected override void OnShow(object userData)
{
    base.OnShow(userData);
    
    var visibility = gameObject.AddComponent<FogOfWarUnitVisibility>();
    visibility.SetCheckPlayerMask(1);
}
```
