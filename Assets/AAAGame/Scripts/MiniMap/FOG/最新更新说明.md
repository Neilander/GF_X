# 战争迷雾系统 - 最新更新说明

## 📢 更新内容（2025-04-13）

根据你的需求，我已经修改了战争迷雾系统的配置方式：

### 🔄 核心变更

**FogOfWarManager 挂载方式**：
- ❌ 旧方式：挂在 Game Framework 对象上
- ✅ 新方式：挂在场景中的独立空对象上

**查找方式**：
- ❌ 旧方式：`GameEntry.GetComponent<FogOfWarManager>()`
- ✅ 新方式：`FindObjectOfType<FogOfWarManager>()`

---

## 🆕 新的配置方式

### 场景结构

```
Game (Scene)
├── Game Framework (GameObject)
│   └── (不包含 FogOfWarManager)
│
├── FogOfWarManager (GameObject) ← 独立空对象
│   ├── FogOfWarManager (Component)
│   └── FogOfWarAutoLoader (Component)
│
├── Main Camera
└── ...
```

### 为什么这样设计？

1. **更灵活**：可以轻松在不同场景中复制或删除
2. **更清晰**：在 Hierarchy 中一目了然
3. **更符合项目规范**：独立管理战争迷雾系统
4. **保持 GF_X 规范**：仍然继承 `GameFrameworkComponent`

## 🔍 自动查找机制

### 工作原理

所有组件都使用 `FindObjectOfType<FogOfWarManager>()` 来查找管理器：

```csharp
// 在 OnOpen/Start/RegisterVision 等方法中
fogManager = FindObjectOfType<FogOfWarManager>();
if (fogManager == null)
{
    Log.Error("FogOfWarManager not found in scene!");
    return;
}
```

### 优点

- ✅ 不依赖 GameEntry
- ✅ 支持任意位置挂载
- ✅ 自动查找，无需手动配置
- ✅ 场景中只能有一个（避免冲突）

### 注意事项

- ⚠️ 场景中必须有且只有一个 `FogOfWarManager` 对象
- ⚠️ 对象必须处于激活状态（Active）
- ⚠️ 组件必须已添加到对象上

---

## 📊 性能影响

### FindObjectOfType 性能

- **调用频率**：只在初始化时调用一次（OnOpen/Start）
- **性能影响**：可忽略不计
- **缓存机制**：找到后会缓存引用，不会重复查找

### 对比

| 方式 | 性能 | 灵活性 | 推荐度 |
|------|------|--------|--------|
| GameEntry.GetComponent | 快 | 低 | ⭐⭐⭐ |
| FindObjectOfType | 中 | 高 | ⭐⭐⭐⭐⭐ |

## 🐛 常见问题

### Q1: 找不到 FogOfWarManager？

**错误信息：**
```
[FogOfWarUI] FogOfWarManager not found in scene!
```

**解决方案：**
1. 检查场景中是否有 `FogOfWarManager` 对象
2. 检查对象上是否添加了 `FogOfWarManager` 组件
3. 确认对象处于激活状态
4. 确认对象名称正确

---

### Q2: 场景切换后迷雾消失？

**原因：**
- FogOfWarManager 对象被销毁了

**解决方案：**

**方式 1：每个场景都有**
```
每个需要迷雾的场景都创建 FogOfWarManager 对象
```

**方式 2：使用 DontDestroyOnLoad**
```csharp
// 在 FogOfWarManager.Awake() 中添加
DontDestroyOnLoad(gameObject);
```

---

### Q3: 多个场景都有 FogOfWarManager？

**问题：**
- 场景切换后可能有多个 FogOfWarManager

**解决方案：**
```csharp
// 在 FogOfWarManager.Awake() 中添加单例检查
private static FogOfWarManager instance;

protected override void Awake()
{
    if (instance != null && instance != this)
    {
        Destroy(gameObject);
        return;
    }
    
    instance = this;
    DontDestroyOnLoad(gameObject);
    
    base.Awake();
    // ...
}
```
