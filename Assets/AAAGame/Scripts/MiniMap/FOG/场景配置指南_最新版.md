# 战争迷雾系统 - 场景配置指南（最新版）

## 📋 配置方式说明

`FogOfWarManager` 继承自 `GameFrameworkComponent`，但挂载在**场景中的独立空对象**上，而不是 Game Framework 对象上。

这样做的好处：
- ✅ 更灵活的场景管理
- ✅ 便于场景切换
- ✅ 易于查找和调试
- ✅ 符合项目结构规范

---

## 🚀 3步快速配置（5分钟）

### 步骤 1：创建 FogOfWarManager 对象（1分钟）

#### 1.1 创建空对象

1. 在 Hierarchy 中右键 → **Create Empty**
2. 重命名为：`FogOfWarManager`
3. 位置：放在场景根目录（与 Game Framework 同级）

#### 1.2 添加组件

1. 选中 `FogOfWarManager` 对象
2. 点击 **Add Component**
3. 搜索：`FogOfWarManager`
4. 添加组件

#### 1.3 配置参数

```
Grid Width: 100
Grid Height: 100
World Min X: -50
World Max X: 50
World Min Z: -50
World Max Z: 50
Update Interval: 0.1
Enable Terrain Blocking: true
Enable Easing: true
Easing Speed: 5
```

#### 1.4 保存场景

按 `Ctrl+S` 保存场景

---

### 步骤 2：创建 FogOfWarUIForm 预制体（2分钟）

#### 2.1 创建 UI 预制体

1. 在 Hierarchy 中右键 → **UI** → **Canvas**
2. 重命名为：`FogOfWarUIForm`

#### 2.2 配置 Canvas

```
Canvas (Component)
├── Render Mode: Screen Space - Overlay
├── Canvas Scaler
│   ├── UI Scale Mode: Scale With Screen Size
│   ├── Reference Resolution: 1920 x 1080
│   └── Match: 0.5
└── Graphic Raycaster
```

#### 2.3 添加 FogOfWarUIForm 脚本

1. 选中 `FogOfWarUIForm` 对象
2. 添加组件：`FogOfWarUIForm`

#### 2.4 创建 RawImage

1. 右键 `FogOfWarUIForm` → **UI** → **Raw Image**
2. 重命名为：`FogOverlay`
3. 设置为全屏：
   - Anchor: Stretch（Alt+Shift+右下角）
   - Left/Right/Top/Bottom: 0
4. RawImage 设置：
   - Color: White (1, 1, 1, 1)
   - Raycast Target: false

#### 2.5 设置引用

1. 选中 `FogOfWarUIForm` 对象
2. 拖拽 `FogOverlay` 到 **Fog Raw Image** 字段

#### 2.6 保存预制体

1. 创建文件夹：`Assets/AAAGame/Prefabs/UI/`（如果不存在）
2. 将 `FogOfWarUIForm` 拖拽到该文件夹
3. 删除 Hierarchy 中的 `FogOfWarUIForm` 对象

---

### 步骤 3：添加自动加载器（1分钟）

#### 3.1 选择挂载对象

你可以选择以下任一对象挂载 `FogOfWarAutoLoader`：
- **推荐**：挂在 `FogOfWarManager` 对象上
- 或者：挂在 Game Framework 对象上
- 或者：挂在任意常驻对象上

#### 3.2 添加组件

1. 选中挂载对象（推荐：`FogOfWarManager`）
2. 添加组件：`FogOfWarAutoLoader`

#### 3.3 配置参数

```
Fog UI Form Id: 10001
Fog UI Form Asset Name: FogOfWarUIForm
Fog UI Group Name: Default
Auto Load On Start: ✓
Delay Load Time: 0.5
```

#### 3.4 保存场景

按 `Ctrl+S` 保存场景

## 📁 场景结构

### 推荐的场景层级

```
Game (Scene)
├── Game Framework (GameObject)
│   ├── Base Component
│   ├── Config Component
│   ├── ... (其他 GF_X 组件)
│   └── (不包含 FogOfWarManager)
│
├── FogOfWarManager (GameObject) ← 独立对象
│   ├── FogOfWarManager (Component)
│   └── FogOfWarAutoLoader (Component) ← 推荐挂在这里
│
├── Main Camera
├── Directional Light
└── ... (其他场景对象)
```

### 为什么这样设计？

1. **独立管理**：FogOfWarManager 作为独立对象，便于管理和查找
2. **场景切换**：可以轻松在不同场景中复制或删除
3. **调试方便**：在 Hierarchy 中一目了然
4. **符合规范**：虽然继承 GameFrameworkComponent，但不强制挂在 Game Framework 上

## 🔍 自动查找机制

### 代码实现

所有组件都使用 `FindObjectOfType<FogOfWarManager>()` 来查找管理器：

```csharp
// FogOfWarUIForm.cs
protected override void OnOpen(object userData)
{
    // 从场景中查找 FogOfWarManager
    fogManager = FindObjectOfType<FogOfWarManager>();
    if (fogManager == null)
    {
        Log.Error("[FogOfWarUI] FogOfWarManager not found in scene!");
        return;
    }
    // ...
}

// FogOfWarVisionComponent.cs
public void RegisterVision()
{
    // 从场景中查找 FogOfWarManager
    fogManager = FindObjectOfType<FogOfWarManager>();
    if (fogManager == null)
    {
        Log.Error("[FogVision] FogOfWarManager not found in scene!");
        return;
    }
    // ...
}
```

### 优点

- ✅ 不依赖 GameEntry.GetComponent
- ✅ 支持任意位置挂载
- ✅ 自动查找，无需手动配置引用
- ✅ 场景中只能有一个 FogOfWarManager（避免冲突）

## 🐛 常见问题

### Q1: 找不到 FogOfWarManager？

**错误信息：**
```
[FogOfWarUI] FogOfWarManager not found in scene!
```

**解决方案：**
1. 检查场景中是否有 `FogOfWarManager` 对象
2. 检查对象上是否添加了 `FogOfWarManager` 组件
3. 确认对象名称正确（不区分大小写）
4. 确认对象处于激活状态（Active）

---

### Q2: UI 不显示？

**检查清单：**
- [ ] FogOfWarManager 对象存在？
- [ ] FogOfWarAutoLoader 已添加？
- [ ] UI 预制体已创建？
- [ ] UI ID 未被占用？
- [ ] Console 无错误？

**解决方案：**
```
1. 检查 Console 输出
2. 手动测试加载：autoLoader.LoadFogOfWarUI()
3. 检查 UI 预制体路径
4. 确认 UI ID 唯一
```

---

### Q3: 场景切换后迷雾消失？

**原因：**
- FogOfWarManager 对象可能被销毁了

**解决方案：**

**方式 1：每个场景都有 FogOfWarManager**
```
每个需要迷雾的场景都创建 FogOfWarManager 对象
```

**方式 2：使用 DontDestroyOnLoad**
```csharp
// 在 FogOfWarManager.Awake() 中添加
DontDestroyOnLoad(gameObject);
```

**方式 3：使用场景加载事件**
```csharp
// 在场景加载时重新加载 UI
SceneManager.sceneLoaded += OnSceneLoaded;

void OnSceneLoaded(Scene scene, LoadSceneMode mode)
{
    var autoLoader = FindObjectOfType<FogOfWarAutoLoader>();
    if (autoLoader != null)
    {
        autoLoader.LoadFogOfWarUI();
    }
}
```
