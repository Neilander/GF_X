## 🎯 功能特性

### 核心功能

✅ **三种迷雾状态**
- Hidden（未探索）：黑色，完全不透明
- Explored（已探索）：灰色，半透明
- Visible（可见）：透明

✅ **多玩家支持**
- 使用位掩码技术
- 支持 32 个玩家
- 支持联盟和观战模式

✅ **地形遮挡**
- 基于 Bresenham 直线算法
- 高地遮挡低地视野
- 支持 Unity Terrain

✅ **高性能渲染**
- 定时更新机制
- 颜色平滑过渡
- 增量渲染优化

✅ **单位可见性控制**
- 三种隐藏方式（SetActive/Layer/Renderer）
- 自动检测可见性
- 性能优化

✅ **小地图集成**
- 与 MinimapManager 同步
- 自动边界配置
- 独立渲染

## 🏗️ 技术架构

### 设计模式

1. **单例模式**：FogOfWarManager 作为全局管理器
2. **组件模式**：FogOfWarVisionComponent 可插拔
3. **观察者模式**：事件驱动（OnVisionUpdated）
4. **策略模式**：三种隐藏方式

### 核心算法

1. **Bresenham 直线算法**：视野遮挡检测，O(n) 时间复杂度
2. **圆形填充算法**：视野范围计算，O(r²) 时间复杂度
3. **位掩码技术**：多玩家支持，O(1) 时间复杂度

### 数据流

```
单位 → FogOfWarVisionComponent → FogOfWarManager → FogOfWarGrid
                                        ↓
                                  OnVisionUpdated
                                        ↓
                                 FogOfWarRenderer
                                        ↓
                                    Texture2D
                                        ↓
                                     屏幕
```

## 📖 使用方法

### 快速开始（5分钟）

#### 步骤 1：添加管理器
```
Game Framework (GameObject)
└── FogOfWarManager (Component)
```

#### 步骤 2：创建 UI
```
Canvas
└── FogOfWarOverlay (RawImage)
    └── FogOfWarRenderer (Component)
```

#### 步骤 3：单位集成
```csharp
visionComponent = gameObject.AddComponent<FogOfWarVisionComponent>();
visionComponent.SetPlayerMask(1);
visionComponent.SetVisionRange(10f);
visionComponent.RegisterVision();
```

#### 步骤 4：敌方隐藏
```csharp
visibility = gameObject.AddComponent<FogOfWarUnitVisibility>();
visibility.SetCheckPlayerMask(1);
```

**详细步骤请查看**：[快速配置指南.md](./快速配置指南.md)
