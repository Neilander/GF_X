
  ```csharp
  visionComponent.RegisterVision();
  ```

## 🐛 常见问题排查

### 问题 1：迷雾不显示

**检查清单：**
- [ ] FogOfWarManager 是否在场景中？
- [ ] FogOfWarRenderer 的 Fog Manager 字段是否已设置？
- [ ] RawImage 是否在 Canvas 下？
- [ ] Canvas 的 Render Mode 是否正确？
- [ ] Console 是否有错误？

**解决方案：**
```
1. 检查 FogOfWarManager.Awake() 是否被调用
2. 检查 RawImage.texture 是否不为 null
3. 检查 Canvas 的 Render Mode（推荐 Screen Space - Overlay）
```

---

### 问题 2：单位不提供视野

**检查清单：**
- [ ] 单位是否添加了 FogOfWarVisionComponent？
- [ ] Auto Register 是否勾选？
- [ ] Player Mask 是否正确？
- [ ] 单位是否在世界范围内？

**解决方案：**
```csharp
// 在 Console 中检查
Debug.Log($"Vision count: {fogManager.GetVisionCount()}");
// 应该 > 0

// 检查单位位置
Debug.Log($"Unit position: {transform.position}");
// 应该在 WorldMin 和 WorldMax 之间
```

---

### 问题 3：敌方单位不隐藏

**检查清单：**
- [ ] 是否添加了 FogOfWarUnitVisibility？
- [ ] Owner Player Mask 和 Check Player Mask 是否正确？
- [ ] Hide Method 是否设置为 Layer？
- [ ] 主摄像机是否剔除了隐藏层？
- [ ] Hidden Layer 是否设置为 31？

**解决方案：**
```
1. 选择 Main Camera
2. Culling Mask → 取消勾选 Layer 31
3. 确认敌方单位的 Owner Player Mask = 2
4. 确认 Check Player Mask = 1
```

---

### 问题 4：性能问题

**检查清单：**
- [ ] 网格大小是否过大？
- [ ] 更新间隔是否过小？
- [ ] 是否启用了地形遮挡？
- [ ] 是否启用了模糊效果？
- [ ] 单位数量是否过多？

**解决方案：**
```
移动设备优化：
- Grid Width/Height: 50
- Update Interval: 0.2
- Enable Terrain Blocking: false
- Enable Easing: false
- Enable Blur: false

PC 优化：
- Grid Width/Height: 100
- Update Interval: 0.1
- Enable Terrain Blocking: true
- Enable Easing: true
```

---

### 问题 5：地形遮挡不工作

**检查清单：**
- [ ] Enable Terrain Blocking 是否启用？
- [ ] 场景中是否有 Unity Terrain？
- [ ] 单位的 Use Terrain Height 是否勾选？
- [ ] Height Block Threshold 是否合理？

**解决方案：**
```
1. 确保场景中有 Terrain.activeTerrain
2. 检查 Terrain 的高度数据
3. 调整 Height Block Threshold（推荐 2-5）
4. 在 Scene 视图中查看地形高度
```
