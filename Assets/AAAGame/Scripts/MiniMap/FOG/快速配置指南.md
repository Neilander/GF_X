# 战争迷雾系统 - 快速配置指南

## 🚀 5分钟快速配置

### 步骤 1：添加 FogOfWarManager（1分钟）

1. 在场景中找到或创建 **Game Framework** 对象
2. 添加组件：`Add Component` → 搜索 `FogOfWarManager`
3. 基础配置（使用默认值即可）：

```
✅ Grid Width: 100
✅ Grid Height: 100
✅ World Min X: -50
✅ World Max X: 50
✅ World Min Z: -50
✅ World Max Z: 50
✅ Update Interval: 0.1
✅ Enable Terrain Blocking: true
```

---

### 步骤 2：创建迷雾 UI（2分钟）

#### 方式 A：全屏迷雾（主视角）

1. 在 **Canvas** 下创建 `RawImage`（命名：FogOfWarOverlay）
2. 设置为全屏：
   - Anchor Presets: **Stretch** (按住 Alt+Shift 点击右下角)
   - Left/Right/Top/Bottom: **0**
3. 添加组件：`FogOfWarRenderer`
4. 拖拽 `FogOfWarManager` 到 **Fog Manager** 字段

#### 方式 B：小地图迷雾（小地图上）

1. 在小地图 UI 的 **MinimapContainer** 下创建 `RawImage`（命名：MinimapFog）
2. 设置为覆盖小地图：
   - Anchor: **Stretch**
   - Left/Right/Top/Bottom: **0**
3. 添加组件：`MinimapFogIntegration`
4. 拖拽 `FogOfWarManager` 和 `MinimapManager`
5. 勾选 **Sync With Minimap Bounds**

---

### 步骤 3：为单位添加视野（1分钟）

#### 士兵预制体

1. 打开士兵预制体
2. 添加组件：`FogOfWarVisionComponent`
3. 配置：

```
Player Mask: 1          ← 玩家0
Vision Range: 10        ← 视野10米
Auto Register: ✓
Use Terrain Height: ✓
```

#### 建筑预制体

1. 打开建筑预制体
2. 添加组件：`FogOfWarVisionComponent`
3. 配置：

```
Player Mask: 1          ← 玩家0
Vision Range: 15        ← 建筑视野更大
Auto Register: ✓
Use Terrain Height: ✓
```

---

### 步骤 4：隐藏敌方单位（1分钟）

1. 打开敌方单位预制体
2. 添加组件：`FogOfWarUnitVisibility`
3. 配置：

```
Owner Player Mask: 2            ← 敌方玩家
Check Player Mask: 1            ← 检查玩家0的视野
Hide When Not Visible: ✓
Hide Method: Layer              ← 推荐
Hidden Layer: 31                ← 隐藏层
```

4. **重要**：确保主摄像机不渲染第31层：
   - 选择 **Main Camera**
   - Culling Mask → 取消勾选 **Layer 31**

## 🔧 代码集成示例

### 在 SoldierEntity 中集成

```csharp
using AAAGame.MiniMap.FOG;

public class SoldierEntity : EntityLogic
{
    private FogOfWarVisionComponent visionComponent;
    
    protected override void OnShow(object userData)
    {
        base.OnShow(userData);
        
        // 添加视野
        visionComponent = gameObject.AddComponent<FogOfWarVisionComponent>();
        visionComponent.SetPlayerMask(Side == SideType.PlayerSide ? 1 : 2);
        visionComponent.SetVisionRange(10f);
        visionComponent.RegisterVision();
    }
    
    protected override void OnHide(bool isShutdown, object userData)
    {
        base.OnHide(isShutdown, userData);
        
        if (visionComponent != null)
        {
            visionComponent.UnregisterVision();
        }
    }
}
```

### 手动控制视野

```csharp
// 获取管理器
var fogManager = GameEntry.GetComponent<FogOfWarManager>();

// 注册视野
int visionId = fogManager.RegisterVision(
    playerMask: 1,
    visionRange: 10f,
    worldPosition: transform.position
);

// 每帧更新位置
void Update()
{
    fogManager.UpdateVision(visionId, transform.position);
}

// 销毁时注销
void OnDestroy()
{
    fogManager.UnregisterVision(visionId);
}
```

## 🐛 常见问题快速修复

### 问题 1：迷雾不显示

**检查：**
- [ ] FogOfWarManager 是否在场景中？
- [ ] FogOfWarRenderer 的 Fog Manager 字段是否已设置？
- [ ] RawImage 是否在 Canvas 下？
- [ ] Canvas 的 Render Mode 是否正确？

**快速修复：**
```
1. 检查 Console 是否有错误
2. 确保 FogOfWarManager.Awake() 被调用
3. 检查 RawImage.texture 是否不为 null
```

### 问题 2：单位不提供视野

**检查：**
- [ ] 单位是否添加了 FogOfWarVisionComponent？
- [ ] Auto Register 是否勾选？
- [ ] Player Mask 是否正确？

**快速修复：**
```csharp
// 在 Console 中检查
Debug.Log($"Vision count: {fogManager.GetVisionCount()}");
// 应该 > 0
```

### 问题 3：敌方单位不隐藏

**检查：**
- [ ] 是否添加了 FogOfWarUnitVisibility？
- [ ] Owner Player Mask 和 Check Player Mask 是否正确？
- [ ] Hide Method 是否设置为 Layer？
- [ ] 主摄像机是否剔除了隐藏层？

**快速修复：**
```
1. 选择 Main Camera
2. Culling Mask → 取消勾选 Layer 31
3. 运行游戏测试
```

### 问题 4：性能问题

**快速优化：**
```
1. 减小网格：Grid Width/Height = 50
2. 降低更新频率：Update Interval = 0.2
3. 禁用地形遮挡：Enable Terrain Blocking = false
4. 禁用过渡：Enable Easing = false
```
