# 战争迷雾系统 - 技术实现说明

## 📐 系统架构

### 核心设计理念

本系统基于 **网格化战争迷雾** 实现，参考了《星际争霸2》和《英雄联盟》的迷雾系统，具有以下特点：

1. **数据与表现分离**：逻辑层（FogOfWarGrid）和渲染层（FogOfWarRenderer）完全解耦
2. **事件驱动**：使用 C# 事件系统通知视野更新
3. **位掩码多玩家支持**：使用 int 的位表示多个玩家，支持联盟
4. **高性能**：优化算法，支持移动设备 60FPS

## 🧮 核心算法

### 1. 网格系统

#### 世界坐标 → 网格坐标

```csharp
public bool WorldToGrid(Vector3 worldPos, out int gridX, out int gridZ)
{
    // 归一化到 [0, 1]
    float normalizedX = (worldPos.x - WorldMinX) / (WorldMaxX - WorldMinX);
    float normalizedZ = (worldPos.z - WorldMinZ) / (WorldMaxZ - WorldMinZ);
    
    // 转换为网格坐标
    gridX = Mathf.FloorToInt(normalizedX * GridWidth);
    gridZ = Mathf.FloorToInt(normalizedZ * GridHeight);
    
    // 边界检查
    return gridX >= 0 && gridX < GridWidth && gridZ >= 0 && gridZ < GridHeight;
}
```

#### 网格坐标 → 世界坐标

```csharp
public Vector3 GridToWorld(int gridX, int gridZ)
{
    float cellSizeX = (WorldMaxX - WorldMinX) / GridWidth;
    float cellSizeZ = (WorldMaxZ - WorldMinZ) / GridHeight;
    
    // 返回格子中心点
    float worldX = WorldMinX + (gridX + 0.5f) * cellSizeX;
    float worldZ = WorldMinZ + (gridZ + 0.5f) * cellSizeZ;
    
    return new Vector3(worldX, 0, worldZ);
}
```

### 2. 位掩码多玩家系统

#### 原理

使用 `int` 的每一位表示一个玩家：

```
玩家0: 0001 (1)
玩家1: 0010 (2)
玩家2: 0100 (4)
玩家3: 1000 (8)

联盟 (玩家0+1): 0011 (3)
联盟 (玩家0+2): 0101 (5)
所有玩家: 1111 (15)
```

#### 操作

```csharp
// 设置可见（OR 操作）
visibleMask[index] |= playerMask;

// 检查可见（AND 操作）
bool isVisible = (visibleMask[index] & playerMask) != 0;

// 组合玩家
int alliance = player0Mask | player1Mask;  // 0001 | 0010 = 0011
```

#### 优势

- **高效**：位运算速度快
- **灵活**：支持任意玩家组合
- **节省内存**：一个 int 支持 32 个玩家

### 3. 视野计算算法

#### 圆形范围计算

```csharp
public List<Vector2Int> GetCellsInRange(int centerX, int centerZ, int range)
{
    List<Vector2Int> cells = new List<Vector2Int>();
    int rangeSquared = range * range;
    
    for (int x = centerX - range; x <= centerX + range; x++)
    {
        for (int z = centerZ - range; z <= centerZ + range; z++)
        {
            // 距离检查（避免开方，使用平方）
            int dx = x - centerX;
            int dz = z - centerZ;
            int distSquared = dx * dx + dz * dz;
            
            if (distSquared <= rangeSquared)
            {
                cells.Add(new Vector2Int(x, z));
            }
        }
    }
    
    return cells;
}
```

**时间复杂度**：O((2r)²) = O(4r²)，其中 r 是视野范围

### 4. 视野遮挡算法（Bresenham 直线）

#### 原理

从目标格子向视野中心绘制一条直线，检查路径上是否有高地遮挡。

```
视野中心 (x0, z0)
目标格子 (x1, z1)

如果路径上任何格子的高度 > 视野高度 + 阈值，则被遮挡
```

#### Bresenham 算法实现

```csharp
private bool IsVisionBlocked(int x0, int z0, int x1, int z1, short visionHeight)
{
    int dx = Mathf.Abs(x1 - x0);
    int dz = Mathf.Abs(z1 - z0);
    int sx = x0 < x1 ? 1 : -1;
    int sz = z0 < z1 ? 1 : -1;
    int err = dx - dz;
    
    int x = x0;
    int z = z0;
    
    while (true)
    {
        // 检查当前格子高度
        short cellHeight = fogGrid.GetTerrainHeight(x, z);
        if (cellHeight > visionHeight + heightThreshold)
        {
            return true; // 被遮挡
        }
        
        // 到达目标
        if (x == x1 && z == z1) break;
        
        // Bresenham 步进
        int e2 = 2 * err;
        if (e2 > -dz) { err -= dz; x += sx; }
        if (e2 < dx) { err += dx; z += sz; }
    }
    
    return false; // 未被遮挡
}
```

**时间复杂度**：O(max(dx, dz))，线性时间

**优势**：
- 不使用浮点运算，只用整数
- 精确绘制直线
- 性能优秀

### 5. 渲染算法

#### 纹理更新流程

```
1. 视野更新 → 触发 OnVisionUpdated 事件
2. 更新目标颜色数组 (targetColors)
3. 颜色过渡 (currentColors → targetColors)
4. 写入纹理 (Texture2D.SetPixels)
5. 应用纹理 (Texture2D.Apply)
```

#### 颜色过渡（Easing）

```csharp
// 平滑过渡
currentColors[i] = Color.Lerp(currentColors[i], targetColors[i], lerpSpeed * deltaTime);

// 直接设置（无过渡）
currentColors[i] = targetColors[i];
```

#### 状态到颜色映射

```csharp
switch (fogState)
{
    case FogState.Visible:   // 可见
        color = new Color(1, 1, 1, 0);  // 透明
        break;
    case FogState.Explored:  // 已探索
        color = new Color(0.3f, 0.3f, 0.3f, 0.8f);  // 灰色半透明
        break;
    case FogState.Hidden:    // 未探索
        color = new Color(0, 0, 0, 1);  // 黑色不透明
        break;
}
```

## ⚡ 性能优化

### 1. 更新频率控制

```csharp
private float updateTimer = 0f;

void Update()
{
    updateTimer += Time.deltaTime;
    
    if (updateTimer >= updateInterval)
    {
        updateTimer = 0f;
        UpdateVision();  // 定时更新，而不是每帧
    }
}
```

**效果**：
- 每帧更新：60次/秒
- 0.1秒更新：10次/秒（性能提升 6倍）

for (int i = 0; i < currentColors.Length; i++)

    if (currentColors[i] != targetColors[i])
    {
        currentColors[i] = targetColors[i];

### 5. 单位可见性优化

使用 **Layer** 方式隐藏单位（推荐）：

```csharp
// 方式 1：SetActive（性能差）
gameObject.SetActive(false);  // 触发大量回调

// 方式 2：Layer（性能好）
gameObject.layer = hiddenLayer;  // 只改变渲染层级

// 方式 3：Renderer（性能中等）
renderer.enabled = false;  // 禁用渲染器
```

**性能对比**：
- Layer：最快（只改变一个 int）
- Renderer：中等（遍历所有 Renderer）
- SetActive：最慢（触发 OnDisable/OnEnable）

## 🔬 数据结构

### FogOfWarGrid

```csharp
class FogOfWarGrid
{
    int width, height;
    
    // 当前可见性（每帧清空）
    int[] visibleMask;      // size = width * height
    
    // 历史探索记录（永久保存）
    int[] exploredMask;     // size = width * height
    
    // 地形高度
    short[] terrainHeight;  // size = width * height
}
```

**内存占用**（100x100 网格）：
- visibleMask: 10,000 × 4 bytes = 40KB
- exploredMask: 10,000 × 4 bytes = 40KB
- terrainHeight: 10,000 × 2 bytes = 20KB
- **总计：~100KB**
