## 🔄 系统流程

### 初始化流程

```
1. 游戏启动
   ↓
2. 进入 FogOfWarGameProcedure
   ↓
3. OnEnter 执行：
   ├── 初始化 GeneralSetup
   ├── 初始化 CardSetup（可选）
   ├── 初始化 FogOfWarSetup
   │   └── 查找场景中的 FogOfWarManager
   ├── 打开 CardUI（可选）
   └── 打开 FogOfWarUI
       ├── 创建纹理
       ├── 订阅视野更新事件
       └── 开始渲染
   ↓
4. 系统运行中
```

### 更新流程

```
1. FogOfWarManager.Update()
   ├── 定时器检查（UpdateInterval）
   └── 触发 UpdateVision()
       ├── 清空当前可见性
       ├── 遍历所有单位视野
       │   └── 计算每个单位的视野范围
       └── 触发 OnVisionUpdated 事件
   ↓
2. FogOfWarUIForm.OnVisionUpdated()
   └── 更新目标颜色数组
   ↓
3. FogOfWarUIForm.Update()
   ├── 颜色过渡（如果启用）
   └── 更新纹理
```

### 关闭流程

```
1. 离开 FogOfWarGameProcedure
   ↓
2. OnLeave 执行：
   ├── 关闭 FogOfWarUI
   │   ├── 取消订阅事件
   │   └── 清理纹理
   ├── 关闭 FogOfWarSetup
   │   └── 重置迷雾数据
   ├── 关闭 CardSetup（可选）
   └── 关闭 GeneralSetup
```

```csharp
{
```

## 🔧 配置参数

### FogOfWarManager 配置

```csharp
// 网格设置
Grid Width: 100              // 网格宽度
Grid Height: 100             // 网格高度
World Bounds:                // 世界边界
  Min: (-50, 0, -50)
  Max: (50, 0, 50)

// 更新设置
Update Interval: 0.1         // 更新间隔（秒）

// 颜色设置
Hidden Color: (0, 0, 0, 1)           // 黑色 - 未探索
Explored Color: (0.5, 0.5, 0.5, 0.5) // 灰色半透明 - 已探索
Visible Color: (1, 1, 1, 0)          // 完全透明 - 可见

// 过渡设置
Enable Easing: true          // 启用颜色过渡
Easing Speed: 5.0            // 过渡速度

// 地形设置
Enable Terrain Blocking: true // 启用地形遮挡
Height Block Threshold: 2     // 高度遮挡阈值
```

### FogOfWarVisionComponent 配置

```csharp
Player Mask: 1               // 玩家掩码（1=玩家0, 2=玩家1）
Vision Range: 10.0           // 视野范围（米）
Auto Register: true          // 自动注册
Update Position: true        // 自动更新位置
```

### FogOfWarUnitVisibility 配置

```csharp
Owner Player Mask: 2         // 单位所属玩家
Visible To Player Mask: 1    // 对哪些玩家可见
Hide Renderers: true         // 隐藏渲染器
Disable Colliders: false     // 禁用碰撞器
```

## ❓ 常见问题

### Q1: UI 无法显示？

**原因**：
- 场景中没有 FogOfWarManager
- UI 预制体未创建
- UIViews 未更新

**解决方案**：
1. 检查场景中是否有 FogOfWarManager 对象
2. 创建 FogOfWarUI 预制体
3. 确认 UIViews.cs 包含 `FogOfWarUI = 18`

### Q2: 视野不更新？

**原因**：
- 单位未注册视野
- UpdateInterval 设置过大
- 玩家掩码不匹配

**解决方案**：
1. 在单位上添加 FogOfWarVisionComponent
2. 调整 UpdateInterval 到 0.1
3. 检查 playerMask 是否正确

### Q3: 编译错误？

**原因**：
- 文件名与类名不匹配
- 命名空间问题
- 缺少依赖

**解决方案**：
1. 检查文件名和类名是否一致
2. 检查命名空间是否正确
3. 重新导入脚本

### Q4: 性能问题？

**原因**：
- 网格太大
- 更新频率太高
- 单位数量太多

**解决方案**：
1. 减小网格大小
2. 增加 UpdateInterval
3. 禁用 EnableEasing
4. 使用对象池
