## 🎯 核心特性

### 1. 多玩家支持（位掩码技术）

```csharp
// 玩家定义
玩家0: 0001 (1)
玩家1: 0010 (2)
玩家2: 0100 (4)
玩家3: 1000 (8)

// 联盟
玩家0+1: 0011 (3)
所有玩家: 1111 (15)

// 操作
设置可见: visibleMask |= playerMask
检查可见: (visibleMask & playerMask) != 0
```

**优势**：
- 支持 32 个玩家
- 高效的位运算
- 灵活的联盟组合

---

### 2. 地形遮挡（Bresenham 算法）

```csharp
// 从目标格子向视野中心绘制直线
// 如果路径上有高地，则视野被遮挡

bool IsVisionBlocked(x0, z0, x1, z1, visionHeight)
{
    for each cell in line(x0, z0 → x1, z1)
    {
        if (cellHeight > visionHeight + threshold)
            return true;  // 被遮挡
    }
    return false;  // 未被遮挡
}
```

**特点**：
- 精确的直线算法
- 只使用整数运算
- 线性时间复杂度 O(n)

### 3. 高性能渲染

```csharp
// 增量更新
if (currentColor != targetColor)
{
    currentColor = Lerp(currentColor, targetColor, speed);
    needsUpdate = true;
}

// 只在有变化时更新纹理
if (needsUpdate)
{
    texture.SetPixels(colors);
    texture.Apply();
}
```

**优化**：
- 定时更新（0.1秒）
- 增量渲染
- 颜色过渡缓存

## 🏗️ 架构设计

### 设计模式

1. **单例模式**：FogOfWarManager 作为全局管理器
2. **组件模式**：FogOfWarVisionComponent 可插拔
3. **观察者模式**：事件驱动（OnVisionUpdated）
4. **策略模式**：三种隐藏方式（SetActive/Layer/Renderer）

### 数据流

```
单位 (Entity)
    ↓ 注册视野
FogOfWarVisionComponent
    ↓ RegisterVision
FogOfWarManager
    ↓ 计算视野
FogOfWarGrid (数据层)
    ↓ OnVisionUpdated 事件
FogOfWarRenderer (渲染层)
    ↓ 更新纹理
Texture2D
    ↓ RawImage
屏幕
```

### 模块解耦

- **数据层**（FogOfWarGrid）：纯数据，无依赖
- **逻辑层**（FogOfWarManager）：依赖数据层
- **渲染层**（FogOfWarRenderer）：依赖逻辑层，通过事件通信
- **组件层**（FogOfWarVisionComponent）：依赖逻辑层
