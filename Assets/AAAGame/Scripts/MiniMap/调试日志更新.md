## 问题分析

### 问题 1: 士兵颜色显示为灰色
- **原因**: `SoldierEntity.OnInit` 中调用 `Initialize(Side)` 时，Side 还未设置（默认 NoSide）

  1. cameraViewFrame 未在 Unity Inspector 中配置
  2. 摄像机未找到
  3. 视野框被其他 UI 遮挡
- **状态**: 🔍 待调试

- **现象**: MinimapManager 正在广播事件，但 MinimapUI 的 `HandleUnitsUpdated` 没有被调用
- **可能原因**:
  1. 事件订阅时机问题
  2. MinimapUI 未正确初始化
  3. 事件订阅失败
- **状态**: 🔍 待调试

## 需要检查的日志

### 小地图系统
运行游戏后，查找以下日志：

1. **事件订阅**:
   ```
   [MinimapUI] Subscribed to event
   ```

2. **事件广播**:
   ```
   [MinimapManager] Broadcasting X units to Y subscribers
   ```

3. **事件接收**（关键！如果没有这个日志，说明事件未触发）:
   ```
   [MinimapUI] HandleUnitsUpdated called with X units
   ```

4. **单位创建**:
   ```
   [MinimapUI] Creating visual for unit X, Side=PlayerSide, Type=Soldier
   [MinimapUI] Soldier dot created with color: (R, G, B, A) for Side=PlayerSide
   ```

5. **摄像机查找**:
   ```
   [MinimapUI] Found main camera: XXX
   ```

6. **视野框激活**:
   ```
   [MinimapUI] Camera view frame activated at pos=(X,Y), size=(W,H)
   ```

### 卡牌丢弃系统
拖动卡牌到垃圾桶时，查找以下日志：

1. **拖拽结束**:
   ```
   [CardUI] ========== OnCardEndDrag START ==========
   [CardUI] Screen Position: (X, Y)
   ```

2. **垃圾桶检测**:
   ```
   [CardUI] IsInTrashBin check: Method1=true/false, Method2=true/false
   [CardUI] Screen pos: (X,Y), Bounds: (minX,minY) to (maxX,maxY)
   ```

3. **丢弃成功**:
   ```
   [CardUI] ✅ Discarding card: XXX
   [CardUI] ✅ Card discarded and removed successfully
   ```

## 下一步调试步骤

### 如果 MinimapUI 事件未触发
1. 检查 MinimapUI 是否正确打开（查找 `[MinimapUI] MinimapUI initialized`）
2. 检查事件订阅是否成功（查找 `[MinimapUI] Subscribed to event`）
3. 检查 MinimapManager 是否正在广播（查找 `[MinimapManager] Broadcasting`）
4. 如果以上都正常但 `HandleUnitsUpdated` 未被调用，可能是 C# 委托事件系统的问题

### 如果摄像机视野框不显示
1. 检查 Unity Inspector 中 MinimapUI 的 `cameraViewFrame` 是否已配置
2. 检查是否找到主摄像机（查找 `[MinimapUI] Found main camera`）
3. 检查视野框是否被激活（查找 `[MinimapUI] Camera view frame activated`）
4. 检查视野框的 Image 组件是否有颜色（应该是白色）
5. 检查视野框的层级是否在其他 UI 之上

### 如果卡牌丢弃不工作
1. 检查垃圾桶检测日志，看 Method1 和 Method2 的结果
2. 如果两个方法都返回 false，说明垃圾桶区域检测有问题
3. 检查垃圾桶的 RectTransform 是否正确配置
4. 检查屏幕坐标和边界坐标是否合理

## 已知问题

### 卡牌丢弃 - 原始 bug
原始代码中有一个严重的 bug：
```csharp
// 错误代码（已修复）
float minX = Mathf.Min(...) / 100;  // ❌ 除以 100 会让区域变得极小
float maxX = Mathf.Max(...) / 100;
```

这会导致垃圾桶的检测区域缩小 100 倍，几乎不可能检测到。已修复为：
```csharp
// 正确代码
float minX = Mathf.Min(...);  // ✅ 不除以 100
float maxX = Mathf.Max(...);
```
