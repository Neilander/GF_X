# 小地图系统调试检查清单

## 问题：士兵在场景中生成，但小地图上没有显示

## 调试步骤

### 1. 检查 MinimapManager 是否存在

**检查项：**
- [ ] 场景中是否有 GameObject 挂载了 MinimapManager 组件
- [ ] MinimapManager 的 GameObject 是否激活（Active）
- [ ] MinimapManager 组件是否启用（Enabled）

**如何检查：**
1. 在 Hierarchy 中查找 "MinimapManager" GameObject
2. 确认该 GameObject 的勾选框是勾选的
3. 确认 MinimapManager 组件的勾选框是勾选的

**预期日志：**
```
[MinimapManager] MinimapManager initialized
```

---

### 2. 检查 MinimapUI 是否打开

**检查项：**
- [ ] MinimapUI 是否已通过 GF.UI.OpenUIForm 打开
- [ ] MinimapUI 的 GameObject 是否激活
- [ ] MinimapUI 是否成功订阅了事件

**如何检查：**
1. 在 Hierarchy 中查找 MinimapUI 的 GameObject
2. 确认该 GameObject 是激活状态
3. 查看 Console 日志

**预期日志：**
```
[MinimapUI] MinimapManager found successfully
[MinimapUI] Subscribed to MinimapUpdateEventArgs
[MinimapUI] MinimapUI initialized
```

**如果没有这些日志：**
- MinimapUI 可能没有打开
- 需要在代码中调用：`GF.UI.OpenUIForm(UIFormId.MinimapUI);`

---

### 3. 检查士兵是否调用了 Initialize()

**检查项：**
- [ ] 士兵 Entity 的 OnInit 中是否添加了 MinimapReportComponent
- [ ] 是否调用了 `minimapReport.Initialize(Side)`
- [ ] Initialize 是否在士兵生成后立即调用

**预期日志：**
```
[MinimapReport] Unit registered: ID=1, Side=PlayerSide, Type=Soldier, Pos=(x, y, z)
[MinimapManager] Unit registered: ID=1, Side=PlayerSide, Type=Soldier, Total units=1
```

**如果没有这些日志：**
- 士兵可能没有调用 Initialize()
- 检查士兵的 OnInit 代码

**示例代码：**
```csharp
protected override void OnInit(object userData)
{
    base.OnInit(userData);
    
    // 添加小地图组件
    minimapReport = gameObject.AddComponent<MinimapReportComponent>();
    minimapReport.Initialize(Side); // 确保这行被执行
}
```

---

### 4. 检查士兵是否调用了 Tick()

**检查项：**
- [ ] 士兵 Entity 的 OnUpdate 中是否调用了 `minimapReport.Tick()`
- [ ] Tick() 是否每帧都在调用

**如何检查：**
在士兵的 OnUpdate 中添加临时日志：
```csharp
protected override void OnUpdate(float elapseSeconds, float realElapseSeconds)
{
    base.OnUpdate(elapseSeconds, realElapseSeconds);
    
    if (minimapReport != null)
    {
        minimapReport.Tick();
        // 临时日志（调试完删除）
        Debug.Log($"[Soldier] Tick called, pos={transform.position}");
    }
}
```

**预期行为：**
- 每帧都应该看到 Tick 日志（可能会很多，调试完记得删除）

---

### 5. 检查 MinimapManager 是否广播事件

**检查项：**
- [ ] MinimapManager 的 LateUpdate 是否在执行
- [ ] 是否有单位注册到 MinimapManager
- [ ] 事件是否正常广播

**预期日志：**
```
[MinimapManager] Broadcasting update with 1 units
```

**如果没有这个日志：**
- MinimapManager 可能没有单位注册
- 或者 LateUpdate 没有执行

---

### 6. 检查 MinimapUI 是否接收到事件

**检查项：**
- [ ] MinimapUI 是否订阅了事件
- [ ] OnMinimapUpdate 是否被调用
- [ ] 接收到的单位数量是否正确

**预期日志：**
```
[MinimapUI] OnMinimapUpdate called with 1 units
[MinimapUI] Creating visual for unit 1, Type=Soldier, Side=PlayerSide
```

**如果没有这些日志：**
- MinimapUI 可能没有订阅事件
- 或者事件系统有问题

---

### 7. 检查 MinimapUI 配置

**检查项：**
- [ ] Minimap Container 是否正确拖入
- [ ] Soldier Dot Prefab 是否正确拖入（可选，没有会动态创建）
- [ ] Minimap Size 是否配置（默认 200）

**如何检查：**
1. 选中 MinimapUI 的 GameObject
2. 在 Inspector 中查看 MinimapUI 组件
3. 确认 Minimap Container 字段有值

**预期日志（如果 Container 为空）：**
```
[MinimapUI] minimapContainer is null!
```

---

### 8. 检查士兵点是否被创建

**检查项：**
- [ ] CreateUnitVisual 是否被调用
- [ ] 士兵点 GameObject 是否被创建
- [ ] 士兵点是否在正确的父级下

**预期日志：**
```
[MinimapUI] Creating visual for unit 1, Type=Soldier
[MinimapUI] Instantiated soldier dot from prefab
（或）[MinimapUI] soldierDotPrefab is null, creating dynamically
[MinimapUI] Set soldier color: RGBA(0.200, 0.500, 1.000, 1.000)
[MinimapUI] Set soldier size: (5.0, 5.0)
[MinimapUI] Unit 1 created at minimap pos: (x, y), world pos: (x, y, z)
```

**如何手动检查：**
1. 运行游戏
2. 在 Hierarchy 中展开 MinimapContainer
3. 查看是否有 "Soldier_1" 之类的子对象

---

### 9. 检查士兵点的位置和大小

**可能的问题：**
- 士兵点可能被创建了，但位置不对（在屏幕外）
- 士兵点可能太小，看不见
- 士兵点可能被其他 UI 遮挡

**如何检查：**
1. 在 Hierarchy 中找到 "Soldier_X" GameObject
2. 查看其 RectTransform 的 Anchored Position
3. 查看其 Size Delta（应该是 5x5）
4. 查看其 Image 组件的 Color（应该是蓝色或红色）

**调整建议：**
- 临时将 Soldier Dot Size 改大（例如 20）
- 检查士兵点是否在 MinimapContainer 的范围内

---

### 10. 检查地图范围配置

**检查项：**
- [ ] MinimapManager 的 World Min/Max X/Z 是否正确
- [ ] 士兵的世界坐标是否在地图范围内

**如何检查：**
1. 选中 MinimapManager GameObject
2. 查看 Config 中的 World Min X/Max X/Min Z/Max Z
3. 对比士兵的世界坐标（在日志中）

**示例：**
```
地图范围：X: -50 到 50, Z: -50 到 50
士兵位置：(10, 0, 20) ✅ 在范围内
士兵位置：(100, 0, 200) ❌ 超出范围（不会显示）
```

---

## 常见问题和解决方案

### 问题 1：MinimapManager not found

**原因：**
- 场景中没有 MinimapManager GameObject
- MinimapManager 组件没有挂载

**解决方案：**
1. 创建空 GameObject，命名为 "MinimapManager"
2. 添加 MinimapManager 组件
3. 配置地图范围

---

### 问题 2：MinimapUI 没有打开

**原因：**
- 没有调用 `GF.UI.OpenUIForm(UIFormId.MinimapUI)`
- UIFormId 中没有定义 MinimapUI

**解决方案：**
1. 在合适的地方（例如 Procedure）调用打开 UI
2. 确保 UIFormId 中有 MinimapUI 的定义

---

### 问题 3：士兵没有调用 Initialize()

**原因：**
- 士兵的 OnInit 中没有添加 MinimapReportComponent
- 或者添加了但没有调用 Initialize()

**解决方案：**
```csharp
protected override void OnInit(object userData)
{
    base.OnInit(userData);
    minimapReport = gameObject.AddComponent<MinimapReportComponent>();
    minimapReport.Initialize(Side);
}
```

---

### 问题 4：士兵没有调用 Tick()

**原因：**
- 士兵的 OnUpdate 中没有调用 Tick()

**解决方案：**
```csharp
protected override void OnUpdate(float elapseSeconds, float realElapseSeconds)
{
    base.OnUpdate(elapseSeconds, realElapseSeconds);
    minimapReport?.Tick();
}
```

---

### 问题 5：Minimap Container 为空

**原因：**
- MinimapUI 组件的 Minimap Container 字段没有拖入

**解决方案：**
1. 选中 MinimapUI GameObject
2. 在 Inspector 中找到 MinimapUI 组件
3. 将 MinimapPanel 的 RectTransform 拖入 Minimap Container 字段

---

### 问题 6：士兵点太小看不见

**原因：**
- Soldier Dot Size 设置太小（默认 5）
- 或者小地图面板太大

**解决方案：**
1. 临时将 Soldier Dot Size 改为 20
2. 查看是否能看到士兵点
3. 如果能看到，再调整到合适大小

---

### 问题 7：士兵点在屏幕外

**原因：**
- 地图范围配置不正确
- 士兵的世界坐标超出地图范围

**解决方案：**
1. 检查士兵的世界坐标（在日志中）
2. 调整 MinimapManager 的地图范围，确保包含士兵位置

## 快速测试代码

如果你想快速测试小地图系统，可以在士兵的代码中添加：

```csharp
using AAAGame.MiniMap;
using UnityEngine;

public class TestSoldier : MonoBehaviour
{
    private MinimapReportComponent minimapReport;
    
    void Start()
    {
        // 添加小地图组件
        minimapReport = gameObject.AddComponent<MinimapReportComponent>();
        minimapReport.Initialize(SideType.PlayerSide);
        
        Debug.Log($"[TestSoldier] MinimapReport initialized at {transform.position}");
    }
    
    void Update()
    {
        // 每帧更新位置
        if (minimapReport != null)
        {
            minimapReport.Tick();
        }
    }
}
```
