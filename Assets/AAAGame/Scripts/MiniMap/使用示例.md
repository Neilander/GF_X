# 小地图系统使用示例

## 系统概述

小地图系统已完成，包含以下文件：
- ✅ `MinimapData.cs` - 数据模型
- ✅ `MinimapEvents.cs` - 事件定义
- ✅ `MinimapManager.cs` - 管理器（Controller）
- ✅ `MinimapReportComponent.cs` - 单位组件
- ✅ `MinimapUI.cs` - UI 显示（View）

## 快速开始

### 1. 场景设置

在 Unity 场景中创建 MinimapManager：

```
1. 创建空 GameObject，命名为 "MinimapManager"
2. 添加 MinimapManager 组件
3. 配置参数：
   - World Min X: -50
   - World Max X: 50
   - World Min Z: -50
   - World Max Z: 50
   - Player Color: 蓝色 (0.2, 0.5, 1)
   - Enemy Color: 红色 (1, 0, 0)
   - Enable Fog Of War: false（初期建议关闭）
```

### 2. 单位集成

在需要显示在小地图上的单位代码中添加：

#### 方法 A：在 Entity 初始化时添加

```csharp
using AAAGame.MiniMap;

public class YourEntity : EntityLogic
{
    private MinimapReportComponent minimapReport;
    
    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        
        // 添加小地图报告组件
        minimapReport = gameObject.AddComponent<MinimapReportComponent>();
        minimapReport.Initialize(SideType.PlayerSide); // 或 EnemySide
    }
    
    protected override void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(elapseSeconds, realElapseSeconds);
        
        // 每帧更新位置
        if (minimapReport != null)
        {
            minimapReport.Tick();
        }
    }
}
```

#### 方法 B：在 GeneralCreature 中集成

如果你的单位继承自 `GeneralCreature`，可以在其中添加：

```csharp
// 在 GeneralCreature.cs 中添加
private MinimapReportComponent minimapReport;

protected override void OnInit(object userData)
{
    base.OnInit(userData);
    
    // 初始化小地图组件
    minimapReport = gameObject.AddComponent<MinimapReportComponent>();
    minimapReport.Initialize(Side); // 使用已有的 Side 属性
}

protected override void OnUpdate(float elapseSeconds, float realElapseSeconds)
{
    base.OnUpdate(elapseSeconds, realElapseSeconds);
    
    // 更新小地图位置
    if (minimapReport != null)
    {
        minimapReport.Tick();
    }
}
```

### 3. UI 设置

创建小地图 UI：

```
1. 在 Canvas 下创建小地图面板：
   - 创建 Image，命名为 "MinimapPanel"
   - 设置为正方形（例如 200x200）
   - 设置背景色为深色（例如黑色半透明）

2. 创建单位点预制体：
   - 创建 Image，命名为 "UnitDot"
   - 设置大小为 5x5 像素
   - 设置为圆形（使用圆形 Sprite）
   - 保存为 Prefab

3. 配置 MinimapUI：
   - 在 MinimapPanel 上添加 MinimapUI 组件
   - Minimap Container: 拖入 MinimapPanel 的 RectTransform
   - Unit Dot Prefab: 拖入 UnitDot Prefab
   - Minimap Size: 200（与面板大小一致）

4. 注册 UI 到 GF_X：
   - 在 UIFormId 中添加 MinimapUI 的 ID
   - 在合适的时机打开 UI（例如游戏开始时）
```

### 4. 打开小地图 UI

在游戏流程中打开小地图：

```csharp
// 在 Procedure 或其他地方
GF.UI.OpenUIForm(UIFormId.MinimapUI);
```

## 进阶功能：战争迷雾

启用战争迷雾（可选）：

```
1. 在 MinimapManager 中：
   - Enable Fog Of War: true
   - Fog Grid Size: 50（格子数量）
   - Vision Radius: 5（每个友方单位的视野半径）

2. 在 MinimapUI 中：
   - 添加 RawImage 作为迷雾遮罩层
   - 拖入 Fog Mask Image 字段
   - 设置为覆盖整个小地图
```

## 性能优化建议

1. 单位数量较多时（>100），考虑降低更新频率
2. 战争迷雾会增加性能开销，建议在需要时才启用
3. 可以在 MinimapManager 中添加更新间隔控制

## 常见问题

### Q: 小地图上没有显示单位点？
A: 检查：
- MinimapManager 是否在场景中
- 单位是否调用了 `minimapReport.Initialize()`
- 单位是否每帧调用了 `minimapReport.Tick()`
- MinimapUI 是否已打开

### Q: 单位点位置不准确？
A: 检查：
- MinimapManager 的世界坐标范围是否正确
- MinimapUI 的 MinimapSize 是否与面板大小一致

### Q: 单位点颜色不对？
A: 检查：
- 单位的 SideType 是否正确
- MinimapManager 的势力颜色配置

## 数据流

```
单位 Update
    ↓
MinimapReportComponent.Tick()
    ↓
MinimapManager.UpdateUnit()
    ↓
MinimapManager.LateUpdate()
    ↓
计算战争迷雾（可选）
    ↓
广播 MinimapUpdateEventArgs
    ↓
MinimapUI.OnMinimapUpdate()
    ↓
更新点位置和颜色
```
