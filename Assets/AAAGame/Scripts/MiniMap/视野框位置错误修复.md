# 视野框显示在场景中心问题修复

## 问题描述
摄像机视野框显示在游戏场景的正中心，而不是在小地图 UI 上。

## 根本原因
**CameraViewFrame 的父对象设置错误**，它不在 `minimapContainer` 下，而是在场景根节点或其他位置。

## 快速修复方案（推荐）⭐⭐⭐⭐⭐

### 方法 1: 使用自动修复脚本

#### 步骤 1: 添加修复组件
1. 在 Unity 中选择 `MinimapUI` 对象（或任何对象）
2. Add Component → `MinimapCameraFrameFixer`

#### 步骤 2: 配置引用
在 Inspector 中配置：
```
Minimap Container: 拖入小地图容器对象
Camera View Frame: 拖入视野框对象
Auto Fix On Start: ✅ 勾选
```

#### 步骤 3: 运行游戏
脚本会自动修复所有问题，并在控制台输出详细日志。

### 方法 2: 手动修复（如果不想用脚本）

#### 步骤 1: 检查父对象
1. 在 Hierarchy 中找到 `CameraViewFrame` 对象
2. 查看它的父对象是什么

**正确的层级结构**:
```
Canvas
└─ MinimapPanel (或类似名称)
   └─ MinimapContainer ⭐ (这是正确的父对象)
      ├─ Background
      ├─ SoldierDot1
      ├─ SoldierDot2
      └─ CameraViewFrame ⭐ (应该在这里！)
```

**错误的层级结构**:
```
Canvas
├─ MinimapPanel
│  └─ MinimapContainer
│     └─ ...
└─ CameraViewFrame ❌ (错误！不应该在这里)

或者

Scene Root
├─ CameraViewFrame ❌ (错误！不应该在场景根节点)
└─ Canvas
   └─ ...
```

#### 步骤 2: 移动到正确位置
1. 在 Hierarchy 中拖动 `CameraViewFrame`
2. 放到 `MinimapContainer` 下
3. 确保它是 `MinimapContainer` 的**最后一个子对象**（最上层）

#### 步骤 3: 重置 Transform
选择 `CameraViewFrame`，在 Inspector 中：
1. 右键 `Rect Transform` 组件
2. 选择 `Reset`
3. 然后手动设置：
   ```
   Anchors: Min(0.5, 0.5), Max(0.5, 0.5)
   Pivot: (0.5, 0.5)
   Position: (0, 0, 0)
   Scale: (1, 1, 1)
   ```

## 详细检查清单

### 检查 1: 父对象 ⭐⭐⭐⭐⭐
```
✅ 正确: CameraViewFrame 的父对象是 minimapContainer
❌ 错误: 父对象是 Canvas、Scene Root 或其他对象
```

**如何检查**:
1. 选择 CameraViewFrame
2. 在 Inspector 顶部查看路径
3. 应该显示：`Canvas/MinimapPanel/MinimapContainer/CameraViewFrame`

### 检查 2: RectTransform 配置
```
Anchors: 
✅ Min: (0.5, 0.5)
✅ Max: (0.5, 0.5)

Pivot:
✅ (0.5, 0.5)

Position:
✅ 使用 Anchored Position（不是 World Position）

Scale:
✅ (1, 1, 1)
```

### 检查 3: Canvas 设置
确保 CameraViewFrame 在正确的 Canvas 下：
```
Canvas:
✅ Render Mode: Screen Space - Overlay 或 Camera
✅ 不是 World Space（World Space 会显示在场景中）
```

### 检查 4: 层级顺序
```
MinimapContainer 的子对象顺序：
1. Background (背景)
2. SoldierDot1 (士兵点)
3. SoldierDot2
4. ...
N. CameraViewFrame ⭐ (应该在最后)
```

## 调试方法

### 方法 1: 使用修复脚本的调试功能
1. 添加 `MinimapCameraFrameFixer` 组件
2. 配置引用
3. 右键组件 → `打印调试信息`
4. 查看控制台输出

### 方法 2: 手动检查
1. 运行游戏
2. 暂停
3. 在 Hierarchy 中选择 CameraViewFrame
4. 在 Scene 视图中查看它的位置
5. 如果它在场景中心（世界坐标 0,0,0），说明父对象错误

### 方法 3: 查看 Inspector
1. 选择 CameraViewFrame
2. 查看 Rect Transform 的 Position
3. 如果显示的是 `Position` 而不是 `Pos X/Y/Z`，说明配置正确
4. 如果显示的是世界坐标（很大的数值），说明父对象错误

## 常见错误

### 错误 1: 父对象是 Canvas
```
❌ Canvas
   └─ CameraViewFrame (错误！)
```
**修复**: 移动到 MinimapContainer 下

### 错误 2: 父对象是场景根节点
```
❌ Scene Root
   └─ CameraViewFrame (错误！)
```
**修复**: 移动到 MinimapContainer 下

### 错误 3: Canvas 是 World Space
```
❌ Canvas (Render Mode: World Space)
```
**修复**: 改为 Screen Space - Overlay 或 Camera

### 错误 4: 使用了 World Position
```
❌ Transform (不是 RectTransform)
❌ Position: (100, 50, 0) - 世界坐标
```
**修复**: 确保使用 RectTransform 和 Anchored Position

## 预期效果

- ✅ 不会显示在场景中心
- ✅ 随摄像机移动和缩放

- 在小地图 UI 的右上角（或你配置的位置）
- 不在游戏场景的中心
- 白色边框清晰可见

### 验证 2: 日志检查
查看控制台，应该看到：
```
[MinimapFixer] ✅ Parent is correct
[MinimapFixer] ✅ Anchors fixed to center
[MinimapFixer] ✅ Pivot fixed to center
[MinimapFixer] Fix completed!
```

### 验证 3: Inspector 检查
选择 CameraViewFrame，Inspector 应该显示：
```
Transform: Rect Transform ✅
Parent: MinimapContainer ✅
Anchored Position: (小数值，如 2.19, 12.08) ✅
```

## 总结

**最快的解决方案**:

2. 配置引用

父对象必须是 `minimapContainer`，不能是 Canvas 或场景根节点！
