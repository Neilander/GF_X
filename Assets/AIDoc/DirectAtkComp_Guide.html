① 状态枚举 & 字段
public class DirectAtkComp : IAtkComp
{
    public enum AtkState
    {
        Idle,
        WindUp,
        WindDown,
        Cooldown
    }

    private IEntityContext _ctx;
    private WeaponData _weapon;

    public AtkState State { get; private set; } = AtkState.Idle;
    public int AttackCount { get; private set; }
    public bool IsAttacking => State == AtkState.WindUp || State == AtkState.WindDown;

    private float _stateTimer;
    private IEntityContext _lockedTarget;

    public DirectAtkComp(WeaponData weapon)
    {
        _weapon = weapon;
    }

架构 四状态机 + 武器注入

四个状态：Idle → WindUp → WindDown → Cooldown → Idle 循环。

_lockedTarget 在前摇开始时锁定，造伤时用，防止目标中途切换。

构造函数接收 WeaponData，所有数值（伤害、前摇、后摇、攻速、射程）都从武器配表来。

③ Attack 主循环
    public void Attack(float deltaTime)
    {
        if (_ctx == null) return;

        switch (State)
        {
            case AtkState.Idle:
                TryStartAttack();
                break;

            case AtkState.WindUp:
                _stateTimer += deltaTime;
                if (_stateTimer >= _weapon.WindUp)
                {
                    DealDamage();
                    EnterState(AtkState.WindDown);
                }
                break;

            case AtkState.WindDown:
                _stateTimer += deltaTime;
                if (_stateTimer >= _weapon.WindDown)
                {
                    _ctx.ResumeComp(_ctx.MoveComp, this);
                    EnterState(AtkState.Cooldown);
                }
                break;

            case AtkState.Cooldown:
                _stateTimer += deltaTime;
                float cooldown = _weapon.AttackInterval - _weapon.WindUp - _weapon.WindDown;
                if (cooldown < 0f) cooldown = 0f;
                if (_stateTimer >= cooldown)
                    EnterState(AtkState.Idle);
                break;
        }
    }

核心 状态机驱动

每帧由 Entity 调用。Idle 时尝试发起攻击；WindUp 结束时造伤；WindDown 结束时解锁移动。

Cooldown 时间 = AttackInterval - WindUp - WindDown，即总攻击间隔扣掉前后摇。如果配表不合理导致负数就 clamp 到 0。

注意：WindDown 结束时 ResumeComp 解锁移动，如果这里没执行到（比如中途 ShutDown），移动会一直被锁。

④ TryStartAttack
    private void TryStartAttack()
    {
        if (_ctx.Brain == null) return;
        if (!_ctx.Brain.Attack) return;

        var target = _ctx.TargetComp?.CurrentTarget;
        if (target == null || !target.Alive) return;

        float dist = Vector3.Distance(_ctx.Position, target.Position);
        float range = _weapon.AttackRange * 0.01f;

        if (dist > range) return;

        _lockedTarget = target;
        AttackCount++;
        _ctx.LockComp(_ctx.MoveComp, this);
        EnterState(AtkState.WindUp);
    }

核心 攻击发起条件

三重守卫：Brain 要求攻击 → 有活着的目标 → 目标在武器射程内。

AttackRange * 0.01f：配表单位是码（百分位），乘 0.01 转米。

发起攻击时 LockComp 锁住移动组件，前摇期间不能动。

    private void DealDamage()

核心 造伤

前摇结束瞬间造伤。如果目标在前摇期间死了就跳过。

溅射伤害目前是空实现，SplashRadius > 0 时会调但什么也不做。

⑥ ShutDown
    private void EnterState(AtkState newState)
    {
        State = newState;
        _stateTimer = 0f;
    }

    public void ShutDown()
    {
        if (IsAttacking && _ctx != null)
        {
            _ctx.ResumeComp(_ctx.MoveComp, this);
        }
        State = AtkState.Idle;
        _stateTimer = 0f;
        _lockedTarget = null;
    }

    public void Resume() { }

注意 清理 & 解锁

ShutDown 时如果正在攻击（前摇或后摇中），必须解锁移动组件，否则移动会永久被锁。

Resume 空实现——攻击组件不需要被其他组件恢复。
