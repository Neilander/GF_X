public class GroupMoveManager : MonoBehaviour

架构 单例 + 协调器持有

经典 MonoBehaviour 单例。HasInstance 给外部（如 SoldierAIBrain）做空检查用。

真正干活的是 GroupMoveCoordinator（纯 C# 类），Manager 只是它的 Unity 外壳。

参数 LJ 力三组参数

三组 Lennard-Jones 参数分别控制：同阵营普通单位间、领袖与跟随者间、敌对阵营间的斥力/吸引力。

默认值除以 PX_SCALE（20），是因为参数最初在 HTML 测试页面里用像素值调好的，除以 20 转成游戏世界单位。

MoveThreshold 防止合力太小时单位原地抖动。

③ 生命周期
    private void Awake()
    {
        Instance = this;
        Coordinator = new GroupMoveCoordinator();
        LoadParams();
        SyncParams();
    }

    private void OnDestroy()
    {
        if (Instance == this) Instance = null;
    }

    private void Update()
    {
        SyncParams();
        SaveParams(); // 每帧存，保证退出 Play 前一定存上
    }

    private void LateUpdate()
    {
        Coordinator.Resolve();
    }

核心 帧循环

Awake 创建 Coordinator 并从 PlayerPrefs 加载上次调好的参数。

Update 每帧把 Inspector 值同步给 Coordinator，并存盘——这样 Play 模式下拖滑块调参不会丢。

LateUpdate 调 Resolve()：所有 Brain 在 Update 阶段提交期望速度，LateUpdate 统一算完再回调。这个时序很关键。

        var d = JsonUtility.FromJson<SaveData>(json);
        // ... 逐字段赋值 ...
    }

    [System.Serializable]
    private struct SaveData
    {
        public float unitRepStr, unitAttStr, unitEqR, unitMaxR;
        public float leaderRepStr, leaderAttStr, leaderEqR, leaderMaxR;
        public float enemyRepStr, enemyAttStr, enemyEqR, enemyMaxR;
        public float obsWeight;
        public float moveThreshold;
    }

工具 PlayerPrefs 存参数

用 JSON 序列化所有调参值到 PlayerPrefs，Play 模式退出后下次进来还能恢复。

也加了 ContextMenu，可以右键手动存/读。

⑤ SyncParams
    private void SyncParams()
    {
        if (Coordinator == null) return;
        Coordinator.UnitRepulsionStrength = UnitRepulsionStrength;
        Coordinator.UnitAttractionStrength = UnitAttractionStrength;
        Coordinator.DefaultEquilibriumRadius = UnitEquilibriumRadius;
        Coordinator.DefaultMaxInfluenceRange = UnitMaxInfluenceRange;
        // ... Leader、Enemy、Obstacle、MoveThreshold 同理 ...
        Coordinator.SyncAllAgentParams();
    }

核心 Inspector → Coordinator 同步

把 Inspector 上的 public 字段值赋给 Coordinator 对应字段，然后调 SyncAllAgentParams() 把新参数刷到所有已注册 agent 上。

这样拖 Inspector 滑块就能实时看到效果。

⑥ Agent 注册
    public void RegisterAgent(MAEntity entity)
    {
        var cc = entity.GetComponent<CharacterController>();
        float radius = cc != null ? cc.radius : 0.5f;
        Coordinator.RegisterAgent(entity.GetInstanceID(), entity.Position, entity.Side, false, radius);
    }

    public void UnregisterAgent(MAEntity entity)
    {
        Coordinator.UnregisterAgent(entity.GetInstanceID());
    }

    public void UpdateAgentPosition(MAEntity entity)
    {
        Coordinator.UpdateAgentPosition(entity.GetInstanceID(), entity.Position);
    }

接口 Agent 注册/注销/位置更新

Entity Show 时调 RegisterAgent，Hide 时调 UnregisterAgent。用 GetInstanceID() 做 key。

碰撞半径从 CharacterController 取，没有就默认 0.5。
