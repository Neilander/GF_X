# FOG3 视野表现：核心规则与当前任务

## 恢复卡片

- 主线：修完移动视野时间过渡的内外条带/黑-白-黑，同时保持权威 Fog 与表现 Fog 单向、dirty 驱动和相机局部上传。
- 当前：已按根因完成表现链重构。GPU `FOG3_LogicTransitionTexture` 保存每个 `0.1` 逻辑格的 `target/state/startAlpha/startTime` 输入源；表现纹理仍按 `PresentationResolution` 控制，材质直接采样逻辑源。脏逻辑格只上传相交的相机覆盖矩形。Shader 在统一当前时间先解析逻辑格 Alpha，再以世界单位向更透明侧做边界羽化；表现输出不再拥有独立时间戳。静态边界改为 8 方向、每方向 6 次二分定位首个更黑采样点，按真实距离连续衰减，不再使用固定半径一次采样。
- 根因边界：旧实现先在表现 texel 上重建空间目标，再给每个输出 texel 保存独立时钟。空间重建与时间过渡不可交换，导致移动时批次条带和黑-白-黑。当前时间顺序已固定为“逻辑时间源 -> 当前逻辑 Alpha -> 空间羽化 -> 相机表现”。
- 目标效果确认：多高度、斜坡、时间过渡和空间模糊是星际争霸 2 式迷雾的核心语义，不是可删的附加约束；`0.1` 独立逻辑格、dirty 驱动、局部 GPU 上传和离屏保留才是性能实现约束。
- 当前底层：权威层继续保存每个 `0.1` 逻辑格的状态、状态改变亚帧时间和地形高度/FOV 结果；表现层上传逻辑输入源，Shader 在当前时间求值后做空间边界重建。离屏逻辑格只保留起点/目标/时间，回屏时按时间直接求当前值；无 dirty 帧不上传。
- 该方案保持星际争霸 2 式效果，同时从数据模型上消除输出 texel 年龄批次；只有在必须精确回放同一 Tick 内多个事件时，才增加有序事件队列，不以更多时钟字段补偿。
- 已验证：Unity `Fog3StageCheckpointTests` 32/32 通过；新增固定 Hidden/Visible 边界 GPU 回读验证静止过渡：暗侧 `1`、边界附近约 `0.94`、两世界单位中点约 `0.53`、距离外约 `0` 且单调下降。Launch -> `Lv_2` 后后台确认逻辑源 `2098x1879`、表现纹理 `1024x917`、材质主纹理为 `FOG3_LogicTransitionTexture`，无 FOG3 Error。
- 下一步：用户固定机位验证移动、反向、斜向和静态边界；随后记录 200 来源下的 dirty 上传矩形和帧耗时。
- 门禁：逻辑与表现不可互相推导；无 dirty 帧不重算；配置异常明确报错；实机始终 Launch -> procedure。

## 不可变规则

1. Fog 逻辑格由 `GameConfig.xlsx` 的 `FogLogicCellSize` 以 Fix64 提供，当前 `0.1` 世界单位；不按地图长边或地块格缩放。
2. Hidden/Explored/Visible 是立即生效的权威状态；时间过渡和空间羽化只属于表现层。
3. 权威更新只消费来源生成、移动、死亡、阵营/幽灵变化和地形变化产生的 dirty；不得逐帧扫描全部来源或全图重算。
4. 静态遮挡按高度预处理；来源使用整域 FOV，结果按行区间增量合并，不做 Fog 格数 × 来源数扫描或逐候选格射线。
5. 表现只处理相机地面投影覆盖区，外扩羽化/预取边距；离屏区域保存起始值、目标值、起始时间，回屏时按时间解析。
6. GPU 不使用 `Texture2D.SetPixels32 + Apply` 每帧整图上传；只上传真实变化矩形或使用等价局部 RenderTexture。
7. `VisionBoundaryFadeDistance` 按世界单位从真实边界向更透明侧延伸；交界处及更黑侧不减淡。
8. UI/镜头/准星交互不进入逻辑帧；只有最终技能、移动、建造等权威命令进入逻辑帧。
9. `_FogSpatialTargetsReady` 路径的当前 Alpha 必须连续重建；禁止以中心 texel 的离散当前值覆盖表现 texel 内的连续采样。
10. ARGBFloat 表现目标的任何真实空间变化都必须重置该 texel 的时间过渡；不得使用 `1/255` 量化门槛吞掉小变化。
11. 时间过渡只能追随当时的空间预期值。一个逻辑 Tick 内不同逻辑格按亚帧时刻改变时，必须保留空间目标随这些事件演化的顺序；禁止把最终空间快照统一压到 `now` 形成批次，也禁止把同一最终空间快照分别追溯到中心逻辑格时钟。单个“最终目标 + 起点 + 起始时间”不足以表达该过程时，必须改数据模型，不得继续调时钟补偿。
12. 用户暂停帧的现象取证不得调用 Unity 相机截图或任何会触发额外渲染的接口；使用系统桌面像素拷贝。Unity 强制重绘只可作为单独实验，不能覆盖用户保留的现场。
