# FOG3 视野表现：核心规则与当前任务

## 当前结论

- `FogLogicResolution=256` 没有需求依据。旧实现把每关世界长边固定切成 256 份，Lv_2 因而得到 `256x229`、约 `0.82` 世界单位的逻辑格；这正是接近地块格大小色块的直接来源，必须移除。
- Fog 逻辑格边长由 `GameConfig.xlsx` 的 `FogLogicCellSize` 配置，当前值为 `0.1` 世界单位，不再根据关卡尺寸或地块数量缩放。地图边缘不足一个逻辑格的部分只裁切最后一格，不扩张或缩放关卡边界。
- 地块格、Fog 逻辑格、Fog 表现粒度是三套独立尺度。地块只提供可行走、高度、斜坡和遮挡属性；Fog 逻辑格保存权威状态；表现层按屏幕像素/fragment 渲染。
- 目标规模按最多约 200 个视野来源、约 `100x100` 地块及更大的外围区域设计。不得采用“每个 Fog 格扫描全部视野来源”。
- 静态地形遮挡不得对每个目标 Fog 格每帧重复打一条射线。应预处理各高度层的遮挡边/遮挡结构，运行时每个来源用整域 FOV（对称阴影投射或角度区间扫描）一次生成可见区域。
- 多来源结果使用按行压缩的可见区间做并集。可用二维差分/前缀和完成本次全体来源并集，或在增量方案中为来源缓存区间并维护全局覆盖计数；不得退回 `Fog格数 x 来源数` 比较。
- 表现纹理只更新相机地面投影覆盖区，并外扩羽化核和相机移动预取边距。离屏 Alpha 过渡不逐帧推进，保存目标值和过渡起始时间，重新进屏时按时间求当前值。
- 不再用 `Texture2D.SetPixels32 + Apply` 每帧上传整张地图；表现层应使用固定大小的相机局部 `RenderTexture`，或能真正上传脏矩形的等价实现。

## 权威与表现更新架构

1. 权威 Fog 保存全图 Hidden、Explored、Visible 状态，但只在视野来源移动、生成、死亡或地形状态变化时增量改动；没有权威输入变化时不得清空和重算全图。
2. 表现 Fog 只处理相机地面投影覆盖区，再外扩空间羽化核和相机移动预取边距；屏幕外区域不得产生逐帧表现重建成本。
3. 离屏 Alpha 过渡不逐帧更新；每个发生目标变化的区域保存过渡起始 Alpha、目标 Alpha 和起始时间，重新进入屏幕时按经过时间直接求当前 Alpha。
4. GPU 数据不得继续通过 `Texture2D.SetPixels32 + Apply` 每帧整图上传；使用固定大小的相机局部 `RenderTexture`，或只上传真实脏矩形的等价方案。
5. 所有轮询在引入或保留前必须严密证明必要性，并记录轮询频率、扫描规模、最坏时间复杂度、分配成本和停止条件；事件或 dirty 能完整覆盖的状态变化不得使用轮询。本任务的权威视野由其他权威链路显式标记来源 dirty 或全局 dirty，`ApplyFrame` 只消费 dirty 集合，不逐帧比较全部视野来源。

## 视野语义

1. Hidden、Explored、Visible 的逻辑状态立即变化；单位可见性和玩法判定不等待表现过渡。
2. 过渡仅在表现层，与逻辑层无关。
3. 时间过渡只让当前 Alpha 按 `VisionFadeSpeed` 趋近目标 Alpha，不具有从单位向外传播或向内收缩的逻辑速度。
4. 空间过渡只依据目标状态的真实边界，从边界向 Alpha 更低、更透明的一侧延伸 `VisionBoundaryFadeDistance`；交界处和更黑一侧不得被减淡。
5. 时间过渡和空间羽化互相独立。中途反向时从当前 Alpha 连续变化，但空间边界不能从历史 Alpha 推断。
6. 高地平面遮挡低地和斜坡单位视野。斜坡点高度向下取整；位于斜坡时可开启当前单位高度及以下平地、当前高度加一及以下斜坡。
7. Lv0 建筑不提供视野。无视野区域的移动限制只对幽灵生效。
8. 配置异常必须明确报错，不静默 fallback。实机测试始终从 Launch 经 procedure 进入目标关卡。

## 已落代码

- `Fog3MapData` 强制接收正数 `Fix64` 逻辑格边长；宽高由地图真实世界尺寸向上取整，最后一格按地图边界裁切。生产代码不存在 `0.1` 默认值或 fallback。
- 删除了按最长边分辨率构造 `Fog3MapData` 的入口；`Fog3Manager` 不再读取 `FogLogicResolution`。
- `GameConfig.xlsx` 来源中的 `FogLogicResolution` 已替换为 `FogLogicCellSize=0.1`，说明为“Fog逻辑格边长（世界单位）”；`GameConfig.txt` 已通过项目正式生成器刷新。
- 权威 Fog 由实体/临时视野/全局链路显式标记 dirty；无 dirty 帧 `ApplyFrame` 为 O(1)，不扫描实体、不重算 FOV。来源缓存逐行可见区间，全局使用覆盖计数做增量撤销和加入。
- 高地遮挡仍属于权威 FOV。`CollectVisibleIntervals` 使用整域 FOV；相机射线只用于表现覆盖区和地形投影，禁止参与权威可见性。
- `Fog3MapData` 保存真实 dirty cell 列表并去重，发布后按列表清空；表现层不再扫描 dirty 包围盒内部未变化的格。
- 每个表现 texel 保存起始 Alpha、目标 Alpha、目标状态和起始时间；Shader 依据 `_Time` 与 `VisionFadeSpeed` 直接解析当前 Alpha。CPU 不再每帧推进全图 Alpha，离屏区域重新进屏时按经过时间直接得到当前值。
- 表现纹理改为 `RenderTexture`，通过复用上传纹理和 `Graphics.CopyTexture` 只上传相机覆盖区与边界核外扩区内的变化矩形；不再每帧调用整图 `Texture2D.SetPixels32 + Apply`。
- 相机表现刷新每帧只比较相机引用、视投影矩阵和 pixel rect；未变化立即停止。变化时固定做 4 条视口角射线与 Fog 平面求交，不遍历 Fog 格且不产生逐帧集合分配。
- 高度采样未配置时明确回退到 `Ground` 层；地面和建筑表面只需一次最近命中 `Physics.Raycast`。已删除无依据的 `RaycastHit[32]`、全命中遍历和单位过滤。
- 对应测试已验证固定 `0.1` 粒度、dirty 边界、无 dirty 帧不推进 FOV 访问戳、权威增量撤销/重获、Shader 边界和 Ground-only 投影。
- `AAAGame.Tests.Editor.csproj` 编译 0 错误；相关 Unity EditMode 回归 `98/98` 通过。
- 已两次从 Launch 调用 `EditorRuntimeLevelEntryLauncher.Enter("Lv_2")` 完成实机对比：旧版首帧表现更新 `46.823ms`，去重真实 dirty 且删除逐格 `Texture2D.SetPixel` 后低于诊断日志 `4ms` 阈值。当前 `1024x917` 表现纹理的相机上传区为 `301x301`，约占全图 9.65%。

## 当前实现缺口

- `Fog3WorldOverlayView.AdvanceVisibilityFade` 仅保留为确定性测试入口，运行时没有调用；后续若删除该测试入口，需把测试改为显式时间源，不能恢复运行时 CPU 全图推进。
- 本次 `Lv_2` 默认固定相机已分别截取静止、获取视野中、失去视野中三种状态，未见未初始化纹理、接近地块格大小的静态色块、三角空洞或逻辑格锯齿；先前用户指定机位的 H2 竖墙亮片和 H1 缺口仍需回到同机位验收，不能用默认机位替代。
- 当前配置的 `UnitVisionRadius=18`、`HeroVisionRadius=21`、`BuildingVisionRadius=18` 在代码中直接与世界坐标距离比较，实际单位是世界单位；生成表注释仍写“格”，单位定义需要同步澄清。

## 下一步

1. 在用户原先指出 H2 亮片/H1 缺口的固定机位，保持相机不动重新截图；默认机位三种过渡状态已经通过，不重复代替指定机位。
2. 建立最多 200 来源的现象级性能基线，分别记录单来源移动、多来源同帧 dirty、来源注销和全局地形 dirty；不得只用首次进关数据代替稳态数据。
3. 补运行态相机移动测试，验证新进入屏幕区域按离屏经过时间解析 Alpha，且相机静止帧没有表现上传。

## 验收标准

- 任意关卡的完整 Fog 逻辑格均为 `FogLogicCellSize x FogLogicCellSize`，当前为 `0.1 x 0.1` 世界单位，边缘裁切格除外；地块尺寸和地图长边不改变该粒度。
- 200 个来源时不存在每个 Fog 格扫描 200 来源，也不存在每个候选格各打一条逐格射线。
- 相机静止时无接近地块格大小的色块；视野扩展、失去和静止三种状态均无锯齿、三角空洞或平台外溢。
- 相机外区域不产生逐帧表现纹理重建/上传成本，重新进入屏幕时 Alpha 与经过时间一致。
- 固定相机验收不得移动镜头、解除暂停导致英雄偏离中心，且必须使用本轮代码生成的新截图。
