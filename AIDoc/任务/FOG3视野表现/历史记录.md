# FOG3 视野表现：历史记录

## 2026-08-28（世界单位边界过渡）

- 补回并固化四条架构规则：权威 Fog 仅由 dirty 驱动；表现 Fog 只更新相机覆盖区；离屏 Alpha 保存起始值/目标值/起始时间；GPU 只上传覆盖区脏矩形。
- `VisionBoundaryFadeDistance` 改为世界单位，删除“最多 2 个逻辑格”上限和固定逻辑格采样半径。相机预取边距按地形世界尺寸换算。
- Shader 边界处理改为目标状态的世界空间采样：先求空间预期 Alpha，再由当前 texel 起始 Alpha 按时间速度趋近；不再用邻域当前 Alpha 或 `max(current,target)` 事后补偿。

## 2026-08-26

- 用户确认视野获取/失去在逻辑上没有传播速度，表现层 Alpha 以配表速度渐变至目标值。
- 用户追加边界空间过渡：仅从边界向更透明一侧延伸，不改变交界处相对更黑区域。
- 双线性场和 Catmull-Rom 插值均被实机放大遮罩否定：前者保留逐格台阶，后者形成逐格鼓包。
- 最终改用等价 `5x5` 二项式高斯低通重建，并以 9 次双线性采样实现；GPU 测试同时锁定并修复了羽化终点多算半格的问题。
- 用户把 `VisionBoundaryFadeDistance` 调为 2 后，旧的距离上限校验在 Lv_2 抛出异常；确认不能只放宽校验，因为原 `5x5` 核和八邻格最大 Alpha 无法让第二格参与羽化。
- 重建核扩为等价 `9x9` 二项式高斯，以 25 次双线性采样覆盖两格距离；宽核采样同时参与较黑 Alpha 判定，最大支持两个 Fog 格。
- 新增两格直边与 View 参数 GPU 测试；FOG3 27/27、环境遮罩与统一进关 14/14 通过。通过 Launch -> procedure 进入 Lv_2，运行时参数为 `distance=2, cellSize=1`，无旧上限异常。
- 用户明确三套尺度必须分离：地块格只提供地形属性，Fog 逻辑格独立决定权威计算规模，表现层在连续 UV/fragment 上重建；逻辑分辨率固定时，地块划分不会改变 Fog 逻辑性能规模。
- Fog 逻辑长边新增独立配置 `FogLogicResolution=256`；Lv_2 运行时为 `terrain=210x188`、`fog=256x229`、`fogCell≈0.82`，地图整体缩放不改变逻辑格数量。
- 动态实证确认 marching-squares 会把表现轮廓限定成 Fog 逻辑格折线；改为等价 `17x17` 二项式连续低通场和直边响应距离标定。
- `σ≈1.73` 的较窄核仍产生恰好一个 Fog 逻辑格的圆周起伏，因此保留 `σ=2`；8-bit Alpha 尾部低于一个量化级时在两格最大距离收口。
- 动态圆形三档等值线、斜线、单侧羽化和两格终点 GPU 测试通过，FOG3 完整测试 30/30 通过；从统一入口进入 Lv_2 并完成英雄移动截图。
- 相关跨模块回归 82/82 通过，`AAAGame.Tests.Editor.csproj` 编译 0 警告、0 错误；实机 Shader 编译错误为 0。

## 2026-08-27

- 固定机位实证确认右侧中部和顶面均有接近地块格大小的 Fog 色块。关闭 overlay 后色块消失；`ZTest=Always` 不改变形状；UV 渐变连续；当前 Alpha 已与目标 Alpha 收敛。由此排除深度穿插、明显 UV 断层和时间残留。
- 追溯发现 `FogLogicResolution=256` 是此前自行新增的工程参数，不是用户需求推导结果。Lv_2 的 `256x229` 逻辑网格约为 `0.82x0.82` 世界单位，直接形成接近地块格尺度的离散场。此前把该配置记为 DONE 是错误结论。
- 用户明确改为固定 `0.1` 世界单位 Fog 逻辑格，不按关卡长边除以固定分辨率。代码已移除 256 配置读取及最长边构造入口，地图边缘采用裁切格保持真实边界。
- 用户进一步明确 `0.1` 必须是配置值而非代码常量。新增来源配置 `FogLogicCellSize=0.1`，生产链路通过 `FixedConfigReader` 以 `Fix64` 读取并强制传入 `Fog3MapData`；缺失、零或负值明确报错，不提供默认值。
- 性能目标补充：最多约 200 个单位、约 `100x100` 地块及更大外围。当前逐来源范围扫描优于逐 Fog 格扫描 200 来源，但 `0.1` 下仍会放大约 100 倍；尤其逐候选格 Bresenham 高地遮挡不可保留。
- 确认后续性能方案：静态地形按高度预处理遮挡边/结构；每来源使用整域 FOV 一次求可见区；结果压缩为逐行区间，通过二维差分和前缀和取并集。避免为所有起点终点预烘焙射线结果造成巨量内存。
- 表现层只需更新相机投影覆盖区并外扩羽化/预取边距。离屏 Alpha 以目标值、起始值和起始时间解析；不得继续每帧整图 `SetPixels32 + Apply`。
- 修改前快照位于 `E:\AvengeSnapshots\20260827_FOG3_BeforeFixedPointOneLogicGrid`。
- 权威 Fog 改为外部链路显式标记来源 dirty/全局 dirty/临时视野 dirty；`ApplyFrame` 只消费 dirty。移动只是触发之一，生成、注销、死亡、复活、阵营、幽灵状态、读档、重置和地形变化均由所属链路触发。
- 权威来源缓存逐行可见区间，并通过全局覆盖计数增量撤销/加入。整域 FOV 替代 Fog 填充中的逐目标 Bresenham；无 dirty 帧测试确认 FOV 访问戳不推进。
- 两项视野丢失测试最初失败。诊断锁定 `AcquireFovVisitStamp()` 错误清空全局行差分并触发 reset，导致来源缓存先清空、旧区间无法撤销；删除该跨域副作用后 `LogicCardPlacementAuthorityTests` 35/35 通过。
- 用户追加全局规则：任何轮询必须证明必要性、频率、规模、最坏复杂度、分配和停止条件；event/dirty 可覆盖时禁止轮询。该规则已写入任务权威文档。
- 表现层改为每 texel 保存起始 Alpha、目标 Alpha、目标状态和起始时间，Shader 按时间解析；删除运行时 CPU 全图 Alpha 推进。
- 表现 GPU 数据改为相机覆盖矩形脏上传。相机矩阵未变时 O(1) 返回；变化时固定 4 条视口角射线求覆盖区。Lv_2 实测完整纹理 `1024x917`，固定相机上传区 `301x301`，约 9.65%。
- 追溯无依据常量：旧 `RaycastHit[32]` 来自高度投影枚举所有默认层命中。用户确认只有地面和建筑位于 Ground；根因是空配置错误回退 `Physics.DefaultRaycastLayers`。现改为强制 Ground-only、单次最近命中，并删除 32 缓冲和全命中遍历。
- 首次 Lv_2 对比日志为 `46.823ms`、`dirtyCells=304644`。进一步确认 dirty 重复入列且逐格 `Texture2D.SetPixel` 维护测试镜像；加入 dirty 位去重、删除运行时诊断纹理写入后，同链路低于 4ms 日志阈值。
- 相关 EditMode 回归 98/98 通过；从 Launch 统一入口重新进入 Lv_2，无运行时异常。固定主相机截图保存于 `Temp/FOG3Validation/Lv2_FogDirtyTimedCameraLocal.png`。
- 为捕获 0.286 秒的正常渐变窗口，验证运行临时把 `Time.timeScale` 设为 `0.05`；通过 `LogicFactionVisionService.AddDamageReveal` 和正常到期 dirty 链路分别截取获取、失去视野中状态。两张图保存于 `Temp/FOG3Validation/Lv2_FogTimedRevealInProgress.png`、`Temp/FOG3Validation/Lv2_FogTimedLossInProgress.png`，固定相机下未见三角洞或逻辑格锯齿；退出 Play 后测试状态已清除。

## 2026-08-29 核心文档分层修复

- 原核心文档误放了大量“已落代码”、旧性能数字和已完成实验；本次迁入历史，核心文档只保留不可变语义、当前缺口和验收。
- 已落权威链：`Fog3MapData` 强制接收正数 Fix64 `FogLogicCellSize`；来源/临时视野/全局链路显式 dirty；来源缓存逐行区间并用覆盖计数增量撤销/加入；无 dirty 帧 `ApplyFrame` 为 O(1)。
- 已落表现链：每 texel 保存起始 Alpha、目标 Alpha、目标状态和起始时间；Shader 按 `_Time` 解析；表现纹理为 RenderTexture，通过复用上传纹理与 `Graphics.CopyTexture` 只上传相机覆盖及边界外扩区内的变化矩形。
- 已锁定精度根因：ARGBFloat 计时载荷必须使用 `float4`；旧 `half4` 在 `Time.time≈91.59s` 时把 `6176` 个 CPU 起始时刻压成 `3` 个 GPU 时刻，最大误差 `31.25ms`，导致移动视野分层。
- 已锁定高度投影根因：空配置误退到 `Physics.DefaultRaycastLayers`，导致无依据 `RaycastHit[32]` 全命中遍历；当前 Ground-only 单次最近命中，删除 32 缓冲与单位过滤。
- 历史性能证据：Lv2 首帧表现更新曾为 `46.823ms`、`dirtyCells=304644`；dirty 去重并删除逐格测试纹理写入后低于 `4ms` 诊断阈值。`1024×917` 表现纹理的固定相机上传区为 `301×301`，约占全图 `9.65%`。
- 历史门禁：相关 EditMode 回归曾 `98/98` 通过；默认固定相机已验证静止、获取、失去视野中状态，但用户指定 H2 竖墙亮片/H1 缺口机位与 200 来源性能仍未闭环。
