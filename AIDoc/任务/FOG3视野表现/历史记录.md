# FOG3 视野表现：历史记录

## 2026-08-31 逻辑时间源与空间表现重构

- 锁定并修复移动条带的结构性根因：旧链路先生成表现 texel 空间目标，再给每个表现 texel 保存独立 `startAlpha/startTime`，空间重建与时间插值不可交换。
- `Fog3WorldOverlayView` 新增独立 `logicTransitionSource` 与 `FOG3_LogicTransitionTexture`。逻辑纹理按每个 `0.1` 逻辑格保存 `target/state/startAlpha/startTime`；表现纹理仍由 `PresentationResolution` 控制，材质直接采样逻辑纹理并在片元中连续重建。dirty 更新只复制相交相机覆盖矩形，离屏数据保留在 CPU 源数组。
- Shader 删除表现 texel 中心目标/时钟依赖，统一以 `_Time.y` 解析逻辑源 Alpha，再使用世界单位、多方向单侧边界羽化。更黑侧不被透明化，空间过渡不再创建独立时间年龄层。
- 保留 `presentationTransitions` 仅供现有编辑器诊断/旧测试反射使用，运行材质上传不再读取该数组；实际 GPU 上传始终读取 `logicTransitionSource`。
- 已完成 `AAAGame.Tests.Editor.csproj` 编译：0 错误；Unity `Fog3StageCheckpointTests` 31/31 通过。Launch -> `Lv_2` 后后台确认逻辑源 `2098x1879`、表现纹理 `1024x917` 且 FOG3 无 Error；固定暂停帧的视觉验收仍待用户执行。

## 2026-08-28（世界单位边界过渡）

- 补回并固化四条架构规则：权威 Fog 仅由 dirty 驱动；表现 Fog 只更新相机覆盖区；离屏 Alpha 保存起始值/目标值/起始时间；GPU 只上传覆盖区脏矩形。
- `VisionBoundaryFadeDistance` 改为世界单位，删除“最多 2 个逻辑格”上限和固定逻辑格采样半径。相机预取边距按地形世界尺寸换算。
- Shader 边界处理改为目标状态的世界空间采样：先求空间预期 Alpha，再由当前 texel 起始 Alpha 按时间速度趋近；不再用邻域当前 Alpha 或 `max(current,target)` 事后补偿。

## 2026-08-31 为什么该问题会反复：表现数据模型边界

- 该功能本身在 RTS 中常见，但常见实现通常是“单一逻辑网格 + 即时权威状态 + shader/纹理做平滑”。本项目额外同时要求 `0.1` 世界单位独立逻辑格、多高度/斜坡遮挡、dirty 驱动、相机局部上传、离屏过渡、世界单位羽化和三档视野状态；这些约束叠加后，难点不在单个距离场或 Shader，而在它们的组合语义。
- 当前权威逻辑层（`Fog3MapData` 的覆盖计数、行区间和 dirty）不是本轮条带的首个错误点。首错在表现层：`Fog3WorldOverlayView.RefreshPresentationRegion` 先把最终权威场做空间距离重建，再把每个表现 texel 压成 `target/startAlpha/startTime`；Shader 只是读取这份载荷。
- 空间距离重建是非线性操作，不能与逐 texel 时间插值交换。并且权威层只保留最终状态和少量 dirty 时间，不保留同一 Tick 内多次事件形成的中间空间场。于是：
  - 用统一 `now` 重打包，所有变化被压到渲染批次，形成条带；
  - 用中心逻辑格亚帧时钟追溯最终空间快照，相邻 texel 追到不同历史相位，形成黑-白-黑；
  - 沿用旧轨迹则把旧年龄分组固化，同样形成批次。
- 这解释了过去几十次修复为何在两种现象间摆动：每次都在修复载荷表现，而不是修复“时间作用在哪个场、场的中间历史是否可表示”这一抽象边界。正确重构方向是让时间先作用于来源/逻辑输入场，再对该随时间变化的场做空间边界重建；若需要跨事件精确回放，则必须保存有序事件或中间场。不得继续在输出 texel 上切换时钟或调羽化核。

## 2026-08-31 星科 2 式效果的可行底层方案

- 用户确认多高度、斜坡、时间过渡和空间模糊本来就是目标效果，不应把它们当作导致问题的“额外功能”；性能约束才是 `0.1` 独立逻辑格、dirty 驱动、相机局部上传和离屏保留。
- 不建议推倒权威逻辑层。`Fog3MapData` 继续作为多高度 FOV/遮挡的唯一权威，保存逻辑格状态与状态变化亚帧时间；表现层不再把空间距离场输出压成每 texel 的独立 `target/startAlpha/startTime`。
- 推荐流水线：`逻辑状态 + 状态时间 -> 同一 now 求值的当前逻辑输入场 -> 空间边界重建/模糊 -> 普通 Alpha/状态表现纹理`。每次 dirty 或活动过渡只求值相机覆盖区加羽化外扩区；离屏逻辑格保留起点/目标/时间，回屏时直接按时间求值。Shader 只采样最终表现场，不再对空间重建后的输出 texel 做独立时间插值。
- 活动过渡通过矩形/行区间队列推进，不逐帧扫描全图；若实际需求是精确重现同一 Tick 内多个事件的中间画面，再增加有序事件队列，而不是继续增加互相冲突的时钟字段。
- 这条流水线保留星际争霸 2 式多层、斜坡、时间和空间效果，同时让时间与空间只在一个明确的输入场边界耦合，避免当前两种修补方案必然在“条带”和“黑-透明-黑”之间摆动。
