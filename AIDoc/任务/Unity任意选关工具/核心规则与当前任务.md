# Unity 任意选关工具：核心规则与当前任务

## 恢复卡片

- DONE：已确认正式直达链为 `EditorRuntimeLevelEntry -> CareerRunSettings -> LevelSelectionService -> RuntimeProcedureBase`。
- NOW：提供任意关卡 ID 的统一入口，并在 runtime-ready 后才报告完成。
- NEXT：完成编译、专项测试，并从该入口实际进入 LvTest 验证 Launch 与运行场景共存。

## 核心规则

1. 必须从 `Launch.unity` 启动 Play，等待当前 procedure 为 `RuntimeProcedureBase` 后请求正式进关。
2. 不点击 `LevelSwitchUIForm` 或 `LvEnterDialog`，不切窗口焦点，不发送键盘或鼠标事件。
3. 关卡配置使用目标关卡的默认 Archetype，Tag 为空，与现有 Editor runner 保持一致。
4. 入口只有在目标关卡 `IsEditorStressRuntimeReady`、加载状态结束且 SelectedLevelIdentifier 匹配后才报告完成。
5. 空关卡 ID、脏场景、重复请求、编译/Play 切换中、超时等异常必须明确报错。

## 入口

- 人工：Unity 菜单 `Tools/Diagnostics/Enter Runtime Level...`，输入关卡 Identifier，点击 `Enter From Launch`。
- 自动化：在 Unity Editor 进程中调用 `EditorRuntimeLevelEntryLauncher.Enter("LvTest")`；把参数替换为任意 LevelTable Identifier。
- 状态：读取 `EditorRuntimeLevelEntryLauncher.Status`；仅当 `IsEntryPending == false` 且 `LastCompletedLevelIdentifier` 等于目标关卡时才算进关完成。
