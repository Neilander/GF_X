# Unity 任意选关工具：核心规则与当前任务

## 恢复卡片

- 主线：提供不依赖 UI 点击的正式任意关卡入口。
- 当前：正式链为 `EditorRuntimeLevelEntry -> CareerRunSettings -> LevelSelectionService -> RuntimeProcedureBase`。
- 下一步：完成编译、专项测试，并从入口实际进入 LvTest。
- 门禁：入口必须等 runtime-ready、加载结束且目标 ID 匹配后才报告完成。

## 不可变规则

1. 必须从 `Launch.unity` 启动 Play，再由 procedure 加载目标关卡。
2. 不点击 `LevelSwitchUIForm`/`LvEnterDialog`，不切换窗口焦点，不发送键鼠事件。
3. 目标关卡使用默认 Archetype，Tag 为空，与现有 Editor runner 一致。
4. 空 ID、脏场景、重复请求、编译/Play 切换中和超时等异常必须明确报错。

## 当前验收

- [ ] 编译和专项测试通过。
- [ ] 调用 `EditorRuntimeLevelEntryLauncher.Enter("LvTest")`，确认 `Launch` 与运行场景共存。
- [ ] 仅当 `IsEntryPending == false` 且完成 ID 匹配时记录进关成功。
