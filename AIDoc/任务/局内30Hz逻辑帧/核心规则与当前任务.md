# 局内 30Hz 逻辑帧：核心规则与当前任务

## 恢复卡片

- 主线：维护固定 Tick、确定性权威状态、输入归帧和可回放协议；显示与 UI 不得反向进入逻辑。
- 当前：逻辑帧迁移历史与长周期回归已完成大部分，当前仅随 Flow/战斗变更做跨模块门禁复核。
- 下一步：发现迁移回归时先补现象红测和权威日志，再修所属逻辑模块并更新 Replay/Hash 门禁。
- 门禁：实机始终 Launch -> procedure；不以单次 Play 或 Build 代替确定性和现象验收。

## 不可变规则

1. 逻辑时间以固定 Tick/帧号表达；输入、攻击、移动、导航、碰撞、投射物和命中判定使用确定性权威数据。
2. UI、准星拖拽、镜头、Animator、粒子、音频和 Display 插值不走逻辑帧，不进入权威 Hash。
3. 只有技能施放、移动、建造等最终权威命令在明确 Tick 归属后进入模拟。
4. Unity float/Physics 只能作为表现或边界 API；核心战斗与导航数值使用 Fix64/raw。
5. 逻辑实体按稳定 ID 和确定顺序处理；随机数、异步完成时机、渲染帧率和追帧次数不得改变权威结果。
6. 逻辑帧失败、空值、协议版本或 Hash 不一致必须明确报错，不静默跳过或 fallback。
