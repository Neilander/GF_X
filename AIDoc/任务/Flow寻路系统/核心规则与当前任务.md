## 不可变规则

1. 先对照 Chapter 23 和当前权威链锁定架构根因，再实现完整主线；禁止从单个热点做表层补偿。
2. 一个有状态 multi-source path request 负责同组 source；目标侧 connector/route/policy 只做一次，source 通过 merging A* 接入。
3. graph/route/tile 所有高层工作按真实 operation quota 跨 Tick 执行；quota 只改变完成 Tick，不改变 route、payload、authority hash 或 replay。
4. request 未完成时只能是显式 `PendingNavigation`，不得读旧 handle、旧方向、旧目标或同步补完。
5. moving target 同 sector 只更新 local binding；跨 sector/dirty topology 只失效必要 suffix/层级。
6. portal-window tile 身份为 `(world, agent type, sector, exit portal, dirty version)`；exact final goal 只属于 final tile，route 只属于 PathHandle。
7. NavigationSync/MoveIntent 不得同步全量 hierarchy、portal A* 或 required tile force commit；UI、准星、镜头等显示交互不走逻辑帧，只有命令提交进入 Tick。
8. 核心导航权威使用 Fix64/raw；异常状态明确报错，不 fallback、不静默跳过。

5. 达标前不得 Build Player 或收尾；未达标时回到文献差异与状态机算法审计，不改成局部限流。
