# 小地图自动水面：核心规则与当前任务

## 恢复卡片

- 主线：让自动环境水面、TWC 地形、Fog、单位/传送点和相机框共享同一最终显示世界边界。
- 当前：Lv2 已采用最小 TWC 范围加 UI 比例扩水的边界算法；后续只做跨关卡与布局变化回归。
- 下一步：从 Launch 经 procedure 复测 Lv2，并验证布局变化后的边界重建。
- 门禁：不得把完整环境水面范围直接当小地图范围；不得要求手铺 `Water` BlueprintLayer；异常边界必须报错。

## 不可变规则

- 自动水面完整范围只服务世界/相机表现，不直接决定小地图展示范围。
- 小地图至少为 TWC 四边各扩 8 格；再沿短缺轴对称扩展以覆盖 UI 宽高比。
- Terrain、Fog、单位图标、传送点和相机框使用同一世界边界与映射。
- 无自动环境背景的关卡保持原 TWC 范围语义。
- 环境背景数量异常或未覆盖最终范围时明确报错，不使用 fallback。

## 当前验收

- [ ] 从 Launch 经 procedure 进入 Lv2，确认小地图截图、像素和 Console 无错误。
- [ ] 验证布局尺寸变化通过 `RefreshLayout()` 事件重建，不逐帧轮询边界。
- [ ] 验证地形、Fog、单位、传送点和相机框无黑边、错位或缩放不一致。
