# 关卡目标设计

> 三十关的胜利条件与剧情的对应关系。
> 剧情内容见《三十关AVG梗概》，系统实现见《剧情系统程序方案》。

---

## 一、两条原则

### 1.1 胜利条件只对应主线目标

**信物委托、救援委托是可选支线，永不占用胜利条件。** 它们是关内的额外目标，不完成也能通关。

### 1.2 关内目标 ≠ 关后 AVG 的内容

这两者是先后关系，不能搞反：**关内是他这一关在做的事，关后 AVG 是他做完之后看到/得知的东西。**

例：L10 关内是"在档案室里翻找，撑到天亮"（存活一定天数），关后 AVG 才是"翻到了转出存根，担保人栏签的是他自己"。

---

## 二、主线目标的两个来源

主角每关的主线目标来自两处，**条件形态的变化本身就是叙事**：

|          | 研究院派的活                              | 他自己的活             |
| -------- | ----------------------------------------- | ---------------------- |
| 内容     | 配钥匙 = 完全掌握指定阵营                 | 找妹妹的线索           |
| 典型条件 | 建造某阵营的 3 级基地、研发科技、采集资源 | 抵达、捡取、翻找、清场 |
| 分布     | 第一章前段为主                            | 第一章后段起压倒性     |

**第一章前五关他还在服从**，扩张与配钥匙就是他的业绩，剧情上没有任何负担——**主任在通讯里夸他，进度快、数据质量好。前五关一个负面暗示都不给。** L6 起他开始违规，条件全部转向"他自己要的东西"。第二章主任已残缺，再没有一关是替研究院打的。

**扩张在剧情上表现为"清理这片区域"**，所以前段多给占领类目标（L3 占领一定数量据点、L5 占领特定几个据点）。

## 三、第一章｜故乡【汐城】

| 关  | 关内在干什么                           | 胜利条件                          | 关后 AVG                                                           |
| --- | -------------------------------------- | --------------------------------- | ------------------------------------------------------------------ |
| L1  | 配第一把钥匙（纯教程）                 | **建造指定阵营的 3 级基地** | 交代处境与任务。**关末中间人出场，主角请他帮忙找人**         |
| L2  | 摸回自家那条街                         | **抵达特定地点**            | 屋里没人没遗体，而且被收拾过                                       |
| L3  | 挨家走访还认得她的人                   | **占领一定数量据点**        | 执念体说法互相矛盾，问不出东西                                     |
| L4  | 给中间人送货抵账                       | **交付订单**                | 他卖的线索：有人见她上了一辆**公务车**离开                   |
| L5  | 沿路追那辆车的去向                     | **占领特定几个据点**        | 车队当天跑了很多趟，**不止接她一个人**                       |
| L6  | 找车队调度记录所在的封条箱             | **地图上捡特殊资源**        | **箱子上是研究院封条。** 主任以权限为由制止他动它            |
| L7  | 摸到无通讯覆盖区**拆箱解码**     | **抵达特定地点**            | 名录里一部分人被单独标记，**她在标记里**                     |
| L8  | **研发屏蔽信号的科技**，反查编号 | **研发一定数量的科技**      | 回执："该编号已转入专项，非本级可见"（含一个看不懂的专项代号）     |
| L9  | 打进她的学校                           | **占领特定据点**            | 名册上她被划掉，旁注"转出"。**见证者与"动手"的真相。信物①** |
| L10 | **在档案室翻找**，撑到天亮       | **存活一定天数**            | **转出存根：担保人栏签的是他自己**                           |

**教学期**：L1 用"建造 3 级基地"教会玩家"配钥匙 = 完全掌握一个阵营"。

**L4–L10 是一条不断的追查链**，胜利条件跟着他每一步在做的具体动作走：追车 → 找箱 → 拆箱 → 做屏蔽手段 → 打学校 → 翻档案。

**L10 的处境**：不是限时抢东西，而是拿到真相之后被困在原地熬到天亮。他知道了，却只能干等着。

| --- | ------------------------ | ------------------------------------------------- | ---------------------------------------------------------- |

| L18 | 打爆主任项目小组的据点   | **击杀一定人口的敌方单位**（待定，见下）    | 从她的模板里问出卸载机制                                   |

> **待定**：L18 的条件用"击杀一定人口"还是"占领一定数量据点"（小组分散在几处）。当前暂定前者——核心组是全作唯一的真坏人，这一关下手最狠。

**L16 是全游戏唯一一处玩法层的剧情强制**：禁用收编 + 只能撑住，两个约束叠加，玩家的无力感与剧情一致。

## 五、第三章｜拟像海

**每层先听到那份执念，再由执念推出关卡目标。** 目标不是被派下来的，是他从这一层的内容里读出来的。

四个阵眼在 L22 / L24 / L26 / L27。**同一条件的四次形态必须递进，但不做多点防守。**

| 关  | 听到的执念 → 目标                           | 胜利条件                                            | 关后 AVG                                       |
| --- | -------------------------------------------- | --------------------------------------------------- | ---------------------------------------------- |
| L21 | "把数据取完" —— 只要数据不要人             | **采集一定资源**                              | 第一次听见她，只有一个字                       |
| L22 | 第一个阵眼                                   | **占领并守护地标**（守 3 天，教学形态）       | 主任最后一次去看他，谈的是数据                 |
| L23 | "这里本来很热闹" —— 恢复当年的繁荣，路才通 | **拥有一定数量单位**                          | 场景退到一年前的汐城。**信物委托②**     |
| L24 | 第二个阵眼                                   | **占领并守护地标**（守更久，敌方压力更大）    | 灾难当天，从她的视角                           |
| L25 | "还有救" —— 主任想救人的那份心情           | **营救特定单位**                              | **75% 希望：她认得他了，会顶他两句**     |
| L26 | 第三个阵眼                                   | **占领并守护地标 + 限时**（代言人在加速崩塌） | 她怎么把救人做成工程。**第六个信物**     |
| L27 | 第四个阵眼                                   | **占领并守护地标（阵眼每天换位置）**          | 第一次活体测试，他出不来                       |
| L28 | 信号不够，找不到她                           | **在任一时刻拥有总人口（频段）达到一定值**    | 抵达她所在的区域，看得见到不了                 |
| L29 | 清她周围的障碍                               | **清除附近全部敌人**                          | **唯一一次正常对话，被狂暴的代言人打断** |
| L30 | BOSS                                         | **击杀 boss**（全作唯一一次）                 | 出示主任遗物 → 他恢复神智 → 二选一           |

**阵眼四次的递进**：守 3 天 → 守更久+压力更大 → 限时 → **阵眼每天换位置**。守的始终是同一个东西，不分兵。

**L25 是压力最低的一关**，配合"她认得他了"这个希望节点。

**L28 用人口/频段**：找她需要更多信号，这是设定上的字面对应。

## 六、支线委托（不占胜利条件）

### 6.1 救援委托（常规，每关可有）

- 条件形态：**营救特定单位**，两种变体轮换——护送回我方据点 / 清除其附近敌人
- 关内撤离时限按天数计，超时该 NPC 被写上，**当关转为敌方单位**，无回报
- **不影响关卡难度**：兵力配置、敌方强度、地图均不因委托而变

### 6.2 信物委托

**一个人一种完成方式，由他的故事决定。** "击杀"是其中一种，不是通用备选。

| 关                 | 这个人                         | 他的执念 / 处境                                                                                                        | 完成方式                                                                                                                  |
| ------------------ | ------------------------------ | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **L4**       | 执念体                         | 待定（教学位，故事简单，不承载主线情感）                                                                               | 待定。**放 L4 关内**：L3 的关后 AVG 才交代"执念体问不出东西"，L4 才有由头；且 L4 关内主线是送货，插委托不影响追查链 |
| **L9**       | **见证者**（活人幸存者） | 他见过那些人封城，怕能指挥这些兵的人                                                                                   | **在他面前守住防御阶段** —— 由关卡自然流程完成，不需要新机制。守住了他就选择相信主角                              |
| **L14**      | 实验体                         | **"等结果出来"** —— 项目早废了，设备停了，数据没了，**结果永远不会来**。他持续痛苦，偶尔清醒时求主角杀他 | **只能击杀，而且是他求的。** 全作唯一一次杀人是仁慈                                                                 |
| **L21–L22** | 中间人托他找的那个人           | 待定                                                                                                                   | 待定。**委托来自 L21 中间人的请求**（信号减弱时他才开口），见下                                                     |

**三处对照关系**：

- **L9 与 L14**：L9 那个人还活着，还能被说服；L14 那个已经什么都不剩，帮不了。
- **L14 与妹妹**：她的执念也是"等"，**区别是她等的那个人真的在来**。如果主角放弃，她就是 L14 的下场——玩家在第二章就提前看到了。

**中间人那条线是跨三关**：L13 交易（他拿研究院的信息换主角帮他找线索，不说是谁的线索、也不说自己在找人）→ L21 主角进了拟像海、**信号开始减弱，他才下决心开口**："要是你在里面遇见这个人，帮帮ta" → L22 化解之后**他才说那人是谁**。**他知道的极其有限**——只知道那人被研究院带走了，不知道拟像海也不知道载体，而且早就知道那人大概率已经不是人了。A 结局主角出来后把信物交还给他；B 结局信物永远留在里面。

**另外两个信物是主线自动获得**：L17（妹妹）、L26（主任）。

**L23 那个委托取消**：第三章已有四个阵眼关，再插委托太挤，而且 L23 本身已承载"名单是他交的"这一击。

> **终局的预演**：帮他做完 = 结局 A 的逻辑（兑现，然后放手）；打死他 = 强行拿走。**不需要一句台词点明。**

### 6.3 关卡副目标的设计与分配（待办）

- 玩法上用于引导阵营搭配与控制，剧情上用于提供代入感、调剂。类型如：选择xx组织/英雄开局、选择特定几个tag开局、启用至少x级偏移率、占领不超过/至少x个据点、、在x天内获胜、总计建造不超过x个xx建筑、（在任一时刻）拥有至少x个xx建筑、（在任一时刻）持有至少xx资金、（在任一时刻）同时在场至少x种不同阵营的单位、（在任一时刻）同一据点内至少建造x个不同阵营的建筑、不让英雄死亡、不让基地受伤、（在任一时刻）拥有x个不同的x类建筑、总计击杀不超过x个单位、不使用xx类单位/建筑（如陷阱关不使用反隐单位/建筑）等。**主任、中间人的通讯负责给这些副目标一个正当理由**——例如鼓励他多带几家的编制，说这样任务完成得更好，纯技术建议、正向。

## 七、未用于主线的条件

以下条件不进主线，放到挑战与规则变体里：

| 条件                       | 去处                                    |
| -------------------------- | --------------------------------------- |
| 采集一定资源               | 已用于 L21；也适合挑战                  |
| 拥有一定数量特定类型建筑   | 规则变体（经济局）                      |
| 研发一定数量科技           | 挑战                                    |
| 达到人口上限               | 已用于 L28；也适合挑战                  |
| 存活一定天数（可不断支援） | 已用于 L8 / L10 / L16；变体可做纯防守关 |
| 争夺物品                   | 规则变体                                |

**"避开某处""不使用某物""不占某个点"这类不做胜利条件，全部走探测目标（挑战）。**

**不使用推进进度条**（实现成本高）。
