# 剧情方案

> 剧情的呈现方式、机制挂点、成本与待办。**故事内容本身见《剧本大纲》**，此处只写"怎么做"。

---

## 一、总原则

**没有配音，所以战斗中的文本读不进去。** 全部叙事位的取舍都从这一条推出来：只用玩家已经停下来、且注意力正好对着相关对象的位置。

**剧情体量宁少不多。** 在曲线合适、能调动情感的前提下越少越好。

---

## 二、叙事位与额度

| 位置               | 内容                                                                                     | 额度         |
| ------------------ | ---------------------------------------------------------------------------------------- | ------------ |
| 关前 AVG           | 背景 + 文本。两段通讯对白，交代这一关为什么要打                                          | 一到两屏     |
| **关后 AVG** | **剧情主战场**，所有推进放这里                                                     | 视情况       |
| 造兵营建造时       | 该阵营的一句话（"证件呢，都拿出来。""里面还有人，别拦我。"）。玩家主动点建造，注意力对齐 | 一句，十余字 |
| 阶段切换           | 主角一行日志。**只跟天数走，不跟玩家行为走**，按（章 × 天数段）分池随机抽         | 一行         |
| 关卡结算           | 从当前编制里随机抽一家，给一条该阵营的结算对白                                           | 一条         |
| 场景内             | 静态/微动态的荒诞小场面，一关一处。不评论、不给主角台词                                  | 多无文本     |
| 挑战/变体奖励      | 非主线收集物，档案阅读                                                                   | 不限         |

**全游戏只有一处玩法层的剧情强制**：第二章第一关不能收编。就这一处，所以它才有分量。

---

## 三、关内叙事位的取舍依据

| 位置                   | 玩家在干什么               | 判断                                             |
| ---------------------- | -------------------------- | ------------------------------------------------ |
| 战斗中 / 卡牌部署      | 操作                       | **不放**。无配音，看不进                   |
| 打爆据点自动收编的瞬间 | 正在继续打                 | **不放**。没有停顿                         |
| 单位/建筑信息卡        | 查数值配兵                 | **不放**。信息卡要极简，避免抵触           |
| **造兵营建造**   | 主动点建造，正在想这个阵营 | **可放**。功能反馈的皮，不是插播           |
| **阶段切换**     | 已有一次结算停顿           | **可放**。见下                             |
| **关卡结算**     | 已停下                     | **可放**。一关五个阵营摊不开，所以只讲一家 |

## 四、阶段切换日志

**为什么只跟天数走**：判断"玩家今天干了什么"要接大量状态，编写和维护成本都高。改成只按天数递进——**内容是主角的状态，不是事件报告**，所以不需要任何状态判断，也不会有"突然蹦出剧情"的感觉。

**不能每章十行、十关全一样**，否则玩家第二关就发现文本在复读。改成**分池随机抽**：

| 分池键                           | 池的数量 | 每池条数 |
| -------------------------------- | -------- | -------- |
| 章（1/2/3）× 天数段（前/中/后） | 9 个池   | 6–8 条  |

同一关内抽过不重复。总量约 **40–50 行**。

- **天数段决定句子的形态**：早期完整，中期简短，晚期只剩碎句。
- **章决定语气**：第一章还有职业口吻，第二章开始出现不该有的私人情绪，第三章几乎不成句。
- 另外给**三到四个关键关卡专属的日志**（关键点一、暗刀、关键点二、章末），这几关不走随机池。

## 五、场景内的荒诞小场面

一关一处，**静态为主**（贴图与道具摆放，不做成动画），表现的是"已经发生完的场面"，玩家自己补出经过：

- 岗亭前的地上，保安和散落的证件排得整整齐齐
- 沉船的船身外，货箱在水面上浮成一片，岸上还在往下搬
- 一间教室，黑板上写满同一个字

**规则：没有人在开玩笑，主角也不评论。** 玩家自己看出可笑，笑完自己觉得不该笑——这个过程本身就是情绪调剂，而且它加深沉重，不稀释。可以配极少量的单位对白（仍是那一句十余字）。

参考《Papers, Please》：全程没有一个角色讲笑话，但很多地方很好笑，笑点全部来自**规则和人的错位**，由玩家自己制造。不可参考的是它靠日复一日重复同一流程堆积荒谬，本作节奏不同，不要硬套。

## 六、关前通讯与任务列表

每关开头两段通讯对白，一段【主任】、一段【中间人】。**任务列表是这两段通讯的总结**——玩家听完对白，列表把要做的事归纳出来，所以对白不是装饰，是任务的来源；反过来玩家跳过对白也能靠列表打下去。

| 章     | 【主任】                                                             | 【中间人】                           | 主线任务来源                                         |
| ------ | -------------------------------------------------------------------- | ------------------------------------ | ---------------------------------------------------- |
| 第一章 | 完整简报。客气、周到、讲道理                                         | 完整。转委托、抱怨、递情报           | 主任的通讯                                           |
| 第二章 | **只剩残缺通讯**，同样的语气，内容开始不对，反复要求"继续执行" | 完整。换渠道，生意照做               | **主角自己总结**（残缺通讯里已经没有可用信息） |
| 第三章 | **无。** 她已经在他的编制里                                    | 见下 | 全靠自己                                             |

### 第三章：通讯位换人

第三章【主任】的通讯位**由妹妹接替**，和"她越走越清晰"整合成同一条线。两个人的信号此消彼长：

| 阶段 | 妹妹 | 【中间人】 |
| --- | --- | --- |
| 前段 | 断续的单字，听不成句 | 还能听清 |
| 中段 | 能说完整句子 | 开始断续 |
| 后段 | **有脸**，能正常对话 | 几乎听不见 |

**关前通讯位从头到尾没空过，但说话的人换了。** 玩家不需要被告知他在往里走，也不需要被告知他和外面断了。

**这同时解决了第三章的孤立感问题**：前两章一直有人在他耳边说话，第三章如果两个通讯位都空掉会显得单薄；换成她逐渐接上，是全作唯一一次通讯质量在**变好**。

**通讯的衰减本身就是叙事**：第一章有人管他、有人跟他做生意；第二章管他的那个人坏了；第三章外面的声音一点点消失，里面的声音一点点清楚。

## 七、两类支线委托（不要混淆）

两类委托对象不同、玩法不同、回报不同。

### 类型一：信物委托 —— 对象是已执念化的人

**这些人已经不行了，救不回来。** 委托的内容不是救他，是了结他。

**两条路，玩家选**：

| 做法                                 | 结果                                 | 小故事的调性                     |
| ------------------------------------ | ------------------------------------ | -------------------------------- |
| **帮他把停在那儿的那件事做完** | 那件事一了结，执念自己走完，他松开了 | **希望**。他终于下班了     |
| **直接打败他**                 | 强行剥离                             | **悲剧**。那件事永远没做完 |

**两条路都拿到同一样东西**：他的**信物**，以及信物附带的**执念能力**。

> **这一条是终局选择的小型预演**：帮他做完 = 结局 A 的逻辑（兑现，然后放手）；打败他 = 强行拿走。玩家在三十关里做过几十次这个选择，最后一关只是把价码换成了自己的妹妹。这个呼应完全免费，不需要一句台词点明。

**数量受制作成本限制：每章 1–2 个，全作 3–6 个。** 信物会影响攻击动作与技能，属于重资源内容，不能量产。所以信物委托是**稀有的章节级事件**，不是每关都有的常规支线。

### 类型二：救援委托 —— 对象是还活着的拾荒者

**这是常规支线**，每关都可以有。

- **关内撤离时限**：本关到指定天数之前没送出去，他被写上，**当关变成敌方单位**，无任何回报。
- **回报（救出来时）**：适配度（见第十节）、收集品、中间人那边的情报（推进妹妹的线索）。小故事以"活下去了"收尾。
- **不产出信物，也不产出可用执念**——活人没有成形模板可调，而且信物是重资源内容。
- **不影响关卡内容与难度**：救与不救不改变兵力配置、敌方强度、地图。回报全在局外。

### 共同约束

- **美术复用**：拾荒者只用一到两套平民模型；被写上之后用现成的十个阵营美术。
- **每关不同人**，不常驻。**常驻的是名单。**
- **剧情量**：委托触发时一段短对白，后续在关后 AVG 里插一小段。不超过这个体量。

## 八、开局选择槽与信物

游戏已有"每关自选 3 个初始词条（LevelTagTable）"。

### 信物 = 特殊槽

**信物全作只有 3–6 个（每章 1–2 个）**，因为它影响攻击动作与技能，是重资源内容。所以它不是普通词条，占一个**独立的特殊槽**，和那 3 个词条分开。

| | 来源 | 数量 |
| --- | --- | --- |
| **他人的信物** | 信物委托（章节级事件） | 每章 1–2 个 |
| **妹妹的信物** | 第一章后期获得，**残缺状态** | **唯一一个** |

**妹妹的信物为什么和别人的不同**：别人的信物对应的是那个人自己的一份执念；她不是执念化的人，她是载体，所以她的信物给的是**她身上某一份执念的调用权**——他带着她的东西，才对得上她身上的那一份。

**每一个信物带一个小故事**，档案里可读：这个人生前是谁、他停在了哪一件事上、玩家当时选了哪条路。**玩家用的每一样东西都是一个具体的人。**

**信物的四段状态**（贯穿全作的可视化情绪计）：

| 阶段                    | 状态               | 含义                                                                               |
| ----------------------- | ------------------ | ---------------------------------------------------------------------------------- |
| 第一章后期获得 ~ 第二章 | 残缺               | 连线还远                                                                           |
| 第三章，随他往深处走    | **逐渐修复** | "她越走越清晰"在机制层的体现。**是加法，不是减法**，玩家不放弃任何已有的东西 |
| **结局 A**        | **重新破损** | 她散了，连线断了                                                                   |
| **结局 B**        | **完全完整** | 载荷接过来了，连线永久接通。最后一个镜头是他紧握着它                               |

**一处免费的重量**：这个信物是他当年买给她的，或是她信里提过想要的东西。玩家在收集品里读到过，然后在每一关的选择界面上看见它。**不写一个字。**

## 九、收集物

- **妹妹的信**（十三封，灾难前，她 16–17 岁）：按日期自动归档，不按获取顺序。玩家乱序拿到、顺序读到——重玩挑战是在往前补一段她的生活。
  - 基调是**不坦率**。正事写一堆，想说的塞在末尾。她从不直接问"什么时候接我"，她问"那边宿舍能住两个人吗""你们那儿冬天冷不冷"。
  - 他寄钱那封她火了："你是不是觉得我还是九岁。"然后才写九岁那件事，写一半又划掉，立刻找补说早都忘了。
  - 学做饭那封：写砸了几次，说你回来别指望有饭吃。（后面几封陆续问他喜欢吃什么。）
  - 最刺的一封：他寄了张【院区】照片。她回信又短又冲，说你在那边挺好的那就别回来了，我一个人能行，末尾没有一句软话。下一封她开头就问上封信收到没有。
  - **最后一封**（被改邮戳那封）：她已经在【院区】，以为是他安排的。写自己一个人也过来了，有点得意。**末尾第一次写实话："你什么时候来。"**
- **阵营遗物**：那个兵在灾难前是什么人，他的家庭、生活背景。让"仇人"复杂化。多在一、二章出现。
- **信物委托的小故事**：见第七节。个体化的阵营遗物。
- **【主任】工作札记残页**：她的动机，她要留住的那个人。以及实验设定和世界观。
- **代言人的东西**：一支笔、一张排班、一句话。补充实验设定和世界观，第二、三章出现。

## 十、局外成长：适配度

### 为什么是"适配度"而不是某种资源

局外经验不能做成一件物件（钥匙数、标定量之类），因为**两个委托来源给的活性质完全不同**：研究院让他配钥匙，中间人让他救人、带消息、找东西。同一件物件解释不了这两边。

所以经验的载体是**主角自己**，叫**适配度**。

他被选中就是因为抗感染。而他现在长期泡在污染区、反复使用采集器、不断和不同执念打交道，**他对这套东西越来越熟、越来越能承受**。

- 配钥匙给适配度：他直接在操作那套装置。
- 救人、带消息、找东西给适配度：**他在污染区多待了一段时间，多接触了几份执念。**

两边的活不一样，但对他的作用是同一个：**这座城正在改造他。**

**这个名字自带三层剧情，全部免费**：

1. **升级 = 他离普通人更远一点。** 玩家看到的等级条，其实是他被同化的进度条。
2. **接得上第三章**：他能进拟像海、能在里面撑住，正是因为这一年适配到了那个程度。
3. **接得上结局**：他适配得越好，越适合当载体。**玩家攒的每一级都在把他自己变成结局 B 的合格人选。**

### 产出规则

| 来源 | 说明 |
| --- | --- |
| 关卡通关 | 基础值 |
| **偏移率加成** | 按本关所选负面词条的 `Score` 求和，**按平方曲线转倍率**：`倍率 = 1 + k × 偏移率²` |
| 支线委托完成 | 每完成一个给固定值。救援委托是常规来源 |
| 首次通关某关 | 一次性额外 |

**为什么用平方而不是线性**：偏移率高之后难度不是线性增长，是叠加增长——高分一把可能要试几个小时。线性给会让高难完全不值得打。**不设倍率上限**（选中数本来就无上限，硬顶会让极限挑战失去动力）。

### 消耗规则

**升级只解锁新的正面词条，不提升任何数值。每关仍然只能选 3 个。**

所以成长是**选择空间变宽**，不是变强——后期关卡不会被局外等级冲垮，难度曲线由关卡自己控制。

### 与现有配表的对接

| | 解锁方式 | 分值 | 选中上限 |
| --- | --- | --- | --- |
| **正面（校准）** | 靠适配度升级逐步解锁，约 30 条 | **无分值、不分等级** | **3 个** |
| **负面（偏移）** | **开局全部解锁**，但部分关卡禁用其中一些 | 1/2/3 级，已填 | 无上限 |

`LevelTagTable` 现状与待办：

| 列 | 负面词条 | 正面词条 |
| --- | --- | --- |
| `Score` 分值 | 已填，1/2/3 分，74 条 | **保持为空**（正面无分值） |
| `UnlockLevel` 解锁所需等级 | 已填（但按新规则应全部改为开局解锁） | **需补填等级门槛**，31 条 |

另需新增一张**等级表**（等级 → 所需适配度 → 解锁的词条 ID 列表），以及一份**关卡禁用负面词条清单**。

> **与角标系统不要打架**：设计文档已有"生涯最高通过偏移率 + 铜银金钻角标"。**角标管荣誉**（记录最高打到多少），**适配度管成长**（累计产出）。同一关重复刷最高难度不应重复给满额适配度，否则会出现刷分位。
>
> **平衡注意**：负面词条的 `Score` 目前是纯难度标记，接上适配度之后会变成收益杠杆。需复核有没有"几乎不影响胜负但给满分"的条目。

## 十一、每章一次的"希望"节点

全作唯一一条纯粹向上的线，用来打断"一路往下"的单调。**成本是一段关后 AVG + 一个收集品，每章一次。**

- **第一章末**：前面几关救出来的那些人已经出去了。中间人转来一句话——他们凑了点东西给主角，或带来一条关于妹妹的消息。**玩家知道自己救的人真的活着，而且在替他做事。** 不需要煽情台词，因为那是玩家自己攒出来的。
- **第二章**：他们想办法把消息送进被封锁的【院区】。
- **第三章**：他们在外面等他出来。**这一下在两个结局里意义完全不同**——A 结局他真的走出来了，有人接他。

## 十二、体验曲线：为什么不能全程往下

**整体不压抑，因为玩法是爽的**：玩家大部分时间在造兵、拼 combo、吞地盘、赢。剧情的沉重压在一个持续给奖励的底子上，这个夹层是本作最值钱的地方。

**真正的风险不是"太黑"，是玩家开始跳过 AVG。** 连续的重击不会累加，只会互相抵消——读到第八次"你又发现自己干了一件更烂的事"就麻了，一旦养成跳过习惯，后面所有重击全部落空。

**所以调剂加在打击之间的空隙里，不加在打击上。** 该疼的地方一点都不能让。四个调剂来源：

| 来源         | 位置                             | 成本               |
| ------------ | -------------------------------- | ------------------ |
| 暖的开场     | 第一章开场九岁那一幕             | 两三屏             |
| 荒诞感       | 场景小场面，一关一处             | 贴图摆放，无新美术 |
| 正常人的声音 | 【中间人】，全程                 | 台词本来就要写     |
| 干净的胜利   | 救援委托成功、每章一次的希望节点 | 已含在上面         |

**不要做的**：搞笑队友、吐槽役、meta 玩笑；支线里角色人格突变（主线沉重、支线耍宝）；给主角加感情线。
