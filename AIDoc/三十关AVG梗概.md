# 三十关 AVG 梗概

> 每关一段关后 AVG（关前只有两段短通讯，不计入）。
> **每一关结束时主角的处境都必须和上一关不同**，否则玩家会觉得情景重复。
> 载体形式：**设备**=采集器界面/编码解码；**人**=有立绘的对话；**物**=纸质、实物、场景线索。

**时长**：第一章全程约一个月；第二、三章约半个月。**院区在第一章末沦陷**（主角还在汐城），污染传播极快，他赶回去的这几天足够全面沦陷。

---

## 开场（L1 之前，独立于关卡）

**九岁那一幕，正着演。** 父母出事，亲戚要把两个孩子分开领养，他不肯，自己去码头找活租了间房。那天他去接她，她坐在楼下台阶上等，问是不是没人要她了。他说"我来接你了，走吧"。

不带反讽，两三屏，然后切到现在。

## 第一章｜故乡【汐城】

**L4–L10 是一条不断的追查链**：车 → 车队 → 封条箱 → 名录 → 权限被屏蔽 → 名册 → 存根。线索全部由他自己查出来，**主任不提供任何关于妹妹的信息**。

**这一章不出现"载体""调用""受试"这类词。** 玩家会猜到她被研究院拿去做什么了（这是好事），但**"主角用能力会伤害妹妹"完全没有任何暗示**，那一刀集中在 L15。

### L9：见证者（信物委托 ② × "动手"的真相）

**他是个活人**——躲在城里一年的幸存者。执念体没有神智、不会怕人，所以必须是活人。他顶替了原来"特别的拾荒者"那个位置，两者合成一个角色。

| 阶段           | 内容                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------- |
| 发现           | 他躲着主角，见了就跑。主角不知道为什么                                                                   |
| 接近           | 追上后才得知：灾难当天他**亲眼看到那些人封街道、追人**。他怕这些兵，**更怕能指挥这些兵的人** |
| 质疑           | 主角第一次面对"我在用凶手"                                                                               |
| **被迫** | **防御阶段来敌，他只能靠这支部队守下来** —— 当着那个人的面                                       |
| 收尾           | 守住了。他坚定下来（或者说麻痹了自己）：**救她只能靠这份力量**。那个人把信物交给他                 |

**"被迫"这一步由关卡自然流程完成** —— 防御阶段本来就要来敌，玩家本来就要用部队打。不需要新机制，剧情只是给这一次防守加了一个观众。

**给信物的理由**：他看着主角守下来了，不再逃了，把身上唯一有用的东西给他。**这是全作第一次有人在见识了这份力量之后选择相信他。**

### L14：实验体（信物委托 ③）

**他的执念永远无法了却："等结果出来。"**

那个项目早就废了，设备停了，数据全没了，**根本不会有结果**。他停在等结果这件事上，而结果永远不会来。

- 不是"停不下来"的机械重复，是**一直在等一个不存在的东西**
- 所以他持续痛苦——每一次以为要来了，都没有
- **他偶尔有一点清醒**（"等"这种执念的空转让他偶尔浮上来），清醒时他求主角杀了他
- **帮不了他**：主角没法制造一个不存在的结果

**完成方式：只能击杀，而且是他求主角这么做的。** 全作唯一一次杀人是仁慈。

> **他和妹妹形成直接对照**：她的执念也是"等"。**区别是她等的那个人真的在来。**
>
> 由此埋一层：**如果主角放弃，妹妹等的东西也变成不存在的了，她就是这个实验体的下场。** 玩家在 L14 提前看到了妹妹的另一种坏结局——比"变成第二个代言人"更具体，也更早。

## 第三章｜拟像海

**她不在他面前**——在最深处，被载荷压着动不了。他只能通过通讯位听见她。所以"直接带她走"从一开始就不成立。

**载荷按年代堆积，每层有一个挂载点（阵眼）。** 打掉一个，那批载荷失去挂点转到他身上（适配），她轻一点、清楚一点，场景退回一个年代。**往下走就是往回走。**

### 信物 ⑤：中间人这条线

**第一章完全不提他的事。** 他的来历全程保持神秘：他能进【汐城】进不了【院区】、消息多得不正常（从哪来的不答）、他在找一个人（一年没进展）。**往上不给。**

**他知道的极其有限**：那个人被研究院带走了，此后没有消息。**他不知道拟像海，不知道载体，什么都不知道**——一年前研究院还正常运转，这种事不是一个黑市贩子能打听到的。他托过关系、找过门路、拿钱砸过，全都没结果。**而他自己早就知道那人大概率已经死了，或者已经不是人了。**

| 位置 | 内容 |
| --- | --- |
| **L13** | 交易：他拿研究院的一些信息，换主角帮他找线索。**不说是谁的线索，也不说他在找人**——但他要的东西让玩家能猜到 |
| **L21** | 主角进了拟像海，**信号开始减弱**。他这才下决心开口：要是你在里面遇见这个人，**帮帮ta**。给一个名字或特征，仍然不说是谁 |
| **L22** | 主角找到了，化解了那份执念。**化解之后他才说那人是谁**，以及这一年他做过什么 |

**"帮帮ta"这三个字是核心**——他不敢说"救"，因为他早就不指望了。他求的只是别让那人就那么耗着。

**为什么是信号减弱时才说**：距离拉远、快要联系不上了，人才肯说真话。这个心理很实在，也解释了他为什么忍到这一刻。

**这是结局 A 的第三次预演**（前两次是 L4 的委托、L14 的实验体）：**一个人求另一个人替他放手。**

**玩家先付出行动，才拿到答案** —— 不是先听一段身世再去办事。

**信物的交还**：

- **A 结局**：他出来了，把那东西还给中间人。那个人的事才算有个交代。
- **B 结局**：他没出来，信物永远留在里面。**于是外面有两个人在等** —— 妹妹等哥哥，中间人等一个答案。两个都等不到。这和 B 结局那句"不停赢了两次"是同一层。

| L9            | 见证者让他看清自己在用什么。**当着那个人的面他还是用了**               | 第一次自我怀疑，随即麻痹自己                       |
| L10           | 主任让他留在汐城完成任务。**他抗命，走了**                             | 第一次公开不服从                                   |
| L11–L13      | 中间人劝他别进院区（进去是死）。**他不听**                             | 开始不听所有人的话                                 |
| **L16** | **他拒绝使用收编**                                                     | **人性峰值。** 唯一一次为了别人克制自己      |
| **L17** | 明知信物带污染，**还是戴上**                                           | **拐点。** 第一次伤害自己换速度，偏执抬头    |
| L18           | 收编真正的仇人（主任的核心项目组）                                           | 为了目的什么都能用                                 |
| L21–L27      | 每卸一层往自己身上搬。L23 得知名单是他交的。中间人信号越来越弱，最后劝不到他 | 偏执加深，但玩家还觉得他是对的                     |
| **L29** | **她自己让他走。他不听**                                               | **偏执的顶点** —— 他连她本人的意愿都不听了 |
| L30 · A      | 他终于听了她的话，放手                                                       | **成长**                                     |
| L30 · B      | 他还是没听                                                                   | **偏执赢了**                                 |

**L16 与 L17 紧挨着是关键**：一个是人性最高点，一个是偏执的起点。玩家在 L17 会觉得他终于振作了（这是希望节点），**但那正是偏执上线的地方** —— 他从"为了她克制自己"变成"为了她什么都干"，包括伤害自己。

**第二章偏执是隐患，不是主旋律**：表面上他变坚定了，代价只在数值和阶段日志里露出来（适配度上涨、日志里开始出现执念体的说话方式）。到第三章才明显。

**A 结局的成长因此很精确**：他这一路谁的话都不听，最后一关他听了她的。而他能说出那句完整的话，是因为他想起了开场那一幕——**"我来接你了，走吧"**。九岁那次是把她从旧生活里带走，这次也是带走。不解释含义，玩家自己想。

## 兵的塑造：先伪人，后活人

**前期他们没有人格**，就是会走路的工具——风味文本只有那一句重复的执念（"证件呢""里面还有人"），不给任何生活细节。玩家使唤他们没有心理负担，因为那不像人。

**中后期才慢慢揭**：他们曾经是活人，有家庭，有故事（阵营遗物、档案条目）。同一批单位，玩家的感受随信息量变化，但机制没变。

**"这些兵就是当天封城的那批人"不做前期揭示** —— 它在 L9 由见证者点出，在 L23 才完整落地。真正的仇人在 L18（主任的核心项目组，知情、自愿、下过命令）。
