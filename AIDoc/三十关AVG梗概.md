# 三十关 AVG 梗概

> 每关一段关后 AVG（关前只有两段短通讯，不计入）。
> **每一关结束时主角的处境都必须和上一关不同**，否则玩家会觉得情景重复。
> 载体形式：**设备**=采集器界面/编码解码；**人**=有立绘的对话；**物**=纸质、实物、场景线索。

**时长**：第一章全程约一个月；第二、三章约半个月。**院区在第一章末沦陷**（主角还在汐城），污染传播极快，他赶回去的这几天足够全面沦陷。

---

## 开场（L1 之前，独立于关卡）

**九岁那一幕，正着演。** 父母出事，亲戚要把两个孩子分开领养，他不肯，自己去码头找活租了间房。那天他去接她，她坐在楼下台阶上等，问是不是没人要她了。他说"我来接你了，走吧"。

不带反讽，两三屏，然后切到现在。

## 第一章｜故乡【汐城】

线索全部由他自己查出来，**主任不提供任何关于妹妹的信息**。

| 关           | 载体         | AVG 内容                                                                                                                                                                                                                                             | 结束时他的处境                                                                 |
| ------------ | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| L1           | 设备         | 交代处境与任务：他是谁、拿着什么进来的、研究院让他干什么（评估采样、配钥匙）、他自己要干什么（找妹妹，官方名册上她是死亡）                                                                                                                           | 进城。目标是确认她死没死                                                       |
| L2           | 物           | 顺路回自家那条街。屋里没人、没遗体，**而且被收拾过**——不是翻乱，是搬走时整理过的样子                                                                                                                                                         | **她可能没死，而且是好好走的。** 从确认死亡变成找人                      |
| L3           | 人           | 找还认得她的执念体。每个只会重复自己那一句，说法互相矛盾（一个说她上学去了，一个说她搬走了，一个说她昨天还来过）                                                                                                                                     | 问不出东西。**这城里没有可信的证人**                                     |
| L4           | 人（中间人） | 中间人开价卖一条：有人见她上过一辆车。他付了钱。中间人顺口抱怨自己的活也不好干                                                                                                                                                                       | 有具体线索了                                                                   |
| **L5** | 人（执念体） | **信物委托①**（教学位）。某个执念体停在一件没做完的事上。玩家选：帮他做完（他松开了）或直接打败他（那件事永远没做完）。**获得第一个信物**。他顺手在这里查到那辆车属于市政普查——**研究院的名义**                                 | **研究院灾难前就在他家门口，而他现在正替他们干活**                       |
| L6           | 设备         | 他要开一个研究院封条箱，主任的通讯以权限为由制止。他照做了。**但他记下了箱子上的编码**                                                                                                                                                         | 替对方看守东西，手里多了一串没查的编码                                         |
| L7           | 设备         | 他挑了个通讯覆盖不到的区域，把编码输进采集器。**这是他第一件自主的事**                                                                                                                                                                         | 从执行者变成偷偷办事的人                                                       |
| L8           | 设备         | **样本 07 调用测试记录**。从平静读到失控，最后一句是他这一关刚收编的部队的战斗语音，备注"这句不是她"。三处认亲埋在里面（左手陈旧伤、"知道了"、被划掉的"呼叫某人，已消音"）                                                                     | **他知道有个活人在替他承担。他继续用**——理由是那是个陌生人，他要找妹妹 |
| L9           | 人+物        | 打到她的学校。教师执念体还在按名册点名，她的名字被划掉，旁注"转出"。**这一关是特别的救援委托**：一个拾荒者要找的人已经执念化了，他不肯走。救出来给**第二个信物**                                                                         | **她是被办手续带走的，不是逃走的**                                       |
| L10          | 物           | 转出存根：目的地【院区】，日期灾难前一个月，**担保人栏签的是他的名字**。**本章希望节点**：中间人转来消息，前面几关救出去的人凑了点东西给他，还带来一条关于她的消息——玩家知道自己救的人真的活着。**同时主任的通讯语气第一次不对** | **章末。** 她被人用他的名义带去了他上班的地方。他要回去                  |

**本章不揭"载体是她"。** L8 起玩家开始怀疑，到 L15 才确认，中间隔七关。

**希望节点放 L10**：L7–L9 三关都带紧张感（违规查编码、看到惨叫记录、有人不肯走），中间不宜插入放松段。放在章末，紧挨着"主任语气不对"，一升一降。

## 第二章｜研究院【院区】

| 关            | 载体         | AVG 内容                                                                                                                                                                                             | 结束时他的处境                                                                                                                  |
| ------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| L11           | 物           | 赶回【院区】。**已经沦陷**，外面是国家清除队的封锁线。他混进去。院内一切停在几天前，有人还坐在工位上                                                                                           | 不是回单位求助，是在废墟里找人。**打研究院的兵有了理由**                                                                  |
| L12           | 物           | 她住过的宿舍。人不在，东西都在——她在这儿住了一个月，好好的。桌上一封没寄出的信                                                                                                                     | **她一直以为是他安排的，一直在等**                                                                                        |
| **L13** | 人（中间人） | 中间人换渠道找上来，说院区这边也有一样的生意。他要一份地下实验区的通行方式。**这一段给出中间人自己的故事**——他为什么干这行、他在等谁或欠谁。**获得第三个信物**（活人给的，不是执念体） | 目标变成一个具体地点：地下实验区入口                                                                                            |
| L14           | 设备         | 实验区外围。敌人是"没做完的项目"。某个项目组的资料里出现**载体计划**，附一串编码                                                                                                               | **这里在拿活人做实验**                                                                                                    |
| **L15** | 设备         | **解码：载体计划档案。样本 07 = 她。** 后续调用记录里的调用者是他的采集器编号                                                                                                                  | **中点低谷（50%）。** 他进城以来打的每一场仗，都是从她身上取的                                                            |
| L16           | 设备         | **玩法强制：不能收编。** 打一场最难看的仗。关后从新记录中得知两件事：她背的东西是研究院压上去的，他不用也一样疼；他要是彻底放弃，她收不到消息，只会一直等到被写垮                              | **他连停手的资格都没有**                                                                                                  |
| **L17** | 物           | 他找到她被带走时随身的那件东西，研究院把它当污染物封存了。**他拿到了，带在身上，心态转为坚定**。**第四个信物**                                                                           | **低谷后的高峰。** 第一次感觉到她**还在**——不是编号，不是记录，是那个人。从"我在害她"翻成"她还等着我，我得快点到" |
| L18           | 人（主任）   | 【主任】被写住，只会重复"继续执行"。**她是唯一还知道卸载机制的活体** → 收编她                                                                                                                 | 用仇人。手上多了一个能问出机制的东西                                                                                            |
| L19           | 人（妹妹）   | **唯一一次通话。** 他摸到终端接通她，她只反复叫他关掉，他听不懂，一直说我马上就到。几句之后她语气变了，平稳地说起别人没干完的活。事后他查到：那台设备一开机就在往她身上加重                    | **他说的每一句话都是把她往下按一点。** 确认她还在，也确认自己在害她                                                       |
| L20           | 物           | 打到最底下的舱室。人在，是空的。她在拟像海里，**而载体出不来**                                                                                                                                 | **章末。** 要接她只能自己进去                                                                                             |

**本章的希望节点就是 L17**，不额外加。

## 第三章｜拟像海

**她不在他面前**——在最深处，被载荷压着动不了。他只能通过通讯位听见她。所以"直接带她走"从一开始就不成立。

**载荷按年代堆积，每层有一个挂载点（阵眼）。** 打掉一个，那批载荷失去挂点转到他身上（适配），她轻一点、清楚一点，场景退回一个年代。**往下走就是往回走。**

| 关            | 载体                 | AVG 内容                                                                                                                                                                                                                 | 结束时他的处境                                 |
| ------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------- |
| L21           | 物                   | 进入拟像海。场景是几天前的【院区】，走廊接着码头。找到第一个阵眼，也第一次听见她——一个字，听不成句                                                                                                                     | 目标明确：一层一层卸                           |
| L22           | 人（主任·差分）     | 打掉第一个阵眼。这一层是主任的记忆：**她最后一次去看他**，在他面前谈的是数据                                                                                                                                       | 他知道了那个人是怎么被放弃的                   |
| **L23** | 人（执念体）         | 场景退到一年前的【汐城】。**信物委托②**：这一层里某个还留着一点形状的东西，同样是"帮他做完"或"打败他"。**第五个信物**                                                                                       | 她能说短句了                                   |
| L24           | 人（妹妹）           | 打掉第二个阵眼。这一层是**灾难当天，从她的视角**：她那天在【院区】的宿舍里，什么都不知道，还在写信                                                                                                                 | 她能说完整的话                                 |
| **L25** | 设备                 | 场景退到十几年前的实验区。**75% 的希望**：卸载确实有效——她认得他了，会顶他两句。他相信搬完就能带她走                                                                                                             | **玩家相信这条路走得通**                 |
| **L26** | 人（主任·差分）     | 打掉第三个阵眼。这一层是她这十几年在干什么：立项、要资源、跟上面打交道，**那份念头怎么一年一年淡下去**。主角对她的感觉从厌恶变成认出——她当年也是想救人的。**获得第六个信物：主任的遗物**                   | 他在用一个和自己走同一条路的人留下的东西       |
| L27           | 人（代言人·差分）   | 最深处。第四个阵眼。这一层是**第一次活体测试**：他自己上，出不来。当时装置只有单向通道，外面开不了口子                                                                                                             | 他明白了载体为什么出不来                       |
| L28           | 物                   | 卸完能卸的。他找路抵达她所在的那个区域——**她第一次真的在眼前**，但周围是压得最厚的一层，进不去                                                                                                                   | 看得见，到不了                                 |
| L29           | **人（妹妹）** | 清完障碍。**全作唯一一次正常对话**：她能说完整的话、认得他、会顶他两句。短暂交流。**然后被打断——狂暴的代言人出现**                                                                                         | 情感峰值，随即被中断                           |
| L30           | 人（代言人）         | **BOSS 战。** 打赢后他虚弱下来。**主角把主任的遗物拿给他看**——那个人也曾经拼命想把你弄出来。**他因此恢复神智**，才说出最后那批卸不掉（挂在载体位上，载体要出来只有死或有人替），也才开得出那两个条件 | **至暗时刻在这里第一次出现牺牲。二选一** |

**第三章的希望节点是 L25。** 那些被救出去的人的结局，放在**结局 A 的后日谈**里兑现：他走出来，外面有人接他。

## 六个信物的排布

| #  | 位置          | 提供者             | 类型                                                                                                                    |
| -- | ------------- | ------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| ① | **L5**  | 执念体             | 信物委托（教学位，同时补 L5 原本偏空的剧情）                                                                            |
| ② | **L9**  | 特别的拾荒者       | 救援委托（活人，救出来才给）                                                                                            |
| ③ | **L13** | 【中间人】         | 支线剧情（活人，讲他自己的故事）                                                                                        |
| ④ | **L17** | **妹妹**     | 主线自动。低谷后的高峰，心境向上，带污染                                                                                |
| ⑤ | **L23** | 执念体             | 信物委托（过去的【汐城】那一层）                                                                                        |
| ⑥ | **L26** | **【主任】** | 主线自动。**真正的用途是 L30 打赢代言人后出示给他看，让他恢复神智——它是解锁最终场景的钥匙。玩家拿到时并不知道** |

**第一章有两个（L5、L9）**：玩家需要在早期学会这套系统，而且第一章最长、最需要玩法激励。第二三章各一主线 + 一支线，稀有度靠位置保证。

| 角色       | 立绘张数 | 说明                                                             |
| ---------- | -------- | ---------------------------------------------------------------- |
| 妹妹       | 2–3     | 现在的她 / 灾难前的她；第三章逐渐清晰可用同一张加效果            |
| 【主任】   | 2–3     | 现在被写住的 / 十几年前的；中间那些年可复用                      |
| 【代言人】 | 2        | 进去之前的 / 现在的                                              |
| 【中间人】 | 1        |                                                                  |
| 主角       | 1–2     |                                                                  |
| 执念体     | 3–5     | 信物委托对象与 L3 那几个，可低成本处理（剪影 / 单色 / 残缺轮廓） |
