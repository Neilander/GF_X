## 🎯 推荐集成方案

### 方案 A：在 GeneralCreature 中集成（推荐）

如果所有单位都继承自 `GeneralCreature`，可以在基类中统一添加：

```csharp
// 在 GeneralCreature.cs 中
private MinimapReportComponent minimapReport;

protected override void OnInit(object userData)
{
    base.OnInit(userData);
    minimapReport = gameObject.AddComponent<MinimapReportComponent>();
    minimapReport.Initialize(Side);
}

protected override void OnUpdate(float elapseSeconds, float realElapseSeconds)
{
    base.OnUpdate(elapseSeconds, realElapseSeconds);
    minimapReport?.Tick();
}
```

优点：
- 一次修改，所有单位自动支持
- 自动使用单位的 Side 属性
- 维护简单

### 方案 B：按需添加

在特定单位类中单独添加，适合只有部分单位需要显示的情况。


### 2. 检查单位是否注册
在 MinimapReportComponent.Initialize() 中添加日志：
```csharp

```

### 3. 检查 UI 是否接收事件
在 MinimapUI.OnMinimapUpdate() 中添加日志：
```csharp
Debug.Log($"[MinimapUI] Received {ne.Units.Count} units");
```

## 📝 注意事项

1. MinimapManager 必须在场景中存在（作为 GameFrameworkComponent）
2. 单位必须调用 Initialize() 和 Tick()，否则不会显示
3. 世界坐标范围必须正确配置，否则点位置不准
4. 战争迷雾会增加性能开销，初期建议关闭
