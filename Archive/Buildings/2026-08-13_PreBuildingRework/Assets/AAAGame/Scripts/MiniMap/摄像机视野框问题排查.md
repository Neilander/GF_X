# 摄像机视野框不显示问题排查

## 问题描述
小地图系统已经找到主摄像机，但摄像机视野框（白色方框）没有在小地图上显示。

## 当前状态
✅ MinimapUI 已初始化  
✅ 找到主摄像机："Main Camera"  
✅ 事件系统正常工作  
✅ 士兵单位正常显示，颜色正确（蓝色）  
❌ 摄像机视野框不显示  

## 可能的原因

### 1. cameraViewFrame 未在 Unity Inspector 中配置 ⭐⭐⭐⭐⭐
**最可能的原因！**

**检查步骤**:
1. 在 Unity 中选择小地图 UI 对象（MinimapPanel 或类似名称）
2. 在 Inspector 中找到 `MinimapUI` 组件
3. 查看 `Camera View Frame` 字段是否为空（None）

**如果为空**:
1. 在 Hierarchy 中找到或创建一个 Image 对象作为视野框
2. 将这个 Image 对象拖到 `Camera View Frame` 字段
3. 配置这个 Image：
   - Color: 白色 (R:255, G:255, B:255, A:255)
   - Image Type: Simple 或 Sliced
   - 可以使用一个白色边框的 Sprite，或者纯色 Image
   - 确保父对象是 minimapContainer

**预期日志**:
```
[MinimapUI] Camera view frame activated at pos=(X,Y), size=(W,H)
[MinimapUI] Camera view frame updated: pos=(X,Y), size=(W,H), active=True
```

**如果看到这个日志**:
```
[MinimapUI] cameraViewFrame is NULL! Please assign it in Unity Inspector.
```
说明确实没有配置。

### 2. 视野框被其他 UI 遮挡 ⭐⭐⭐
**检查步骤**:
1. 在 Hierarchy 中检查视野框的层级顺序
2. 确保视野框在 minimapContainer 的最后（最上层）
3. 检查视野框的 Canvas Group 是否被禁用

**解决方法**:
- 将视野框移到 Hierarchy 的最后
- 或者设置视野框的 Canvas 的 Sort Order 更高

### 3. 视野框的 Image 组件配置问题 ⭐⭐
**检查步骤**:
1. 视野框的 Image 组件是否启用
2. Color 的 Alpha 是否为 0（完全透明）
3. Raycast Target 可以关闭（不影响显示）

**正确配置**:
```
Image Component:
- Enabled: ✅
- Color: White (255, 255, 255, 255)
- Material: None (Default)
- Raycast Target: ❌ (可选)
```

### 4. 视野框的 RectTransform 配置问题 ⭐⭐
**检查步骤**:
1. Anchors: 应该设置为 center (0.5, 0.5)
2. Pivot: 应该设置为 center (0.5, 0.5)
3. Scale: 应该是 (1, 1, 1)

**正确配置**:
```
RectTransform:
- Anchors: Min(0.5, 0.5), Max(0.5, 0.5)
- Pivot: (0.5, 0.5)
- Scale: (1, 1, 1)
- Rotation: (0, 0, 0)
```

### 5. minimapContainer 配置问题 ⭐
**检查步骤**:
1. minimapContainer 是否正确配置
2. minimapContainer 的 RectTransform 是否正确

## 调试步骤

### 步骤 1: 检查日志
运行游戏后，查找以下日志：

```
[MinimapUI] OnUpdate called, cameraViewFrame=exists
```
如果看到 `cameraViewFrame=NULL`，说明没有配置。

```
[MinimapUI] Camera view frame updated: pos=(X,Y), size=(W,H), active=True
```
如果看到这个日志，说明代码正常运行，问题在 Unity 配置。

### 步骤 2: 手动创建视野框（如果不存在）

1. 在 Hierarchy 中找到小地图的 minimapContainer
2. 右键 → UI → Image，创建一个新的 Image
3. 重命名为 "CameraViewFrame"
4. 配置 Image：
   ```
   RectTransform:
   - Anchors: center (0.5, 0.5)
   - Pivot: center (0.5, 0.5)
   - Position: (0, 0, 0)
   - Size: (50, 50) // 初始大小，会被代码动态调整
   
   Image:
   - Color: White (255, 255, 255, 255)
   - Image Type: Simple
   - Sprite: 可以使用白色方框 Sprite，或者留空
   ```
5. 将这个 Image 拖到 MinimapUI 组件的 `Camera View Frame` 字段

### 步骤 3: 使用白色边框 Sprite（推荐）

如果想要更好的视觉效果，可以创建一个白色边框的 Sprite：

1. 创建一个 64x64 的图片，中间透明，边缘白色
2. 导入到 Unity，设置为 Sprite
3. 将这个 Sprite 赋值给 CameraViewFrame 的 Image 组件

### 步骤 4: 测试视野框是否可见

1. 在 Unity Editor 的 Scene 视图中选择 CameraViewFrame
2. 在 Inspector 中手动修改 Size Delta 为 (100, 100)
3. 查看 Game 视图，看是否能看到白色方框
4. 如果能看到，说明配置正确，问题在代码
5. 如果看不到，说明配置有问题

## 快速修复方案

如果确认 `cameraViewFrame` 为 null，最快的修复方法：

1. 在 Unity 中运行游戏
2. 暂停游戏
3. 在 Hierarchy 中找到 MinimapUI 对象
4. 在 minimapContainer 下创建一个 Image（如上述步骤 2）
5. 将这个 Image 拖到 MinimapUI 的 `Camera View Frame` 字段
6. 继续游戏，应该就能看到视野框了

## 预期效果

正确配置后，你应该看到：
1. 小地图上有一个白色方框
2. 方框随着摄像机移动而移动
3. 方框随着摄像机缩放而缩放
4. 日志显示：
   ```
   [MinimapUI] Camera view frame updated: pos=(X,Y), size=(W,H), active=True
   ```

## 下一步

运行游戏后，查看日志：
- 如果看到 `cameraViewFrame is NULL`，按照步骤 2 手动创建
- 如果看到 `Camera view frame updated`，但看不到方框，检查步骤 3 和 4
- 如果都正常，可能是视野框被其他 UI 遮挡，检查步骤 2（层级顺序）
