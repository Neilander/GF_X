# 卡牌系统快速配置指南

## 🚀 5 分钟快速配置

### 步骤 1: 配置 UITable (2 分钟)

1. 打开 Excel 文件：
   ```
   GF_X/AAAGameData/DataTables/Core/UITable.xlsx
   ```

2. 在最后一行添加：
   | Id | Name | AssetPath | UIGroup | AllowMultiInstance | PauseCoveredUIForm |
   |---|---|---|---|---|---|
   | 16 | CardUIForm | Assets/AAAGame/Prefabs/UI/CardUIForm.prefab | Default | FALSE | FALSE |

3. 保存文件

### 步骤 2: 生成 DataTable (30 秒)

1. Unity 菜单：`AAAGame → Generate DataTables`
2. 等待完成

### 步骤 3: 创建预制体 (2 分钟)

#### 3.1 创建 CardUIForm 预制体

1. 在 Unity 中创建空 GameObject
2. 添加 `Canvas` 组件（如果需要）
3. 添加 `CardUIForm` 脚本
4. 创建子对象：
   ```
   CardUIForm (Root)
   ├─ HandCardsContainer (Transform) - 手牌容器
   ├─ TrashBin (GameObject) - 垃圾桶
   │  └─ HintText (TextMeshProUGUI) - 提示文本
   ├─ PopulationView (GameObject) - 人口显示
   │  └─ PopulationText (TextMeshProUGUI)
   └─ CardDeck (RectTransform) - 卡组位置
   ```

5. 配置 CardUIForm 脚本：
   - `handCardContainer` → HandCardsContainer
   - `trashBin` → TrashBin
   - `trashBinHintText` → TrashBin/HintText
   - `handCardItemPrefab` → HandCardItem 预制体（步骤 3.2）
   - `populationView` → PopulationView 组件
   - `cardDeckTransform` → CardDeck

6. 保存为预制体：
   ```
   Assets/AAAGame/Prefabs/UI/CardUIForm.prefab
   ```

#### 3.2 创建 HandCardItem 预制体

1. 创建 UI Image
2. 添加 `HandCardItem` 脚本
3. 创建子对象：
   ```
   HandCardItem (Root - Image)
   ├─ CardImage (Image) - 卡面
   ├─ PopulationText (TextMeshProUGUI) - 人口消耗
   └─ SoldierCountText (TextMeshProUGUI) - 士兵数量
   ```

4. 配置 HandCardItem 脚本：
   - `cardImage` → CardImage
   - `populationText` → PopulationText
   - `soldierCountText` → SoldierCountText
   - `canvasGroup` → 添加 CanvasGroup 组件

5. 保存为预制体：
   ```
   Assets/AAAGame/Prefabs/UI/HandCardItem.prefab
   ```

### 步骤 4: 配置场景 (1 分钟)

在 Game 场景中：

1. 创建 `ValidArea` GameObject
   - 添加 Plane 或其他 3D 对象
   - 添加 Collider 组件
   - 命名为 "ValidArea"

2. 创建 `InvalidArea` GameObject
   - 添加 Cube 或其他 3D 对象
   - 添加 Collider 组件
   - 命名为 "InvalidArea"

### 步骤 5: 测试 (30 秒)

1. Unity 菜单：`AAAGame → Card System → Quick Start Card Game`
2. 或者直接运行 Launch 场景

## ✅ 验证清单

- [ ] UITable.xlsx 包含 CardUIForm 条目
- [ ] 执行了 Generate DataTables
- [ ] UIViews.cs 包含 CardUIForm 枚举
- [ ] CardUIForm.prefab 已创建
- [ ] HandCardItem.prefab 已创建
- [ ] Game 场景有 ValidArea 和 InvalidArea
- [ ] 卡牌数据在 Resources/CardData/ 目录

## 🎮 操作测试

运行游戏后测试：

1. **Tab 键** - UI 应该显示/隐藏
2. **拖拽卡牌** - 应该能拖动
3. **绿色区域** - 可放置区域应显示绿色
4. **红色区域** - 禁止区域应显示红色
5. **垃圾桶** - 拖到垃圾桶应删除卡牌
6. **快捷键 1234** - 应该能选择卡牌

## 🐛 常见问题快速修复

### 问题 1: "UIViews.CardUIForm 不存在"

```bash
# 解决方案
1. 检查 UITable.xlsx 是否有 CardUIForm
2. Unity 菜单 → AAAGame → Generate DataTables
3. 重新编译
```

### 问题 2: "CardUIForm 预制体找不到"

```bash
# 解决方案
1. 确保预制体路径正确：Assets/AAAGame/Prefabs/UI/CardUIForm.prefab
2. 检查预制体是否有 CardUIForm 脚本组件
```

### 问题 3: "卡牌无法拖拽"

```bash
# 解决方案
1. HandCardItem 添加 CanvasGroup 组件
2. 检查人口是否足够
3. 确保 CardUIForm 的 handCardItemPrefab 已配置
```

### 问题 4: "区域效果不显示"

```bash
# 解决方案
1. 在 CardUIForm 添加 CardAreaMaterialOverlay 组件
2. 配置 validOverlayMaterial 和 invalidOverlayMaterial
3. 配置 validAreaObject 和 invalidAreaObject
```

## 📝 最小配置示例

2. **Generate DataTables** - 生成枚举
